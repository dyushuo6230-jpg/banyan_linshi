## REQ-103 商品未挂一级时计佣结果

| 名称 | 商品未挂一级时计佣结果 |
| 目标与价值 | 避免下单后无法唯一计佣 |
| 需求变化状态 | 修改 |
| 结论标签 | 已确认 |
| 开放项状态 | 无（入驻 1～3 个一级见 DEC-032；停用后不可再售见 DEC-035；本需求只管未挂一级） |

| 来源编号 | DEC-013、DEC-001、DEC-012、DEC-058 |

## REQ-107 有效订单与售后窗

| 字段 | 值 |
|---|---|
| 需求编号 | REQ-107 |
| 名称 | 有效订单与售后 |
| 目标与价值 | 履约完成后即完成；完成后只评价不退；结算认已完成单 |
| 需求变化状态 | 修改 |
| 结论标签 | 已确认 |
| 开放项状态 | 无 |
| 角色 | 消费者；租户；平台财务 |
| 前置条件与入口 | 已付订单；售后申请；结算任务 |
| 页面和字段 | 主状态数字见 DEC-052。不加订单库字段；列表/评价表可加展示列（DEC-054）。后台 tab/状态列用书面语：待付款 / 已付待履约 / 履约中 / 已完成 / 已取消 / 已关闭；禁止待发货、待收货、已付款。租户须有「已关闭」tab。租户首页「已付待履约」仍统计状态 20。给人看的金额用元，库内仍为分。平台「订单管理 → 订单列表」：来源（各店/众享源品 - 在线商城）、履约（堂食/核销/发货）；「租户」列显示店名，无店名再显示编号；可按来源、租户、下单日期筛，打开默认全部。平台「订单管理 → 售后管理」页签：全部 / 待处理 / 已退款 / 已拒绝 / 已撤销；不得出现「平台介入中」。平台/租户「商品管理 → 评价管理」展示订单号与评价时间（已有才显示）；不可从评价点进订单详情 |
| 主流程 | 未付取消/超时→60。打开本池订单列表、详情或去支付时，已过到期且仍待付款的单立刻关成 60；定时仍留（DEC-060）。美发/商超核销→50。餐饮完成→50。众享源品 - 在线商城确认收货或到期自动确认→50。全额退完→70。售后仅 20/30 可申请；租户待处理时全额退或拒绝。订单 50 可真提交评价，评完不改订单状态；60/70 不可评；众享源品 - 在线商城商品详情展示真评价，无该商品已完成单不能从详情写（DEC-057）。履约为发货（众享源品 - 在线商城）且订单 20 时，租户在详情办理单笔发货或限时改运单；堂食/核销不出现发货；不在列表行内发货；CSV 保留 |
| 分支和异常 | 50 禁止新售后。有待处理售后不可收货/核销/出餐/发货。拒绝后订单主状态不变。用户可撤销待处理售后 |
| 业务规则 | 有效=订单 50 且无待处理售后。70 无效。结算从进入 50 起算 + T+周期。整单全额退。无部分退、无退货物流主路径（OPEN-01/02=A，DEC-057）。本期去掉平台仲裁办理入口与租户待收退货办理通道（DEC-054，叠加 DEC-052 第 4 条）。真评价写入评价管理，不做先审后发。未付过期打开列表/详情或去支付立刻关成 60，定时仍留（DEC-060）。众享营销 - 本地生活现用订单与众享源品未付页待付款要有倒计时、到点不能去支付（DEC-061） |
| 状态变化 | 10→20→30→50（众享营销 - 本地生活 20→50）；10→60；20/30 全额退→70 |
| 权限和数据范围 | 各端只处理本池本店单。平台后台售后只读，不办理同意/拒绝/仲裁；同意与拒绝只在租户后台。平台售后列表态：全部 / 待处理 / 已退款 / 已拒绝 / 已撤销。平台首页不展示「平台介入售后」、不按售后 80 计数。本期去掉平台仲裁办理入口；以后超管退款须新开决策。租户售后待处理只办全额退或拒绝；本期去掉「确认收到退货 / 拒绝收货」；不含订单履约上的确认收到商品 |
| 消息通知 | 沿用现码 |
| 审计要求 | 取消、核销、关单、结算筛选可追 |
| 非功能约束 | 不加订单字段 |
| Given/When/Then | Given 用户取消未付款；When 查状态；Then 为 60 不是 50。Given 美发核销成功；When 查状态；Then 为 50。Given 众享源品 - 在线商城确认收货；When 查状态；Then 为 50 不是 40。Given 订单已 50；When 申请售后；Then 拒绝。Given 该单已 50 且过结算周期、无待处理售后；When 跑结算；Then 纳入。Given 平台打开售后详情；When 寻找同意/拒绝/仲裁或支持用户/支持租户；Then 不能办理。Given 平台打开订单管理 → 售后管理；When 看页签；Then 为全部 / 待处理 / 已退款 / 已拒绝 / 已撤销，没有「平台介入中」。Given 平台打开仪表盘待办；When 查看；Then 没有「平台介入售后」。Given 租户打开众享源品 - 在线商城状态 20 且履约=发货的订单详情；When 发货；Then 在详情办理，列表行内无发货按钮。Given 平台或租户打开订单列表；When 看 tab 与状态列；Then 为待付款 / 已付待履约 / 履约中 / 已完成 / 已取消 / 已关闭，没有待发货、待收货、已付款 tab。Given 租户订单列表；When 查看；Then 有「已关闭」tab。Given 平台刚打开订单列表；When 未选筛选；Then 仍是全部。Given 平台或租户打开「商品管理 → 评价管理」；When 看列；Then 有订单号和评价时间，没有则空着。Given 订单、售后、结算给人看金额；When 查看；Then 用元。Given 订单已完成；When 提交评价；Then 评价管理出现该条，订单仍为已完成。Given 用户申请只退一部分金额；When 走本期售后；Then 不能部分退，只能整单全额退或拒绝。Given 顾客打开本池订单列表或详情或去支付；When 该单已过到期且仍待付款；Then 立刻关成 60，不能再当待付款去付。Given 一直没打开过的超时未付单；When 定时跑完；Then 也是 60。Given 现用众享营销 - 本地生活或众享源品 - 在线商城顾客打开待付款列表或详情；When 尚未到期；Then 能看见还剩多久；到期后不能再点去支付 |
