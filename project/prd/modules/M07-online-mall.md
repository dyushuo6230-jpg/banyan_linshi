众享源品 - 在线商城是多店平台商城。商品来自在线商城业态租户。平台负责众享源品 - 在线商城与在线商城设置、平台券、统一收款（除供应商租户后台外，DEC-026）。不写 mall-online 实现。页面口径见 DEC-008 v1.2、DEC-071。现用页已出现的能力须接到 mall-online 并能办完或按表藏掉（DEC-029 v1.3.0）。本轮 C 端不调起微信/支付宝/金豆，支付按钮与组件保留；加购与购物车结算进未付单（DEC-050 v1.1）。本轮登录为手机号短信或账号密码；H5「我的」须能登录并展示已登录态，不强制绑定微信身份（DEC-050）。订单主状态与售后见 REQ-107 / DEC-052。本批订单展示对齐覆盖众享源品 - 在线商城 C 端（多端同一套，DEC-054）。供应商发货办理入口见 REQ-107。发现不做；AI 整页假页（REQ-063）。众享源品 - 在线商城购物首页轮播只渲染平台 `banner` 接口；无数据不轮播、不拿页面静图冒充接口（DEC-039、DEC-050）；附近顶 banner 用板块子列表（DEC-069）。在线商城供应商侧栏无「内容管理→轮播」。众享源品 - 在线商城用户使用平台优惠券，不用供应商店铺券。附近筛选项为当前全部本地业态根（平台级，与某店勾选无关）。附近列表/店详情吃本地生活店档案（REQ-134）；本袋不算距离与导航（DEC-073）。CPS 只出平台目录上架项；跳转 extraData 只带来自众享源品 - 在线商城的标记，不传某供应商。协议与本地生活隔离、推荐双轨、地址复用、本轮「我的」/详情能力收口见 DEC-053 v1.1；商品详情真评价见 DEC-057。未付过期：打开列表/详情或去支付立刻关成已取消，定时仍留（DEC-060）。未付订单列表/详情要有倒计时、到点不能去支付（DEC-061）。商城独立拼团秒杀见 REQ-131。首页快捷区见 CR-047。
