本模块定义业态枚举、经营类目树和抽佣挂靠。不得把「到店」写成第五业态。无业态老店默认餐饮（DEC-011）。在线商城类目与计佣一级同一套（DEC-012）；一级以平台类目为准，经营类目不挂子节点（DEC-021）。未挂一级不可售（DEC-013）。节点费率空或 0 按不抽佣（DEC-058）。在线商城入驻强制 1～3 个启用中的一级（DEC-032）。类目/一级停用后已上架商品不可再售（DEC-035）。本地生活根可增；拷贝源仅餐饮/美发/商超；种子四根不可删（DEC-046/047）。在线商城发品只能挂叶子（规则在 M04 / DEC-055）；本模块计佣仍取所属一级，例句不再写「任意深度」。

| 名称 | 经营类目一棵树 |
| 目标与价值 | 入驻、可售范围、抽佣共用一棵树，避免业态表与平台类目两套打架 |
| 需求变化状态 | 新增 |
| 结论标签 | 已确认 |
| 开放项状态 | 无 |
| 角色 | 平台运营 |
| 前置条件与入口 | 平台「经营类目/业态树」配置 |
| 页面和字段 | 种子根为经营类目根：餐饮、美发、商超、在线商城。本地根可增。在线商城一级与平台类目一级同一套；经营类目页**不挂子节点**，只给一级配置费率/排序/启停。结构增删改名在「平台类目」 |
| 主流程 | 1. 平台维护业态根（本地可增）。2. 本地生活根下不要求申请人再选下级。3. 在线商城一级在平台类目维护；经营类目只展示并配置这些一级的费率 |

| 业务规则 | 一棵业务树、同一套一级。现码经营类目不再作为入驻主数据。经营类目不另建第二套一级（DEC-021） |
| 状态变化 | 节点启用/停用：资料未写停用后已选租户如何处理 → 待配置，不得编造 |
| 权限和数据范围 | 仅平台运营维护树与一级费率 |
| 消息通知 | 无 |
| 审计要求 | 节点费率变更须可查，因影响新单快照 |
| 非功能约束 | 无 |
| Given/When/Then | Given 平台打开经营类目；When 查看根；Then 至少含种子四根，并可有新增本地根。Given 展开在线商城；When 配置；Then 只见平台类目一级且可配费率，不能在此新增子节点 |
| 来源编号 | SRC-REQ-001、DEC-001 |

## REQ-003 入驻选业态与一级类目

| 字段 | 值 |
|---|---|
| 需求编号 | REQ-003 |
| 名称 | 入驻选业态与一级类目 |
| 目标与价值 | 本地生活降低入驻成本；在线商城用一级划定可售范围 |
| 需求变化状态 | 修改 |
| 结论标签 | 已确认 |
| 开放项状态 | 无 |
| 角色 | 入驻申请人 |
| 前置条件与入口 | 入驻 H5 选择业态步骤 |
| 页面和字段 | 业态必选，选项仅为「入驻可选」开启的根。餐饮/美发/商超及克隆出的本地新根：不出现经营类目下级、不选一级。在线商城：业态后多选启用中的平台类目一级，数量 1～3 |
| 主流程 | 1. 选业态。2. 若在线商城则选 1～3 个一级。3. 提交进入审核 |
| 分支和异常 | 在线商城选 0 个或超过 3 个一级：不能提交。提交失败保留已填项 |
| 业务规则 | 入驻 H5 只出现「入驻可选」为开的根（DEC-046）。在线商城强制 1～3 个启用中的一级（DEC-032）。多选只表示可售范围，不平均费率到店。过审后供应商不能自改可售一级；平台可改。改完后不在新绑定内的货按 DEC-035：不可再售、不改商品行、旧单快照不动，不自动迁货（DEC-044）。一级停用后店绑定留下、不静默删；该一级不能发新品；重新启用后绑定还在（DEC-044） |
| 状态变化 | 进入入驻待审 |
| 权限和数据范围 | 申请人只提交本申请 |
| 消息通知 | 沿用现码入驻通知（资料未改通知文案） |
| 审计要求 | 记录所选业态与一级 |
| 非功能约束 | 无 |
| Given/When/Then | Given 入驻页打开；When 申请人选择业态；Then 选项为「入驻可选」开启的根且无「到店」。Given 某本地根入驻可选已关；When 申请人看选项；Then 不出现该根。Given 申请人选餐饮；When 到类目步；Then 不要求选下级或一级。Given 选在线商城且勾 1 个或 3 个启用中的一级；When 提交；Then 申请记录这些一级且不把费率平均。Given 选在线商城且勾 0 个或 4 个一级；When 提交；Then 不能提交。Given 已过审供应商；When 自己改可售一级；Then 失败。Given 平台把某一级从该店绑走；When 该一级下已上架货；Then 不可再售且不改商品行。Given 某一级停用；When 看该店绑定；Then 绑定行仍在且不能用该一级发新品 |
| 来源编号 | SRC-REQ-001、DEC-001、DEC-032、DEC-044、DEC-046 |
| 关联设计图 | 无 |

## REQ-004 抽佣挂树节点与费率快照

| 字段 | 值 |
|---|---|
| 需求编号 | REQ-004 |
| 名称 | 抽佣挂树节点与费率快照 |
| 目标与价值 | 计佣权威在树上，新单不受事后改店字段影响 |
| 需求变化状态 | 修改 |
| 结论标签 | 已确认 |
| 开放项状态 | 无（无一级失败见 REQ-103 / DEC-013） |
| 角色 | 平台运营；结算相关角色 |
| 前置条件与入口 | 树节点可配费率（空或 0 表示不抽佣）；订单支付成功进入计佣 |
| 页面和字段 | 节点费率。店铺抽佣字段可仍存在于现码，但**不再作为新单权威** |
| 主流程 | 1. 本地生活订单：取该店业态根费率，写入订单快照。2. 在线商城订单：取商品所属**平台类目一级**费率，写入快照。3. 结算按快照 |
| 分支和异常 | 下单后平台改节点费率：已生成订单仍用快照。商品无一级：拦截，见 REQ-103 / DEC-013。节点费率为空或 0：快照为不抽佣，不拦截已挂一级的可售商品（DEC-058） |
| 业务规则 | 本地生活按业态根；在线商城按平台类目一级（DEC-021）。发品挂点收窄见 REQ-031 / DEC-055，本条不改计佣算法。禁止用多选一级的平均值作为店铺费率。DEC-058：空或 0 均不抽佣；不编造根费率死数字 |
| 状态变化 | 订单带抽佣快照后进入既有支付/结算流 |
| 权限和数据范围 | 租户不可改平台节点费率 |
| 消息通知 | 无 |
| 审计要求 | 快照数值、节点、下单时刻可查 |
| 非功能约束 | 金额唯一可计算 |
| Given/When/Then | Given 餐饮店业态根费率为资料所配值；When 产生新单；Then 抽佣用该节点快照而非店铺字段。Given 餐饮根费率为空或为 0；When 产生新单；Then 快照为不抽佣，订单仍可成交。Given 在线商品挂在平台类目叶子上且所属一级费率为空或 0；When 下单；Then 快照为不抽佣。Given 在线商品挂在平台类目叶子上；When 下单；Then 用所属一级节点费率快照。Given 存量仍挂在非叶子上且尚未改挂；When 下单；Then 仍用所属一级快照，不另算一套佣 |
| 来源编号 | DEC-001、DEC-021、DEC-055、DEC-058 |
| 关联设计图 | 无 |

## REQ-007 在线商城一级与平台类目对齐

| 字段 | 值 |
|---|---|
| 需求编号 | REQ-007 |
| 名称 | 在线商城一级与平台类目对齐 |
| 目标与价值 | 发品所选类目与计佣一级一致，避免两套一级 |
| 需求变化状态 | 修改 |
| 结论标签 | 已确认 |
| 开放项状态 | 无（具体节点名称可改，见 DEC-012；无一级见 DEC-013；停用后已上架商品见 DEC-035） |
| 角色 | 平台运营；在线商城供应商 |
| 前置条件与入口 | 平台类目树；经营类目配置一级费率；发品选类目 |
| 页面和字段 | 同一套一级。结构在平台类目（可到二/三级）；费率在经营类目对应一级。发品用树形选择器。挂哪一层见 REQ-031，本条只管与计佣一级同一套 |
| 主流程 | 平台维护平台类目（本期可用通用树先挂）→ 入驻多选一级 → 发品用树选择器选类目（只能挂叶子，规则在 REQ-031）→ 下单按所属一级快照计佣 |
| 分支和异常 | 不得在经营类目再挂一套与计佣无关的一级。超出入驻一级不得送审通过。类目名称可改，改名不另造一套一级 |
| 业务规则 | DEC-012 + DEC-021：同一套一级；结构以平台类目为准；经营类目不挂子；树选择器发品；通用树可先挂且可改名，不是行业标准。发品必须挂叶子见 REQ-031 / DEC-055，本条不重复挂点规则 |
| 状态变化 | 节点启用/停用后已上架商品：不可再售、不改商品行、已下单不改快照（DEC-035）。一级停用后店绑定留下（DEC-044） |
| 权限和数据范围 | 仅平台维护结构与一级费率；供应商只读选用且受入驻一级约束 |
| 消息通知 | 无 |
| 审计要求 | 费率变更可查（已有 REQ-004） |
| 非功能约束 | 不写库表；非正式 UI_SPEC |
| Given/When/Then | Given 供应商发品；When 选择品类；Then 选项来自平台类目树且计佣一级与所选节点所属一级相同。Given 入驻只选了一级 A；When 选到 A 以外的一级；Then 不得送审通过。Given 已过审商品所属一级停用；When 众享源品 - 在线商城下单；Then 不可再售且不改该商品上架字段 |
| 来源编号 | DEC-012、DEC-021、DEC-001、SRC-REQ-001、DEC-035 |
| 关联设计图 | 无 |
