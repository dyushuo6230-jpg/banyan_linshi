仅本地生活（种子餐饮/美发/商超及克隆出的新根，随该业态菜单模板）。租户完整创建上下架，平台不审、不建**统一**场次（店可自建秒杀场次，DEC-070）。C 端按 DEC-070：首页专区、新列表、从点餐详情复制的新详情；功能件跟会话四张图，不卡像素。待审历史按 DEC-014 改为未上架。停用后不可新参、已下单不自动退（DEC-038）。拼团不另出核销码，与普通已付订单同一套码；拷贝源餐饮仍扫桌（DEC-043）。首页模块归属增加拼团/秒杀坑（DEC-046 v1.1）。**众享源品独立拼团秒杀不在本模块第一种流程里**，见 REQ-131 / DEC-068 / ADR-011 v1.1。REQ-052「在线商城本期无拼团秒杀」已废止。

## REQ-050 租户发布拼团秒杀且平台不审

| 字段 | 值 |
|---|---|
| 需求编号 | REQ-050 |
| 名称 | 租户发布拼团秒杀且平台不审 |
| 目标与价值 | 本地生活营销由店内完成，去掉平台审核等待 |
| 需求变化状态 | 修改 |
| 结论标签 | 已确认 |
| 开放项状态 | 无（进行中停用见 DEC-038；拼团核销码见 DEC-043） |
| 角色 | 本地生活租户（含克隆新根）；本店消费者 |
| 前置条件与入口 | 租户后台营销：秒杀（场次 / 商品管理两个页签）、拼团活动。不经平台审核 |
| 页面和字段 | 秒杀场次：名称、开始、结束、停止/上架、删除；无「商品」弹窗。秒杀商品管理：分部表单，先选场次，再搜索勾选本店已上架货，价用元、单独活动库存、限购。拼团：分部表单单选一货一规格，填拼团价（元）、成团人数、活动库存、限购、成团时限；上架/下架，不要开始结束时间；团列表能看清状态。无待审状态。标明单位为元（DEC-054）。不把已删平台经营入口加回来 |
| 主流程 | 1. 租户勾本店货创建拼团或秒杀并上架。2. 本店 C 端可见可买（规则与后台对齐，见 REQ-054）。3. 下架或秒杀场次结束后不可再按进行中购买 |
| 分支和异常 | 进行中停用：下架后不可新参；已下单不自动关、不自动退（DEC-038）。库存不足：不能超卖（活动库存与规格库存同时扣，DEC-070） |
| 业务规则 | 不经平台审核。无待审状态。平台不增加强制下架经营菜单。有拼团秒杀菜单的本地生活店均可自发（新根随拷贝源模板，不写死三个业态名）。活动库存单独记账，上限不超过该规格可售。DEC-038：停用后 C 端拒绝新参；已生成订单不因停用改状态、不自动退；要退走现码退款。DEC-043：拼团不另出核销码。禁止手填商品 ID。不与源品报名表混用 |
| 状态变化 | 租户上下架；无平台待审 |
| 权限和数据范围 | 本店活动、本店订单 |
| 消息通知 | 资料未写平台通知 |
| 审计要求 | 租户创建与上下架记录 |
| 非功能约束 | 先不做插件，直接在租户后台使用完整功能 |
| Given/When/Then | Given 餐饮租户勾本店货创建秒杀并上架；When 未经过平台审核；Then 本店用户仍可见该活动。Given 活动；When 查看状态；Then 无「待平台审核」。Given 活动进行中租户下架；When 新用户参加；Then 失败。Given 已付待核销的秒杀单；When 租户随后下架活动；Then 订单不自动关、不自动退。Given 租户打开拼团或秒杀表单；When 看价格或填写；Then 单位为元，不是按分给人填，且从本店已上架货勾选而不是手填 ID |
| 来源编号 | SRC-REQ-001、DEC-004、DEC-038、DEC-043、DEC-054、DEC-070、CR-048 |
| 关联设计图 | SRC-UI-001（交互线索）；会话附图（后台结构按 DEC-070） |

## REQ-054 本地生活 C 端拼团秒杀

| 字段 | 值 |
|---|---|
| 需求编号 | REQ-054 |
| 名称 | 本地生活 C 端拼团秒杀 |
| 目标与价值 | 用户能在店内小程序参加租户已上架活动 |
| 需求变化状态 | 修改 |
| 结论标签 | 已确认 |
| 开放项状态 | 无 |
| 角色 | 本店消费者 |
| 前置条件与入口 | 租户已上架活动；本店小程序首页拼团专区 / 限时秒杀，或「查看全部」进列表 |
| 页面和字段 | 首页：拼团专区两列（图、名、拼团价、划线原价、去拼团）+ 查看全部；限时秒杀横向滑（图、名、距结束、秒杀价、划线原价、立即抢购）+ 查看全部。拼团列表、秒杀列表为新页（秒杀含场次页签、已抢进度、限购、已结束态）。详情为从点餐详情复制的新页，不改普通货详情。须与后台设置对齐。首页坑按 DEC-046 v1.1 归属，无活动则空 |
| 主流程 | 首页或列表 → 活动详情 → 按活动规则下单支付（到该店账户）→ 履约按业态：餐饮扫桌；美发/商超与普通已付订单同一套核销码，拼团不另出码（DEC-043） |
| 分支和异常 | 活动已下架或秒杀场次已结束：不能按进行中购买；已结束场次仍可看货。装修关掉或归属不允许：整块不出现 |
| 业务规则 | 仅本地生活、认本店。不进源品端、不读源品报名。DEC-043：拼团不另出核销码。功能件和结构跟会话四张图，不卡像素（DEC-070） |
| 状态变化 | 沿用活动与订单状态（无平台待审） |
| 权限和数据范围 | 本店用户池 |
| 消息通知 | 资料未写细 |
| 审计要求 | 无 |
| 非功能约束 | 非正式 UI_SPEC；不验收手表 Banner / 开通会员 / 点赞红包 |
| Given/When/Then | Given 美发店上架拼团；When 本店用户从首页拼团专区或拼团列表点进活动详情并下单；Then 可按拼团价下单且无需平台先审，且未进入普通点餐详情。Given 本店无进行中秒杀；When 打开首页秒杀区；Then 空态，不拿普通推荐冒充。Given 秒杀场次已结束；When 打开秒杀列表该场；Then 能看见货且按钮为已结束、不能买。Given 仅有参考截图；When 做视觉验收；Then 查功能件是否齐全，不以截图像素为基准。Given 美发拼团单已支付；When 到店核销；Then 使用与普通已付订单同一套码，不另出第二张 |
| 来源编号 | SRC-REQ-001、SRC-UI-001、SRC-CODE-002、DEC-043、DEC-046、DEC-070、CR-048 |
| 关联设计图 | 会话附图（功能件）；SRC-UI-001（旧交互线索） |
