改什么、验收、一次交付以 SRC-REQ-003（A1～A17）为准；SRC-REQ-002 只解释原理与现码盘点。工期按一次上线（顺序 ≠ 分期）。本模块描述业务与验收，不写密钥配置文件、中间件类名或票的存储实现。

默认数字（产品未另定，DEC-005 采用文档默认）：后台闲置 30 分钟；后台同一段登录寿命 12 小时；C 端可作废长票约 7 天无活动作废；短票 30～120 分钟，快过期且会话仍在则换新票。

众享源品 - 在线商城纳入同一套可作废会话。认店只限众享营销 - 本地生活。网页后台本期 Cookie+CSRF；小程序继续 Header。不要先本地存储再迁 Cookie。

## REQ-080 口令不以明文保存或返回

| 字段 | 值 |
|---|---|
| 需求编号 | REQ-080 |
| 名称 | 口令不以明文保存或返回 |
| 目标与价值 | 拖库或调接口拿不到可登录原文 |
| 需求变化状态 | 修改 |
| 结论标签 | 已确认 |
| 开放项状态 | 无（复杂度 DEC-062；存量后台强制改密 DEC-063；超管登录名与登录页不预填 DEC-064；超管独占 DEC-065；浏览器回填 DEC-066） |
| 角色 | 平台账号；租户主账号与子账号；两套顾客端在设密时 |
| 前置条件与入口 | 入驻通过设密、重置密码、账号列表、店铺详情、首次改密、顾客端注册/改密 |
| 页面和字段 | 密码只可设置/修改，列表与详情不展示可登录明文。各端登录页账号、密码框都不写死默认值；生产/测试对外站无演示账号下拉、无默认弱口令进入。登录、设密、改密、注册的账号密码框，以及微信 AppID/AppSecret、支付密钥、短信/OSS 密钥，须声明不要浏览器自动填；登录页不要「记住密码」（DEC-066）。设密/改密/重置/注册的密码框旁或下方必须写明该端规则（后台与顾客端两句不同）。登录已有密码的输入框不展示复杂度规则 |
| 主流程 | 1. 入驻通过或重置：随机密码只向操作者亮一次，之后只存不可逆口令。2. 首次登录强制改密。3. 超管首次必须改密。4. 停写停读任何可登录明文旁路。5. 新设、改密、重置、注册须符合 DEC-062。6. 存量平台管理员、租户主账号、租户后台子账号：开工后打上必须改密；用当前密码能登到改密页，改成 DEC-062 后台规则前不能进日常菜单（DEC-063）。7. 平台超管登录名改为 `ZadminDister`，`admin` 登不上；该号仍走第 6 步强制改密（DEC-064）。8. 登录与密钥框按 DEC-066 声明不要浏览器自动填 |
| 分支和异常 | 刷新后再看重置结果：看不到原文。历史明文须清空。生产演示弱口令登不进生产。新密码不合格：拒绝保存，提示须说清该端规则。旧密码没人记得：走现有重置，只亮一次，不发全站清单。租户登录页找回密码：发送通道已配置则必须真发；失败须让操作者看见失败原因，不得提示成功。通道未配置的处理沿用现码，不编造新文案。改名若与已有登录名冲突：停止、报给人，不覆盖。浏览器仍从自己保险柜填回登录框：不算页面写死默认值 |
| 业务规则 | 库和接口不再保存/返回可登录明文。告知改成只亮一次。设密复杂度以 DEC-062 为准，服务端为权威。存量后台按 DEC-063 强制改密，不批量生成明文总表。登录核哈希通过后若仍须改密，不得进日常菜单。两套顾客端不因此批量改密。平台超管登录名与登录页预填以 DEC-064 为准。浏览器回填以 DEC-066 为准，不承诺 Chrome 对登录框 100% 不填 |
| 状态变化 | 标记须改密直至改完 |
| 权限和数据范围 | 重置权限沿用现码角色 |
| 消息通知 | 可弹窗或短信亮一次（资料允许二者），不得再次从列表取出。租户找回密码走短信且通道已配置时必须真发（CR-033） |
| 审计要求 | 重置操作可查，日志无完整密码 |
| 非功能约束 | 换清明文须全员相关账号按新口令登录 |
| Given/When/Then | Given 平台打开租户账号列表；When 查看；Then JSON/页面无明文密码。Given 刚重置；When 只亮一次后刷新；Then 再也看不到该明文。Given 打开平台或租户或顾客端登录页；When 查看账号和密码框；Then 均为空，不预填 `admin`、`ZadminDister` 或任何密码；框声明不要浏览器自动填。Given 打开店铺设置或支付配置；When 查看 AppID 或密钥框；Then 声明不要浏览器自动填。Given 用没有保存过密码的浏览器打开上述页；When 查看；Then 框为空。Given 用 `admin` 登平台；When 提交；Then 失败。Given 用 `ZadminDister` 与当前密码登录；When 核哈希通过且仍须改密；Then 只能进改密页。Given 平台或租户在设密页；When 查看密码框旁；Then 能看见至少 10 位且四类至少三类的说明。Given 用 `123456` 给平台或租户设新密；When 提交；Then 失败且提示说清规则。Given 存量平台或租户账号仍用旧密码；When 登录成功；Then 只能进改密页，不能进日常菜单。Given 改成符合后台规则的新密；When 再进入；Then 能进日常菜单。Given 众享源品或本地生活顾客在注册/改密页；When 查看；Then 能看见至少 8 位且须有字母和数字。Given 顾客端只填 8 位纯数字；When 提交；Then 失败。Given 租户在登录页找回密码且短信通道已配置；When 通道发送失败；Then 页面看见失败原因，不是已发送成功 |
| 来源编号 | SRC-REQ-003 A2/A3/A14、DEC-005、DEC-062、DEC-063、DEC-064、DEC-066、CR-033、CR-037、CR-038、CR-039、CR-041 |
