租户后台仍是一套系统。平台在同一配置页切换业态编辑菜单模板（种子四套；新增本地根多一个克隆页签）。租户已点名显示名与有无见 DEC-020～024、DEC-027、DEC-028；在线商城无「内容管理→轮播」（DEC-039）、无「周边CPS」；v1.1 有「秒杀报名」「拼团报名」「板块报名」。本地生活「秒杀 / 拼团活动」菜单仍在，页内结构按 DEC-070（秒杀两页签勾货、拼团分部单选）。平台侧栏点名见 DEC-031 v1.1：删「周边分类管理」，周边管理下加「周边CPS」，商户管理下加「首页模块归属」；秒杀/拼团审核删行且不恢复旧名；补通道用量；另有商城秒杀/商城拼团与板块菜单。小魔推四套侧栏均隐藏（DEC-019），代码与小程序页不拆。在线商城有「店铺资料」、无员工/角色（DEC-028）。落地标准见 DEC-029 v1.3.0。本地生活「店铺」页店档案与附近详情展示见 REQ-134 / DEC-073。

## REQ-025 接口按权限校验

| 字段 | 值 |
|---|---|
| 需求编号 | REQ-025 |
| 名称 | 接口按权限校验 |
| 目标与价值 | 菜单与权限对齐，隐藏不能越权 |
| 需求变化状态 | 修改 |
| 结论标签 | 已确认 |
| 开放项状态 | 无（平台四项对普通角色关闭 DEC-065） |
| 角色 | 平台管理员；租户主账号与子账号 |
| 前置条件与入口 | 任何需登录的后台接口 |
| 页面和字段 | 角色与权限（现码已有；细项资料未重写则保留现状能力并与模板对齐）。平台「系统管理 → 管理员」创建/编辑非超管必须选出至少一个角色。给其它角色勾权限时，菜单树与接口树不出现管理员、角色管理、菜单管理、API 管理及只管这四页的接口 |
| 主流程 | 请求带会话 → 校验身份与权限与数据范围 → 通过才执行 |
| 分支和异常 | 无权限：拒绝。跨店：拒绝。过期会话：见 M09。非超管未选角色：不能保存。无角色账号登录后侧栏无菜单，业务接口按无权限拒绝。给普通角色保存时带着那四项或配套接口：失败并说人话 |
| 业务规则 | 数据范围为本店（租户）或平台全局（平台角色）。不以自营标记授权。平台非超管必须至少有一个角色才能保存；无角色不能当运营用（CR-033）。平台那四项及配套接口不对普通角色开放；藏菜单不是授权（DEC-065、DEC-002）。系统管理里参数/快递/日志等本条仍可给运营 |
| 状态变化 | 无 |
| 权限和数据范围 | 如上 |
| 消息通知 | 无 |
| 审计要求 | 敏感操作沿用现码审计（资料未加新审计事件则不编造） |
| 非功能约束 | 无 |
| Given/When/Then | Given 租户 A 会话；When 访问租户 B 数据；Then 失败。Given 已隐藏菜单但账号无该权限；When 调接口；Then 失败。Given 平台在系统管理 → 管理员新建非超管且未选角色；When 保存；Then 不能保存。Given 某非超管账号没有任何角色；When 登录平台后台；Then 侧栏无可用菜单，不能当运营办理。Given 给运营角色勾管理员或角色管理或菜单管理或 API 管理；When 保存；Then 失败。Given 非超管直访这四页或调对应接口；When 请求；Then 失败 |
| 来源编号 | SRC-REQ-001、DEC-002、DEC-006、CR-033、DEC-065、CR-040 |
