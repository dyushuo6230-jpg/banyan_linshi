平台只审核在线商城商品（DEC-026）。本地生活普通商品店内上架即可本店可售，租户自己推本店推荐栏（店铺推荐）。在线商城/众享源品 - 在线商城的平台推荐与店铺推荐分离：店铺推荐不影响众享源品 - 在线商城货池（DEC-053）。审核台批量通过/驳回仅覆盖在线商城（DEC-018 经 DEC-026 收窄），逐条独立（DEC-044）。草稿保持驳回，提交/上架回待审（DEC-043）。拼团秒杀仍不审（DEC-004）。品牌按 DEC-009 保留且发品可选。类目与计佣一级同一套（DEC-012）；一级以平台类目为准（DEC-021）。在线商城发品必须挂叶子，计佣仍向上取一级；筛选选祖先须含子孙叶子上的商品（DEC-055）。存量非叶子可在商品列表批量改挂到人手选叶子，逐条独立，系统不自动猜（DEC-057）。在线商城发品不强制店铺分类（DEC-030）。类目/一级或店内分类停用后已上架商品不可再售（DEC-035）；一级停用后店绑定留下（DEC-044）。本地生活商品不进入众享源品 - 在线商城。

## REQ-030 本地生活店内分类发品

| 字段 | 值 |
|---|---|
| 需求编号 | REQ-030 |
| 名称 | 本地生活店内分类发品 |
| 目标与价值 | 店内小程序售卖仍用店内分类，发品必选分类 |
| 需求变化状态 | 保留 |
| 结论标签 | 已确认 |
| 开放项状态 | 无 |
| 角色 | 餐饮/美发/商超租户 |
| 前置条件与入口 | 租户后台商品；已套本地生活菜单 |
| 页面和字段 | 店内分类；商品。发品必须选择店内分类。推荐栏：租户将本店商品推到本众享营销 - 本地生活推荐区 |
| 主流程 | 1. 维护店内分类。2. 发布商品并必选分类。3. 上架后本众享营销 - 本地生活按分类可售。4. 租户可选将商品推到本店推荐栏 |
| 分支和异常 | 未选分类不能可售。店内分类停用后挂该类的已上架商品不可再售（DEC-035），不改商品行。平台不审本地生活普通商品。平台不把本地生活商品当众享源品 - 在线商城货源 |

| 状态变化 | 上架 / 下架沿用现码。无平台待审。字段名留 G8 |
| 权限和数据范围 | 租户本店 |
| 消息通知 | 沿用现码；专用通知文案资料未写 → 待配置 |
| 审计要求 | 谁上架/谁推荐可查（沿用现码能力，不新编状态机） |
| 非功能约束 | 无 |
| Given/When/Then | Given 餐饮租户发品未选分类；When 上架；Then 不能作为可售。Given 已选分类并上架；When 本店顾客打开小程序；Then 能按分类看到并可买。Given 租户将某商品推到推荐栏；When 本店顾客看推荐区；Then 能看到该商品。Given 众享源品 - 在线商城用户；When 浏览；Then 看不到该本地生活商品。Given 店内分类已停用且商品仍显示上架；When 本店顾客加购或下单；Then 不可再售且不改该商品上架字段 |

## REQ-031 在线商城按平台类目发品并送审

| 字段 | 值 |
|---|---|
| 需求编号 | REQ-031 |
| 名称 | 在线商城按平台类目发品并送审 |
| 目标与价值 | 供应商货进入众享源品 - 在线商城前受平台监管 |
| 需求变化状态 | 修改 |
| 结论标签 | 已确认 |
| 开放项状态 | 无 |
| 角色 | 在线商城供应商；平台审核人 |
| 前置条件与入口 | 租户后台发品；平台商品审核 |
| 页面和字段 | 商品；类目用树形选择器，选自与计佣同一套的**平台类目树**（DEC-012、DEC-021）。树仅含该店入驻已选一级及其下级；发品/保存/送审只能选最末叶子，有下级的节点不可选（DEC-055）。可售范围受入驻所选一级约束。不要求选择店铺分类（DEC-030）；侧栏无店铺分类且不恢复。商品列表按平台类目筛选时，选中祖先节点须包含其子孙叶子上的商品。商品列表可多选后批量改挂到一个人手选的叶子（DEC-057） |
| 主流程 | 1. 供应商按平台类目创建商品（店铺分类可空）。2. 提交审核。3. 平台通过后众享源品 - 在线商城可按平台类目展示。4. 驳回则不可作为众享源品 - 在线商城在售。5. 再提：草稿保存保持驳回；提交或上架且需审则回待审（DEC-043）。6. 存量挂在非叶子上的：可单条编辑改叶子，或列表勾选后批量改挂到指定叶子 |
| 分支和异常 | 未选平台类目不得送审通过。未选叶子、或商品类目超出入驻一级范围：不允许保存/送审通过。缺店铺分类不得否决。本地生活普通商品不审（DEC-026）。存量已挂非叶子：编辑可回显，保存必须改成叶子；不自动改挂。批量改挂：目标必须是叶子且在入驻一级子树内；逐条独立，失败留下并提示；不改未勾选的；不得猜第一个叶子（DEC-057） |
| 业务规则 | 未审核通过不得在众享源品 - 在线商城对用户可售。不是平台自营商品。类目与计佣一级同一套（DEC-012、DEC-021）。DEC-030：店铺分类可空；不以店内分类为众享源品 - 在线商城逛货权威。DEC-043：草稿保持驳回；提交/上架回待审。DEC-053：平台推荐（众享源品 - 在线商城）与店铺推荐分离；店铺推荐开关不改变众享源品 - 在线商城可售或在线商城顾客端推荐池。DEC-055：发品必须挂叶子；计佣仍向上取一级。DEC-057：允许人手选叶子的批量改挂，逐条独立 |
| 状态变化 | 待审 → 通过 / 驳回（名称沿用现码审核语义，不写字段名） |
| 权限和数据范围 | 供应商只看本店商品；平台看全部在线商城待审 |
| 消息通知 | 资料未写专用通知 → 待配置，不得编造短信文案 |
| 审计要求 | 审核人、时间、结果 |
| 非功能约束 | 无 |
| Given/When/Then | Given 供应商提交商品；When 尚未通过；Then 众享源品 - 在线商城用户不能把它当在售商品买到。Given 平台通过；When 用户浏览；Then 可见可买（支付见 M10）。Given 在线商城发品未选店铺分类已选平台类目叶子；When 保存或送审；Then 不以缺店铺分类否决。Given 未选平台类目或只点了还有下级的父节点；When 保存或送审；Then 失败。Given 已驳回商品只存草稿；When 不点提交；Then 仍为驳回。Given 已驳回商品再次提交或上架；When 该货须平台审；Then 回待审。Given 列表筛选选中某祖先节点；When 查看结果；Then 含挂在其子孙叶子上的商品。Given 旧货挂在还有下级的父节点；When 打开编辑；Then 能看见原挂点。Given 该旧货再保存且未改成叶子；When 保存；Then 失败，系统不自动改挂。Given 供应商勾选本店多条非叶子旧货并选一个合法叶子；When 批量改挂且其中一条目标非法；Then 合法的已改挂，非法的留下并提示，不整批回滚。Given 批量改挂时选中仍有下级的父节点；When 确认；Then 失败 |
| 来源编号 | SRC-REQ-001、DEC-012、DEC-021、DEC-030、DEC-043、DEC-055、DEC-057 |
| 关联设计图 | 无 |

## REQ-032 平台只审核在线商城商品

| 字段 | 值 |

| 名称 | 平台只审核在线商城商品 |
| 目标与价值 | 平台把关众享源品 - 在线商城货源；不审店内小程序普通商品 |
| 需求变化状态 | 修改 |

| 审计要求 | 审核人、时间、结果 |
| 非功能约束 | 不在 PRD 写列改名 |
| Given/When/Then | Given 在线商城商品；When 未通过平台审核；Then 众享源品 - 在线商城不可售。Given 美发租户上架本店服务；When 未送平台审核；Then 本众享营销 - 本地生活仍可售（不经本队列）。Given 平台勾选多条在线商城待审；When 批量通过且其中一条失败；Then 成功的已通过，失败的列出原因，其余不回滚 |
| 来源编号 | SRC-REQ-001、DEC-026、DEC-018、CR-007、DEC-044 |

## REQ-034 平台类目树供在线商城选用

| 字段 | 值 |
|---|---|
| 需求编号 | REQ-034 |
| 名称 | 平台类目树供在线商城选用 |
| 目标与价值 | 供应商发品有类目可选，且与计佣一级同一套 |
| 需求变化状态 | 修改 |
| 结论标签 | 已确认 |
| 开放项状态 | 无（节点名称可改；停用后已上架商品见 DEC-035；停用保留店绑定见 DEC-044） |
| 角色 | 平台运营；在线商城供应商 |
| 前置条件与入口 | 平台类目树；租户发品 |
| 页面和字段 | 树形选择器。本期可用通用树先挂。只给在线商城租户用。树已按入驻一级裁剪；非叶子不可选（DEC-055） |
| 主流程 | 平台在平台类目维护树 → 供应商用树选择器选**叶子** → 审核与展示使用该类目 → 计佣取所属一级 |
| 分支和异常 | 不得再在经营类目挂第二套发品一级。本地生活不选该树。挂点或所属一级停用后已上架商品不可再售（DEC-035）。一级停用不静默删除店绑定；该一级不能发新品；再启用后绑定仍在（DEC-044） |
| 业务规则 | DEC-012、DEC-021：同一套；结构以平台类目为准；树选择器；通用树可改名，不是行业标准。DEC-035：停用后不可再售、不改商品行、已下单不改快照；再启用可再售。DEC-044：停用保留绑定。DEC-055：发品必须挂叶子；筛选祖先包含子孙。DEC-057：人手选叶子批量改挂。DEC-058：不把节点清单写进 PRD 或正式种子，运营在「商品管理 → 平台类目」自建 |
| 状态变化 | 停用：已上架商品不可再售，不改上架字段。再启用：仍上架且已过审的可再售。无新商品状态机 |
| 权限和数据范围 | 平台维护结构；经营类目配一级费率；供应商只读选用（选择器已按入驻一级裁剪） |
| 消息通知 | 无 |
| 审计要求 | 无 |
| 非功能约束 | 非正式 UI_SPEC；节点清单不冻结为本需求 |
| Given/When/Then | Given 在线商城发品；When 选品类；Then 用树形选择器且选项来自该店入驻一级及其下级，只能选叶子，不是店内分类，也不是经营类目另挂的一套。Given 改了一级名称；When 已有商品仍挂该一级下的叶子；Then 仍按该一级计佣，不视为换了一套类目。Given 已过审商品所属一级停用；When 众享源品 - 在线商城浏览或下单；Then 不可再售且订单快照不因停用重算。Given 一级停用；When 查看该供应商绑定；Then 绑定行仍在 |
| 来源编号 | DEC-012、DEC-021、SRC-REQ-001、DEC-001、DEC-035、DEC-044、DEC-055、DEC-057、DEC-058 |
| 关联设计图 | 无 |
