## 用途

原始资料入口、批次摘要和来源总登记。G1 之前不要把任何资料自动当作已确认需求。

## 规则

1. 用户说「这是第 N 批资料」时才处理。
2. 只登记和归档，不改写原件。
3. 分离业务需求、技术建议和 UI 建议。
4. 历史资料标记 `HISTORICAL_REFERENCE`。
5. 设计图只用于识别可见页面、字段、按钮和状态，不能推断完整权限、状态机和资金规则。
6. 用户未宣布「材料投放完成」前，不进入 G2。

## 投放时需要的信息

- 资料类型
- 资料路径
- 版本 / 年代
- 优先级
- 适用终端（如有）

## 子目录

- `inbox/`：待处理资料入口
- `batches/`：每批摘要
- `platform-categories/`：平台类目导入定稿（DEC-072；已确认并灌入本机 shop；不是 PRD）
