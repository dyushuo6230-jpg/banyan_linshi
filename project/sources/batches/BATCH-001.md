## 2. 业务 / 技术 / UI 分离

### 业务需求（候选，来自 SRC-REQ-001）

- 两大类业态：本地生活（有独立小程序，支付到商家账户）与在线商城供应商（无独立小程序，商品平台审核后上架众享源品 - 在线商城，平台统一支付并抽佣）
- 方案正文业态列举：餐饮、商超、到店、美发、在线商城（与会话中「四个业态」表述不完全一致，见冲突）
- 入驻：餐饮/美发/商超不选经营类目；在线商城可多选平台类目一级
- 拼团秒杀：本地生活做、平台不审、商户后台直接用；在线商城本期不做
- 美发/商超：支付后核销码、到店核销；首页改文案、去掉堂食预约
- 餐饮：到店扫桌号，本期不做外卖
- 菜单：平台与商户菜单重命名、对齐权限、菜单隐藏、商家菜单分业态
- 众享源品 - 在线商城独立登录（手机号 + 账号密码）；店与店、店与众享源品 - 在线商城用户分开
- 订单信息完善；关键配置加注释
- 本期不做：外卖；在线商城拼团秒杀；众享源品 - 在线商城 AI 和发现（页面可留样式）
