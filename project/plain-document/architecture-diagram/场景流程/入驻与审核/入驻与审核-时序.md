# 入驻与审核-时序

这张图看入驻页、审核、套菜单谁先谁后。入驻只读业态树，不在入驻页改树。通过后才套该业态菜单。不写接口路径、字段名。

## 给谁看

开发交接套菜单时机。细则在《租户入驻与审核》；泳道见同夹《入驻与审核-泳道》。

## 关键规则

- 入驻页只读「入驻可选」开着的根。在线商城再读启用中的一级。
- 没有菜单模板不能通过。驳回只能提新单。
- 不问自营。

## 图

```mermaid
sequenceDiagram
  actor 申请人
  participant 入驻页
  participant 树 as 业态树
  participant 平台 as 平台审核
  participant 菜单 as 商户菜单

  申请人->>入驻页: 拿着有效资格打开同一套入驻页
  入驻页->>树: 只要开着、允许入驻的根
  树-->>入驻页: 只读列表，入驻页改不了树
  申请人->>入驻页: 选一个根；若是商城再选 1～3 个启用中的一级；交执照
  入驻页-->>申请人: 申请变成待审，进不了租户后台

  平台->>入驻页: 打开待审单办理
  入驻页-->>平台: 业态、执照、商城已选一级
  alt 没有菜单模板或补不了业态
    平台-->>申请人: 不能通过；驳回则原单结束，只能提新单
  else 通过
    平台->>菜单: 按该业态套这一家店的菜单
    菜单-->>申请人: 以后从租户后台进，侧栏是这套模板
  end
```

## 不画什么

- 不写字段名、接口路径、端口、域名。
- 无此路径：入驻页改树、自营勾选、改原单再送。
- 发品、履约不在本图。
