# 本地生活登录-泳道

这张图只看众享营销 - 本地生活：人在**某一家店**的小程序登录，账号进店铺池，权限只落在这一家店。不要和在线商城的顾客端登录画在一张图上。

## 给谁看

开会讲「店 A、店 B、在线商城的顾客端是三个号」；测试串店和下错池。细则在《用户账号与用户池》《登录会话与口令》；页面在分端《众享营销-本地生活》。

## 关键规则

- 店 A 注册只是店 A 的号；打开店 B 还要再注册。
- 认店只约束本端：购物车、下单、支付、券不能信顾客端传来的店号。
- 店内登录态放在请求头。店内票不能拿去调在线商城的顾客端。
- 本期不开在线商城的顾客端那套短信或账密作为店内必做登录。闲置天数、票过期秒数图上不写死。

## 图

```mermaid
flowchart TB
  subgraph 顾客["顾客"]
    direction TB
    cStart((顾客打开店 A 小程序<br/>要办事时走进本店登录，不是在线商城的顾客端「我的」))
    cLogin["顾客用店内现有方式登录<br/>微信授权或本店已绑手机，沿用现页"]
    cMine["顾客在本店「我的」看见本店会员身份<br/>不和在线商城的顾客端账号打通"]
    cOrder["顾客在本店选菜、选商品或选服务要下单<br/>钱若付成功进的是该店账户，不进在线商城的顾客端"]
    cExit["顾客点退出，或长票闲置到期<br/>须重新登录才能再当本店会员"]
    cEnd((仍是店 A 的人<br/>或被踢回本店登录页))
  end

  subgraph 店 A 小程序["店 A 小程序"]
    direction TB
    aHead["小程序把本店登录票放在请求头<br/>不改成网页那套登录态"]
    aNoPwd["无此路径：把在线商城的顾客端短信或账密当成店内必做登录"]
    aFake{"顾客端有没有乱传别家店号？"}
    aHall{"有没有拿这张店内票去调在线商城的顾客端？"}
  end

  subgraph 本地生活["本地生活"]
    direction TB
    sPool["按店铺池认出：这家店加这个手机才是一个号<br/>老数据一律看成店铺池，空店身份不要默认成在线商城的顾客端用户"]
    sOk["发给店内登录票<br/>权限只落在店 A，不是店 B，也不是在线商城的顾客端"]
    sShop{"打开的还是店 A 吗？"}
    sB["须在店 B 再注册、再登录<br/>店 A 的号不能直接当店 B 会员"]
    sBind["当前店以小程序绑的那一家为准<br/>乱传店号不能下到别人店、不能付到别人店"]
    sRefuseHall["拒绝：这不是在线商城顾客端账号<br/>在线商城的顾客端货架和在线商城的顾客端订单都够不着"]
    sVoid["立刻作废这一张店内票<br/>在线商城的顾客端那一套登录票原样留着，互不影响"]
    sIdle["无此路径：店内再套一套 30 分钟闲置、短信二次验证、设备列表"]
  end

  cStart --> cLogin --> aNoPwd --> aHead --> sPool --> sOk --> cMine --> sShop
  sShop -->|顾客又打开店 B 小程序| sB
  sShop -->|仍在店 A 办事| cOrder --> aFake
  aFake -->|乱传店 B 或伪造店号| sBind
  aFake -->|不传或传的就是本店| sBind
  sBind --> aHall
  aHall -->|拿店内票调在线商城的顾客端| sRefuseHall
  aHall -->|只在本店继续点| cExit --> sVoid --> sIdle --> cEnd
```

## 不画什么

- 不画众享源品登录、在线商城的顾客端协议、在线商城的顾客端「我的」已登录。隔离先后见同夹《两套登录隔离-时序》。
- 无此路径：店内票调在线商城的顾客端、在线商城的顾客端账密铺到每家店、第三方登录全家桶、短信二次验证、设备列表、顾客端额外 30 分钟闲置。
- 不画后台网页登录、入驻资格票、端口和域名。
