# 商城审品-时序

这张图看供应商送审之后，谁让货出现在在线商城的顾客端。只办理在线商城。本地生活普通商品不进这队列。不写接口路径、字段名。

## 给谁看

开发交接审核台。细则在《商品类目与审核》；泳道见同夹《在线商城发品与审核-泳道》。

## 关键规则

- 挂叶子才能送审。未过审不能买。
- 批量逐条独立，失败列出原因。
- 编辑后是否重审：未定，本图不画成已定。

## 图

```mermaid
sequenceDiagram
  actor 供应商
  participant 后台 as 租户后台
  participant 审核台 as 平台审核台
  participant 顾客端 as 众享源品

  供应商->>后台: 选最末叶子，提交送审
  后台-->>供应商: 货变成待审，在线商城的顾客端还不能买

  审核台->>后台: 只拉取在线商城待审，不拉本地生活普通商品
  alt 驳回
    审核台-->>供应商: 不能当在线商城的顾客端在售；草稿保持驳回
    供应商->>后台: 再提交或上架
    后台-->>审核台: 须审的货回到待审
  else 通过
    审核台-->>顾客端: 这件货可售权限落到在线商城的顾客端
    顾客端-->>顾客端: 顾客能看见、能立即购买下未付单
  end

  Note over 供应商,顾客端: 未定：改完已过审的货要不要重新送审，不在本图画死
```

## 不画什么

- 不画本地上架即可售。不写接口路径、字段名、端口、域名。
- 无此路径：本地货进审核台、拼团秒杀进审核台、未过审出现在在线商城的顾客端。
