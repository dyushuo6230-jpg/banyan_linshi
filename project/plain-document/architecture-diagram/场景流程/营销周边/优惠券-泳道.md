# 优惠券-泳道

这张图必须画成两条：店内券只在该店用，平台券只在在线商城的顾客端用。不要汇成一张全场通用券。供应商没有发店铺券的菜单。

## 给谁看

开会讲两类券不能互抵。细则在《优惠券》《钱和券怎么算》。

## 关键规则

- 门槛、叠加、过期未点名的沿用现页，不编满减数字。
- 本轮在线商城的顾客端可以下未付单、不真扣款，券规则仍按两类分开，不要写成没有券。

## 图

```mermaid
flowchart TB
  subgraph 店内券["店内券"]
    direction TB
    aStart((本地店在租户后台发本店券))
    aUse["顾客只在这一家店小程序下单时用"]
    aMoney["钱仍进该店账户"]
    aNoHall["无此路径：拿店内券到在线商城的顾客端抵"]
  end

  subgraph 平台券["平台券"]
    direction TB
    bStart((平台在平台后台发平台券))
    bUse["顾客只在众享源品下单时用"]
    bNoShop["无此路径：拿平台券去某店小程序当店内满减"]
    bSupp["无此路径：在线商城供应商发店铺券"]
  end

  aStart --> aUse --> aMoney --> aNoHall
  bStart --> bUse --> bNoShop
  bUse --> bSupp
```

## 不画什么

- 无此路径：全场一张通用券、给供应商加发券菜单。
- 不编门槛数字。不画端口、域名。
