# 在线商城抽佣结算-泳道

这张图看在线商城的顾客端货的钱怎么分：目标态付给平台，按下单时一级类目快照抽佣，剩余结给供应商。空或 0 快照 = 该新单不抽佣。提现画在本图，不必再拆。本地生活不要画成也能提现。

## 给谁看

开会讲平台代收再结；测试未挂一级不能卖、空费率不是「没挂一级」。细则在《业态经营类目与抽佣》《订单支付与结算》《钱和券怎么算》。

## 关键规则

- 权威在树上的节点快照，不在店铺资料旧抽佣格子。事后改树不改旧单。
- 未挂一级：不可售、不能下单，不要当成按 0 放行。
- 结算从进入已完成起算。不以自营标记筛选。
- 提现按元填，满一千元须再确认。最低额未点名不编造。本轮 C 端未付则还没有可结的已付货款。

## 图

```mermaid
flowchart TB
  subgraph 顾客["顾客"]
    direction TB
    cPay["目标态：顾客向平台付钱<br/>本轮若仍未付，后面结算还走不到"]
  end

  subgraph 计佣["计佣"]
    direction TB
    rHang{"这件货挂上一级了吗？"}
    rNo["不可售、不能下单<br/>不要用缺省费率或 0 抽佣冒充已挂一级放行"]
    rSnap["下单当时拍一张所属一级节点费率快照<br/>店铺旧抽佣格子不再当新单权威"]
    rZero{"快照是空或 0 吗？"}
    rNoFee["这笔新单不抽佣<br/>已挂一级的货仍可卖"]
    rFee["平台按快照抽走佣金<br/>公式见经营类目，本图不写死数字"]
  end

  subgraph 平台["平台"]
    direction TB
    pGet["钱先在平台账户"]
    pSettle["订单已完成且无卡住的售后才纳入结算<br/>剩余结给该供应商"]
    pSelf["无此路径：按自营店规则筛选结算"]
  end

  subgraph 供应商["供应商"]
    direction TB
    sSee["租户打开资金总览 / 结算账单 / 账户流水<br/>给人看用元，明细是一行一行的表"]
    sWd["租户申请提现，按元填<br/>满一千元须再确认"]
    sOk["货款落到供应商<br/>不是本地生活那套对账单"]
  end

  cPay --> rHang
  rHang -->|没挂一级| rNo
  rHang -->|已挂| rSnap --> rZero
  rZero -->|空或 0| rNoFee --> pGet
  rZero -->|有费率| rFee --> pGet
  pGet --> pSettle --> pSelf --> sSee --> sWd --> sOk
```

## 不画什么

- 不画本地线下对账、三套都提现。
- 无此路径：未挂一级按 0 放行、自营口径、本轮把未付单结成已付货款。
- 不写死费率、通道商户号、端口、域名。
