# 本地生活结算对账-泳道

这张图看本地生活抽佣怎么收回来：货款已经进店账户，平台只出对账单，店线下转，财务勾已收。禁止做成假入账去增加可提现余额。本地三套没有提现菜单。

## 给谁看

开会讲「店收了货款、平台怎么拿佣」；测试不能点入账加余额。细则在《订单支付与结算》《业态经营类目与抽佣》《钱和券怎么算》。

## 关键规则

- 对账单范围 = 已完成且没有卡住的售后。本地抽佣看业态根快照。
- 空或 0 快照：该新单不抽佣，仍可进有效订单，只是应付为 0。
- 不接微信分账、不接银行代扣。对公账号本期不入库。账期天数沿用现页，图上不写死。
- 费率死数字不画。

## 图

```mermaid
flowchart TB
  subgraph 店["本地生活店"]
    direction TB
    sStart((店里已有已付成交<br/>钱早就进该店账户，不是平台代收))
    sDone["出餐或核销成功，订单已完成<br/>没有卡住的售后才算有效"]
    sBill["租户打开结算账单只读<br/>看见应付佣金，不是「平台再付给店的净额」"]
    sPay["店按账单线下转给平台"]
    sNoWd["无此路径：本地生活资金总览 / 提现 / 银行卡<br/>不要画成三套都能提现"]
  end

  subgraph 对账["对账"]
    direction TB
    bValid{"是已完成、且没有待处理售后吗？"}
    bSkip["不算有效订单<br/>进不了对账单"]
    bSum["按该店业态根、下单时快照累计应付佣金<br/>空或 0 快照这一笔不抽佣"]
    bFake["无此路径：点确认入账增加可提现余额"]
    bWait["未转账就保持未收"]
  end

  subgraph 平台财务["平台财务"]
    direction TB
    pSee["平台打开结算办理<br/>只核销已收，不替店做分账"]
    pMark{"店的钱转到了吗？"}
    pYes["勾已收<br/>租户再看账单是已收"]
    pNo["仍未收<br/>不编造自动停店"]
  end

  sStart --> sDone --> bValid
  bValid -->|不是有效订单| bSkip
  bValid -->|是| bSum --> sBill --> sNoWd --> sPay --> bFake --> bWait --> pSee --> pMark
  pMark -->|已转| pYes
  pMark -->|未转| pNo
```

## 不画什么

- 不画商城抽佣结算、在线商城的顾客端提现。
- 无此路径：假入账、微信分账、银行代扣、本地提现菜单、自动停店。
- 不写死费率、账期天数、对公账号、端口、域名。
