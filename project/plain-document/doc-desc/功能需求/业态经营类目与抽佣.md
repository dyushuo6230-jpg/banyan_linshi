# 业态经营类目与抽佣

平台用一棵树管「能入驻哪种店」和「新单抽多少佣」。不是四个互不相干的产品，也不是到店本身再登记成第五种业态。

## 谁用、在哪一端

- **平台后台**：运营打开经营类目相关页，维护业态根、入驻是否可选、节点费率、启停。租户不能自己发明一种业态。
- **租户入驻 H5**：申请人只能看见「入驻可选」开着的根。
- **租户后台 · 在线商城**：发品时挂平台类目叶子；计佣仍看这件货所属一级，不在本篇重写发品步骤。
- **不用人点**：顾客下单当时，系统按节点拍一张抽佣快照。

## 主路径怎么走

1. 平台先有种子四根：餐饮、美发、商超、在线商城。本地生活这一侧还可以新增根；新根只能从餐饮、美发、商超里拷菜单和履约，不发明第四种到店做法。种子四根不能删。新根本来默认不开放入驻。
2. 申请人在入驻页选一个开着的根。在线商城还要选 1～3 个启用中的一级，只表示以后能卖哪些，不把几个费率平均成「本店一个数」。
3. 店开起来之后：本地生活抽佣看**业态根**；在线商城抽佣看商品所属**平台类目一级**。发品必须挂叶子，计佣仍向上取这一级。经营类目不再往下挂子节点。
4. 新单用下单当时的节点费率快照。店铺资料里那个旧抽佣格子不再当新单权威。

## 关键规则

- 「到店」是履约方式，不要登记成业态根。
- 老店还没有业态的，按餐饮。
- 节点费率为空或写成 0：这笔新单**不抽佣**；已经挂上一级的货仍可卖。
- 商品还没挂上一级：**不可售、不能下单**。不要把它当成「按 0 抽」放行。
- 一级或类目停用后：已上架的不能再卖；已经打下的单，快照不动。店内分类停用，同样不可再售。再启用后，仍上架且（商城）已过审的可以再卖。
- 费率死数字、类目正式名单：**未定**，不编。

## 会变成什么

- 店绑定一个业态。本地生活 = 全部不是在线商城的根（含以后新增的）。
- 每笔新单带着当时的抽佣快照，事后改树不改旧单。
- 未挂一级的商城货：在线商城的顾客端看不见可买，下单要失败。

## 明确不做 / 未定

- 不发明第四种履约。
- 不把多个一级的费率平均到店铺。
- 不编造根上的死数字和类目名单。

## 和谁交接

入驻选根、商品挂类目、订单怎么抽，都指向本篇，不要在那三篇里再写一套互相打架的抽佣。菜单长什么样见分端；履约扫桌还是核销见《本地生活怎么履约》。

## 落在哪一端

平台改树；入驻页只读开着的根；商城发品挂叶子；抽佣结果出现在订单和结算里，不出现在顾客点单按钮上。
