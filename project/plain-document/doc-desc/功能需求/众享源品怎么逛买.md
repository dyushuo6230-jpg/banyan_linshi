# 众享源品怎么逛买

众享源品是多供应商的在线商城的顾客端，不是某店小程序。货来自在线商城业态、已经平台审过的商品。供应商没有独立小程序可给顾客装。

现用页上已经出现的能力，必须接到在线商城自己的接口并能办完，或按已确认的表藏掉。可以没货、可以空态，不能只弹一句提示当交差。

## 谁用、在哪一端

- **众享源品 · 顾客**：打开在线商城的顾客端（手机、小程序、H5 同一套）。可先逛；下单、支付须登录。在「我的」能看见已登录，不强制绑微信。
- **租户后台 · 在线商城**：发品送审、接单、详情里发货。侧栏没有内容轮播。可报秒杀、拼团、板块。
- **平台后台**：审品、平台券、在线商城的顾客端设置、开活动场、审报名、管板块。购物首页轮播只读平台配的那一套；没数据就不要轮，不要拿一张静图冒充已经接上。附近顶上的灯片走板块子列表，不是购物首页那套。
- **本地生活顾客**：不走本篇。店内号不能直接当在线商城的顾客端会员。

## 主路径怎么走

1. 看首页轮播（有数据才轮）和已过审的货。分类对接平台类目：点一级铺二级，点二级铺三级。
2. 两套列表：板块里的货走没有搜索框的列表；分类和搜索走带搜索框的列表。
3. 进电商详情。立即购买可选规格，走出未付单。加入购物车写入购物车；购物车可改数量、结算进未付单。底栏在购物和加购之间加收藏：空心加「收藏」/ 红实心加「已收藏」，再点取消。店详情不加收藏。四钮间距相等。
4. 详情评价区：能看见已经交上去的评价；只有对该商品有已完成订单的人，才能从详情去写。
5. 未付订单列表/详情能看见还剩多久；到期打开或去支付，立刻变成已取消，不能再付。
6. 本轮点支付：按钮还在，不调起真通道，单子保持未付。购物车、订单继续用旧页，不卡像素。
7. 「我的」不藏门店入驻、供应商入驻，点了提示敬请期待；真开店、当供应商先走入驻页。隐藏个人主页。余额/消费券/金豆留三格，点了提示，不做真金豆账户。待评价只进已完成且未评的单，不当订单主状态。足迹、收藏用没有搜索框的商品列表。银行卡、全民推广、官方公告、联系客服点了提示。设置可进，隐藏切换语言。订单里回首页，进的是在线商城的顾客端首页。
8. 底部四栏：购物 / 附近 / AI助手 / 我的。没有发现。AI 整页假页，视频、生图子页本批不做。
9. 附近：去掉静态坑，列表是本地生活租户。点店进本地生活店详情，点货进电商详情。本期不拉起店小程序。搜索按业态筛，点店进店详情。CPS「美团外卖」到「更多」两行本页轮播，不删。店详情顶图、介绍图、按业态提示见店档案；本袋不算距离、不导航。
10. 首页快捷：好友助力藏掉。限时折扣点进商城秒杀列表。品牌联盟点进「超级品牌」板块；平台没配这个板块就把联盟入口藏掉。

有设计图的现用页按图还原。没有设计图的不卡像素。

## 关键规则

- 未过审不能买。
- 用平台券，不用某供应商的店内券。
- 附近筛的是**当前全部本地业态根**（平台级），跟某供应商有没有勾选无关。CPS 不把某供应商塞进跳转。细则在《周边与到店服务》。
- 协议读在线商城的顾客端自己的，不要套本地生活那份。
- 地址用现成的用户地址，不加第二张地址表。
- 推荐：平台推荐和店铺推荐分开。店铺把自己货推进店内推荐，不影响在线商城的顾客端货池。
- 顾客端订单口语可以用待发货 / 待收货；不要出现待评价主状态。已完成可评、不可新申请售后。
- 审过的商城秒杀、拼团，顾客能进、能下未付单。到期没成团关未付单。专篇见《拼团与秒杀》。
- 模块按板块标识取当前板块内容。专篇见《平台运营与现码保留》。

## 会变成什么

未付单可存在。本轮不应变成已付。以后真扣到账：已付待履约 → 履约中 → 确认收货即已完成。

## 明确不做 / 未定

- 发现业务。
- AI 接真业务；视频、生图子页。
- 本轮真扣款、微信小程序支付（本轮登录也不绑微信身份去付）。
- 拉起店小程序。
- 助力业务、独立限时折扣规则。
- 浏览要不要强制登录：资料没写死 → 待配置；下单须登录是已确认。
- 库存不足怎么提示：现码没重写则待配置，不编超卖策略。

## 和谁交接

审品见《商品类目与审核》。钱和未付见《订单支付与结算》。账号分池见《用户账号与用户池》。登录见《登录会话与口令》。活动见《拼团与秒杀》。板块见《平台运营与现码保留》。

## 落在哪一端

顾客只在在线商城的顾客端看见逛和未付；供应商只在网页后台看见送审、发货和报名。不要把在线商城的顾客端接到店内接口或租户后台。
