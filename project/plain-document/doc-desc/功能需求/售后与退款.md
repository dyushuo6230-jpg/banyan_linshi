# 售后与退款

售后只办理已确认的那一段：已付还没完成的整单。平台只看不办。部分退、退货物流本期没有这条路。支付主状态、倒计时仍以《订单支付与结算》为准，本篇不重写。

## 谁用、在哪一端

- **众享营销 - 本地生活 · 顾客**：在**现用**订单页申请。仅已付待履约可以申请（美发/商超这时显示待核销）。已完成、已取消、已关闭不能新申请。
- **众享源品 · 顾客**：在订单或售后页申请。仅已付待履约、履约中可以申请。售后页不填退货物流。
- **租户后台**：待处理时只能整单全额退或拒绝。没有「确认收到退货 / 拒绝收货」。有待处理售后时，不能再出餐、核销、发货、确认收货。
- **平台后台**：订单管理 → 售后管理只读。页签是全部 / 待处理 / 已退款 / 已拒绝 / 已撤销，没有「平台介入中」。没有同意、拒绝、仲裁按钮。首页待办没有「平台介入售后」。

## 主路径怎么走

1. 顾客在允许的状态下提交售后。待处理时顾客可以撤销。
2. 租户全额退 → 订单已关闭。本地生活该单核销码不能再核，不补第二张主码。
3. 租户拒绝 → 订单主状态不变，顾客不能再当「平台已经介入」去催。
4. 已完成只能评价，不能新开售后。

## 关键规则

- 整单全额退。不要走只退一部分金额。
- 以后若要超管代退，须另作决定，本期没有这个办理口。
- 给人看的金额用元。

## 会变成什么

人看见的是：申请入口只在未完成的已付单上；退完码失效、单子已关闭；平台列表能查，不能点办理。

## 明确不做 / 未定

- 部分退、退货寄回、填物流。
- 平台仲裁、支持用户/支持租户。
- 退款通道细节沿用现页，不编新状态机。

## 和谁交接

主状态、未付关单见《订单支付与结算》。核销码作废见《本地生活怎么履约》。在线商城的顾客端本轮未付本来就不能申请售后。真评价在已完成之后，见逛买和履约篇。

## 落在哪一端

顾客在小程序或在线商城的顾客端订单里申请；租户在租户后台办退或拒绝；平台只能打开列表看。
