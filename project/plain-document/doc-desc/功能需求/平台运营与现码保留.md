# 平台运营与现码保留

这一篇只说明平台还留着什么、本期验什么。不要写成和入驻同等厚度，也不要把未定编成新功能。

## 谁用、在哪一端

- **平台后台**：轮播、两套协议、首页模块归属、周边 CPS 目录、通道用量、板块列表和板块内容、商城秒杀/拼团场次和报名审核。没有周边分类管理，没有已删的秒杀管理/拼团审核。
- **众享源品 · 顾客**：购物首页轮播只读平台配的那一套接口图。没数据就不轮，不要拿一张静图冒充已经接上。不强制运营必须先配图才能验收。附近顶上的灯片走板块子列表。模块按板块标识取当前内容。
- **众享营销 - 本地生活**：首页轮播仍走店内装修，不以平台那张表为准。模块按「首页模块归属」过滤，细则在《本地生活怎么履约》。
- **在线商城供应商**：侧栏没有内容管理 → 轮播。一级有板块报名。
- **本地生活租户**：没有板块报名。

## 要保留、本期怎么验

- **平台轮播菜单和表保留。** 在线商城的顾客端**购物首页**改读这一套。店铺轮播、周边轮播、平台轮播、板块子列表不是同一批图。
- **协议分两套维护**：本地生活一份，众享源品一份。在线商城的顾客端打开服务协议/隐私政策，读在线商城的顾客端自己的。
- **首页模块归属**：平台能配，本地生活一套首页按归属过滤。本页增加拼团、秒杀两种，默认通用（全部本地根，新根自动纳入）。不并进活动三坑。没有进行中的活动就空着。除此两行外不增删其它种类。在线商城无装修、不进这页。
- **板块**：可新增，标识用英文数字。类型商品或子列表。商品型：只有已审通过的在线商城货能申请，平台审过才上架。子列表：平台自配。跳转可以是电商详情、带搜索框的搜索结果、另一个已启用板块、https 外链。不是 https 不能保存。手机 App / H5 用系统浏览器打开外链。微信小程序复制链接并提示去 App 或浏览器，小程序里仍展示这条。不编造域名白名单。板块本批不改支付方式，通道仍跟平台。
- **报名**：租户下一页勾货，跨页还留着，本页可全选，每批最多 30。失败后再提交改回待审。
- **通道用量**：平台数据统计下有这项入口（点名有）。参数配置里支付、商城字段清单**未定**，不编清单。
- **无自营店。** 身份只看业态。筛选、结算不要按自营标记。

## 现码保留、不纳入必验

- **小魔推**：代码和小程序页不拆、不删。四套租户侧栏都隐藏。多业态主路径验收不以完整小魔推为必验。误改坏了按回归修，不要改成「本期必须交付小魔推」。本地生活现状：顾客扫店码，进中间页登录或注册，本店设备一人一机，通过后才出该店推广链。开通没有合法渠道，人能看见失败。密码错不注册；注册或绑设备失败不出推广链。中间页具体网址、密码最少几位、对接密钥**未定**，不编。众享源品在线商城的顾客端不应有这条入口，不要写成在线商城的顾客端也能扫码进小魔推。
- **推广员**：现码推广和入驻注入还在，方案没要求拆掉，也没定义改造成什么样。佣金、等级、结算**不编**。不是「本期重做推广体系」。全业态仍走同一套入驻页。

## 明确不做 / 未定

- 不把已删的周边分类、秒杀管理、拼团审核写回侧栏。
- 不为在线商城的顾客端再建一个根菜单专门放轮播。
- 不为众享源品新做小魔推或扫码进店。
- 板块不是首页模块归属，也不是 ToB 那套轮播/入口/分类/产品。
- 不按板块拆支付通道。
- 其余资料没点名的运营能力，不编造成功能。
- 量化运营指标未给：未定。

## 和谁交接

CPS 目录规则见《周边与到店服务》。在线商城的顾客端读图、报名后的露出见《众享源品怎么逛买》。菜单隐藏见《租户后台与菜单》。商城活动见《拼团与秒杀》。

## 落在哪一端

运营配置在平台后台。顾客分别在在线商城的顾客端或店内看见轮播、板块和协议。推广员、小魔推侧栏可以看不见，代码还在，不当作本期新功能验收。扫码进店只在本地生活店里讲；在线商城的顾客端不写这个入口。
