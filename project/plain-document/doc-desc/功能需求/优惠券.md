# 优惠券

店内券和平台券是两类生意，不是一张全场通用券。本地生活各店自己发、只在本店用；众享源品只用平台发的券。

## 谁用、在哪一端

- **租户后台 · 餐饮/美发/商超**：店发本店券。顾客只能在这家店的小程序里用。
- **租户后台 · 在线商城**：没有发店铺券的菜单。供应商不要在这里找「本店优惠券」。
- **平台后台**：发、管平台券。在线商城顾客用这一类。
- **众享营销 - 本地生活 · 顾客**：下单时用该店发出的券。
- **众享源品 · 顾客**：只用平台券，不能拿某家店的店内券到在线商城的顾客端抵。

## 主路径怎么走

1. 本地店在租户后台发券、设本店能用。顾客在该店小程序选券下单，钱仍进该店。
2. 平台在平台后台发平台券。在线商城顾客下单时用平台券。本轮在线商城的顾客端可以下未付单、不真扣款，券规则仍按两类分开，不要写成「本轮没有券」。
3. 两类券不能互相当可用：店内券进不了在线商城的顾客端；平台券不能拿去某店小程序当店内满减。

## 关键规则

- 供应商不发店铺券。
- 门槛、叠加、过期、是否可与活动同用：资料没点名的，**沿用现页**，不编造「满多少减多少」。
- 抽佣怎么算见《业态经营类目与抽佣》，本篇不重写。

## 会变成什么

顾客看见的是：这家店有店内券，在线商城的顾客端有平台券。用错地方，券不可用，订单不能按另一类券的优惠成交。

## 明确不做 / 未定

- 不做成全场一张通用券。
- 不给供应商加发券菜单。
- 未点名的门槛数字、叠加表：未定。

## 和谁交接

下单付钱见《订单支付与结算》。在线商城的顾客端逛买见《众享源品怎么逛买》。拼团秒杀不是券，见《拼团与秒杀》。

## 落在哪一端

发券在租户后台（仅本地生活）或平台后台；用券在对应那一端的下单页。分端写按钮和表单。
