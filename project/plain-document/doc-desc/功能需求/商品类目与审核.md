# 商品类目与审核

一个商品能力、两种流程。本地生活店内上架即可本店卖；在线商城必须挂平台类目叶子、送平台审核，通过后才出现在众享源品。

## 谁用、在哪一端

- **租户后台 · 餐饮/美发/商超**：商品相关菜单。发品必选**店内分类**，上架后本店小程序可售。可把货推到本店推荐栏。平台不给这些普通商品盖章。
- **租户后台 · 在线商城**：发品挂平台类目**叶子**并送审。店铺分类可以空。店铺推荐开关不能把货推进在线商城顾客端推荐池。
- **平台后台**：商品审核台只办理在线商城的货。批量通过或驳回逐条独立，失败列出原因。不审本地生活普通商品，也不审拼团秒杀。
- **众享源品**：顾客只看见已过审、仍可售的货。

## 主路径怎么走

**本地生活**

1. 店维护店内分类。
2. 发布商品并选分类，上架。
3. 该店小程序按分类可售。平台审核台没有这一单。

**在线商城**

1. 供应商选平台类目叶子（不能只挂在一级或中间层当发品点）。
2. 提交待审。草稿保持驳回；再提交或上架，回到待审。
3. 平台通过后，众享源品可售。驳回后按已确认口径处理，不能当已出现在在线商城的顾客端。
4. 以前挂在非叶子上的存量，可在商品列表里批量改挂到人手选的叶子，一条一条独立，系统不自动猜该挂哪片叶子。

## 关键规则

- 本地生活的货不进众享源品货池。店内推荐只作用于本店小程序。在线商城顾客端的平台推荐和店铺推荐是两条，不要当成一个开关。
- 品牌可以选、不强制。
- 筛选时若选了祖先类目，结果里要含挂在子孙叶子上的货。
- 店内分类或平台类目/一级停用：已上架不可再售，不改商品行，已下单不改快照。
- 未挂一级：不可售。抽佣怎么算见《业态经营类目与抽佣》，本篇不重写公式。
- **编辑后是否要重新送审：未定。** 未定就写未定，不编成「改了必审」或「改了不必审」。

## 会变成什么

- 本地：上架 → 本店可售；下架 → 本店不可售。没有平台待审态。
- 商城：待审 → 通过后在线商城的顾客端可售；驳回不能买。
- 停用类目：顾客端不能再下这件已上架的货。

## 明确不做 / 未定

- 不把审核台拆成两个产品。
- 不把店内分类必选套到供应商。
- 不把本地生活普通商品送进在线商城的顾客端。
- 通知文案资料没写死的，待配置。
- 本期测试可以清库，不当作生产已如此。

## 和谁交接

抽佣、未挂一级见《业态经营类目与抽佣》。在线商城的顾客端怎么逛见《众享源品怎么逛买》。履约不在本篇。菜单树见分端。

## 落在哪一端

发品在租户后台；盖章在平台审核台；顾客分别在店内小程序或众享源品看见能不能买。
