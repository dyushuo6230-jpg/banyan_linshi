# 租户入驻与审核

所有业态走**同一套入驻页**。平台审过之后，这家店进同一套租户后台，侧栏按业态套菜单。没有「是否自营」这一问。

## 谁用、在哪一端

- **租户入驻 H5**：还没通过的申请人打开入驻页，选业态、交执照。在线商城还要选一级类目。
- **平台后台**：运营从入驻审核打开待审单，通过或驳回。存量待审如果当年没选业态，通过前要补选，系统不猜。
- **租户后台**：通过之后才能进。套哪套菜单，跟审过的业态走。

## 主路径怎么走

1. 申请人拿到有效入驻资格，打开同一套入驻页。
2. 选一个「入驻可选」开着的根。本地生活不选下级类目。在线商城必须选 1～3 个**启用中**的一级。
3. 执照沿用现在这套入驻页上的执照，不另发明一套资质表单。
4. 提交后待审。平台通过 → 按该业态套租户菜单，申请人以后从租户后台进。驳回 → 不能改原单再送，只能提一份新的重新待审。
5. 同一个手机：已经待审或已经通过，不能再提一份。凭证过期或无效：提交不了，须重新取得入驻资格。

## 关键规则

- 以后新增的本地根，只要入驻可选开着，也走这套页，不拆第二套入驻产品。
- 没有对应菜单模板的业态，不能审核通过。
- 平台不自己开自营店，入驻不问自营。
- 在线商城入驻时选的一级，过审后供应商不能自己改；一级停用后绑定留下，发品能不能卖看《商品类目与审核》和《业态经营类目与抽佣》。

## 会变成什么

- 通过：店有业态、有菜单模板，可以发品、接单。
- 待审/已通过：该手机不能再交一份入驻。
- 驳回：原单结束，新单重新排队。

## 明确不做 / 未定

- 不按业态做四套入驻产品。
- 不把「到店」做成一种可选项。
- 入驻票里不要带着手机号给前端乱传（细则在《登录会话与口令》）。
- 推广场景怎么进来，沿用现页，不编新获客流程。

## 和谁交接

套哪套菜单的细则见以后的《租户后台与菜单》。抽佣和一级可售范围见《业态经营类目与抽佣》。店员出餐不在入驻页。

## 落在哪一端

申请人只在入驻 H5；审核只在平台后台；通过后的日常经营在租户后台。顾客端看不见入驻审核过程。
