# 众享源品 - 在线商城

多供应商在线商城的顾客端。手机、小程序、H5 同一套，只调在线商城自己的服务。供应商没有独立小程序可给顾客装。

现用页已经出现的能力，必须接到在线商城自己的接口并能办完，或按已确认的表藏掉。可以没货、可以空态。本轮不真扣款，支付按钮还在。可以加购、可以下未付单。这不等于已经真扣到账。后台货源、审品、订单、结算要能闭口。

规则见《众享源品怎么逛买》《订单支付与结算》。协议读在线商城的顾客端自己的，不要套本地生活那份。

## 底部栏实际露出什么

现用购物页、「我的」用在线商城顾客端自己的底部组件，四栏：**购物 / 附近 / AI助手 / 我的**。没有发现。AI 整页假页，视频、生图子页本批不做。

工程里还有一套原生占位底栏和装修下发的旧底栏，现用购物 / 我的不拿它们当顾客看见的默认入口。

## 购物（首页）

现用首页。顶栏：首页 / 特价 / 新品，以及购物车、搜索。轮播只渲染平台配的 banner；没数据就不轮，不用店铺轮播、不用一张静图冒充已经接上。

分类对接平台类目：点一级铺二级，点二级铺三级。两套列表：板块里的货走没有搜索框的列表；分类和搜索走带搜索框的列表。点商品进**现用商品详情**，不是静态复刻详情页。

快捷：好友助力藏掉。限时折扣点进商城秒杀列表。品牌联盟点进「超级品牌」板块；平台没配这个板块就把联盟入口藏掉。

有设计图的现用页按图还原。购物车、订单继续用旧页，不卡像素。没有设计图的页（含商城拼团秒杀自编页、AI 假页）不卡像素。

#### 细点

- 轮播接口是平台那一套。
- 回首页进这一页，不要进旧首页。
- 浏览要不要强制登录：资料没写死 → **未定**；下单须登录。
- 模块按板块标识取当前板块内容。

## 搜索 / 分类 / 商品列表

搜索、分类列表接平台类目。库存不足怎么提示：现码没重写则 **待配置**。

## 商品详情（现用）

已审可售才当在售。未过审、未挂一级、类目停用：不可售。

立即购买：弹出规格，确认后走进待支付 / 未付单。加入购物车写入购物车。底栏在购物和加购之间加收藏：空心加「收藏」/ 红实心加「已收藏」，再点取消。店详情不加收藏。四钮间距相等。

评价区：能看见已经交上去的真评价。只有对该商品有已完成订单的人，才能从详情去写。不是假数据。

#### 细点

- 点立即购买可选规格下未付单。
- 点加入购物车写入购物车，不要弹敬请期待。
- 回首页进众享源品现用首页。
- 配送信息等未点名能力：敬请期待或沿用现页，不编成已上线物流详情。

## 购物车

从现用详情加购能进购物车。可改数量、结算进未付单。继续用旧页，不卡像素。

## 下单 / 待支付

可下未付单。地址用现成的用户地址，不加第二张地址表。金额用元。

支付按钮和组件还在。本轮点支付不调起真通道，单子保持未付。

未付倒计时：到期打开列表、详情或去支付，立刻变成已取消，不能再付。后台定时仍会关。

审过的商城秒杀、拼团也能走出未付单。到期没成团关未付单。没有设计图就自编页，不卡像素。

## 订单

「我的」订单入口：待付款 / 待发货 / 待收货 / 评价 / 退款售后。口语页签给顾客看；确认收货即完成，不要出现待评价主状态。已完成可评、不可新申请售后。

列表回首页、待支付页回首页：口径是进现用购物首页。若个别旧跳转还落到旧首页，以现用首页为准，不要把旧页写成在线商城的顾客端主页。

### 售后 / 退款

仅已付待履约、履约中可以申请。本轮未付本来就不能申请售后。部分退、退货物流本期无此路径。售后页不填退货物流。平台不办售后。见《售后与退款》。

## 评价

已完成订单可写。详情展示真评价。已完成评完仍是已完成。

## 我的

现用「我的」。未登录显示「登录/注册」；登录后显示昵称和打码手机，能看出已登录。不强制绑微信。H5 同样要能登上去。

订单宫格：待付款、待发货、待收货、评价、退款/售后。点进须登录。

#### 本轮隐藏或敬请期待

- 不藏门店入驻、供应商入驻，点了提示敬请期待；真开店、当供应商先走入驻页。隐藏个人主页。
- 余额 / 消费券 / 金豆留三格，点了提示，不做真金豆账户。
- 我的收藏、我的足迹：用没有搜索框的商品列表。
- 银行卡、全民推广、官方公告、联系客服：点进敬请期待。
- 个人设置可进。设置里隐藏切换语言。
- 不应有小魔推扫码进店入口。工程里若还挂着，不是已经批准的在线商城的顾客端能力，本期不写、不必验。

## 登录 / 注册 / 找回密码

独立账号池。从「我的」点登录走进来。短信登录或账号密码。先填 11 位手机，同意《用户协议》《隐私协议》（读众享源品协议），再走短信或改走密码登录。

不强制绑微信。在线商城的顾客端登录态作废不影响店内票。忙不踢、闲必踢、退出立刻作废。见《登录会话与口令》《用户账号与用户池》。

## 附近

底部有附近。去掉静态坑，列表是本地生活租户。点店进本地生活店详情，点货进电商详情。本期不拉起店小程序。搜索按业态筛，点店进店详情。CPS「美团外卖」到「更多」两行本页轮播，不删。附近顶上的灯片走板块子列表，不是购物首页那套轮播。

店详情吃老板在「店铺」填的档案：顶图、介绍组图（最多 9 张，可点开轮播）、带行政区的地址、营业说明弹层。餐饮提示「支持到店消费」；美发/商超提示「支持到店消费和到店核销」。开业 30 天内列表打招新开业。本袋不算离你多远、不写驾车几分钟、不打开地图导航。让利、积分、共益分发那几句先不展示。

筛的是当前全部本地业态根（平台级），跟某供应商有没有勾选无关。CPS 不把某个供应商塞进跳转。细则在《周边与到店服务》。

## AI 助手 / 发现

底部有 AI助手，整页假页。视频、生图子页本批不做。没有发现入口，不对接发现业务。

## 现码有、不写成本期商城功能的

积分商城、发票全套、新人专区、静态分类 / 详情复刻、入驻表单、管理端「我的」旧页、旧首页、小魔推扫码进店、发现业务。
