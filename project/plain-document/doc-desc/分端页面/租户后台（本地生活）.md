## 登录

网页登录。会话规则同平台：忙不踢、闲必踢、退出或改密立刻作废。子账号跟同一套口令规则。登录框不要写死账号密码，也不要浏览器自动填。权限细节未点名则沿用现页。租户登录失败锁定次数：**未定**。细则在《登录会话与口令》。

## 工作台

经营概览。不是发品、不是核销主入口。

## 商品

本地普通商品：挂店内分类、上架即可本店可售，平台不审。分类停用后不可再售，不改商品行。本地货不进众享源品货池。可把货推到本店推荐栏，只作用于本店小程序。

### 商品列表 / 发布商品 / 库存管理 / 店铺分类 / 评价管理

商品列表、库存、店铺分类、评价：有这些页，沿用现页。分类必选才能作为可售。

#### 发布商品表单要点

三步：基础信息 → 规格价格 → 详情。金额填**元**。

| 项 | 怎么填 |
|---|---|
| 商品名称 | 必填 |
| 店铺分类 | 必选。不要求平台类目 |
| 主图 | 必传 |
| 售价 | 必填，元 |
| 库存 | 必填 |
| 规格 | 可单规格 / 多规格 |
| 副标题、划线价、成本、详情、营销标签 | 沿用现页，不强制 |

未选分类不能当作可售上架。提交后本店小程序可卖，不进平台商品审核台。

## 订单

### 订单列表 / 订单详情

看本店单。书面语页签：待付款 / 已付待履约 / 履约中 / 已完成 / 已取消 / 已关闭。不要出现待发货、待收货当后台页签。金额用元。

美发 / 商超可核销码核销，整单一次。餐饮出餐 / 确认完成。未付倒计时；超时打开即关单，到点不能再付。有待处理售后时，不能再出餐、核销。

顾客端出餐/核销主入口在店内小程序，见《众享营销-本地生活》。

### 预约订单

仅餐饮。还受首页模块归属约束：预约默认只对餐饮开。美发 / 商超侧栏无此项。

### 售后

待处理时只能整单全额退或拒绝。部分退、退货物流本期无此路径。见《售后与退款》。

## 营销

### 店铺优惠券

仅本店顾客用。众享源品不用店内券。细则在《优惠券》。未点名字段沿用现页。

### 秒杀 / 拼团

仅本地生活。租户自建自上下架。平台不审、不经营场次。停用后不能新参。拼团不另出核销码，成交仍走同一套核销或扫桌。见《拼团与秒杀》。

## 财务

### 结算账单

佣金对账。无资金总览 / 提现 / 银行卡。本地佣金禁止假入账。给人看用元。

## 数据统计

### 交易统计 / 通道用量

交易统计沿用现页。通道用量仅本地三套有。不编造指标清单。

## 店铺

### 店铺 / 员工 / 角色 / 支付 / 短信 / OSS

店名只读。可配小程序 AppID、码、进店 Scheme。AppID、密钥、支付密钥框声明不要浏览器自动填。员工 / 角色仅本地生活。支付进件、OSS、短信有菜单，沿用现页。无 WiFi。

本地生活这一页还要能填省市区、详细地址、经纬度、详情顶图、介绍组图（最多 9 张）、营业说明。改地址后由租户后台服务端推出坐标，仍可手改。不新开侧栏。细则在《众享源品怎么逛买》附近店详情和 DEC-073。在线商城仍只有「店铺资料」。

## 桌台

仅餐饮。无桌、桌号无效，顾客不能按这张桌下单。美发 / 商超无此菜单。

## 装修

### 模板配置 / 底部导航 / 页面路径

本店首页轮播只在装修里配。侧栏没有「内容管理 → 轮播」。底部 Tab 由该店装修配置，2～5 项，细则未点名的沿用现页。首页按归属可以出拼团、秒杀坑，没有进行中的活动就空着。在线商城无装修。

## 周边管理

### 周边轮播图 / 周边CPS

CPS 只能上下架平台目录项，不能自建目录。店内附近按**本店已勾本地业态**筛，细则在《周边与到店服务》。

## 会员管理 / 消息中心

有此菜单，沿用现页。不是本期闭口主链。
