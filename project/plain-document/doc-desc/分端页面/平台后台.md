# 平台后台

给平台运营用的网页。侧栏审店、配业态树和商户菜单、只审在线商城的货、管平台券和财务。可开商城秒杀/拼团场、审报名、管板块。不审本地生活普通商品，也不审本地生活店自己发的拼团秒杀。

没有「设为自营」。已删的秒杀管理、拼团审核、周边分类，不要在说明书里写回来。新菜单不是旧入口换皮。小魔推不在这一端验收。

规则只点到：抽佣见《业态经营类目与抽佣》；套菜单见《租户后台与菜单》；审品见《商品类目与审核》；售后只读见《售后与退款》。

## 登录

网页登录。平台运营从登录页进。

持续点选、保存，不会无故被踢。停手超过闲置必须重登。退出或改密后，旧登录立刻作废。同一账号在别处再登，旧的那一段立刻作废。不要求短信二次验证。登录页账号、密码框都不写死，也不要浏览器自动填，不要「记住密码」。超管登录名是 `ZadminDister`，填 `admin` 登不上。首次登录（含超管）要改密。列表和详情永远不要展示可登录的明文密码。细则在《登录会话与口令》。

非超管管理员必须至少有一个角色才能保存。每次请求按当时库里的角色授权，不能靠登录那一刻记住的旧身份。超级管理员只属于 `ZadminDister`。别人选角色看不到「超级管理员」。给运营勾权限时，看不到管理员、角色管理、菜单管理、API 管理；直访这四页也会被拦。系统管理里参数、快递、日志仍可给运营。细则在《登录会话与口令》。

## 仪表盘

看今日概览、待办、趋势。不是本期业务验收主链。首页待办没有「平台介入售后」。

## 商户管理

管入驻、已开业租户、业态树、租户菜单模板、店内首页模块归属。

### 入驻审核

平台运营从侧栏「商户管理 → 入驻审核」进来。页签：待审核 / 已通过 / 已驳回。可按店铺名、手机号搜。

待审单点「审核」打开办理；已通过、已驳回点「详情」只看。通过后按该业态套该店菜单。待审或已通过的同一手机不能再提；驳回只能提新单。没有菜单模板的业态不能点通过。

#### 审核时要看什么

| 看什么 | 说明 |
|---|---|
| 店铺名 | 申请人填的店名 |
| 业态 | 必须有。存量待审当年没选业态时，通过前必须在本页补选，系统不猜 |
| 可售一级 | 仅在线商城。须 1～3 个启用中的一级。本地生活显示「本地生活不选一级」 |
| 执照图 | 能打开看 |
| 识别结果 | 识别成功 / 无识别结果；企业名称、法人、住所等沿用现页 |
| 联系人 / 电话 | 展示 |
| 推广员 | 有则展示，本期不改造推广体系 |
| 驳回原因 | 点驳回时填写。已驳回详情里能看见 |

没有「是否自营」。抽佣数字不在审核弹窗里编一栏权威费率。

### 商户列表

已开业租户。可冻可解冻、可关闭。无「设为自营」。

本地店可勾「周边业态」：决定店内附近按哪些本地根筛。在线商城不设周边。抽佣列只展示「按业态根 / 按一级」，权威费率在经营类目节点上，见《业态经营类目与抽佣》。

小程序列：本地店看有没有绑 AppID；在线商城显示走众享源品，不要求供应商自己有小程序。支付列：本地看该店有没有配收款；在线商城是平台收款。

### 经营类目

侧栏「商户管理 → 经营类目」。一棵树。

种子根：餐饮、美发、商超、在线商城，不可删。可新增本地根；拷贝源只能是餐饮（扫桌）或美发/商超（核销）。新根默认不开放入驻。无店、无待审的新根可删。

入驻可选开关：关掉的根，入驻页看不见。本地抽佣看业态根；在线商城经营类目不再挂子节点，只给对应一级配费率。空或 0 表示新单不抽佣。未配置的费率数字不编造。停用一级或节点后，已上架不可再售，不改商品行，已下单不改快照。

历史扁平类目只读兼容，不再作入驻主数据。

#### 和平台类目的关系

在线商城发品树、计佣一级，和「商品管理 → 平台类目」是同一套。这边改的是费率、排序、入驻开关，名称以平台类目为准。

### 商户菜单

同一页切换业态改模板。页顶切换餐饮 / 美发 / 商超 / 在线商城（以及以后新增的本地根页签）。新本地根会多一个从拷贝源克隆出来的页签。

「无」= 该业态没有这一行，删掉，不是藏起来。小魔推是隐藏不是删除：侧栏看不见，隐藏不是权限边界，直访旧页仍要按权限拦。租户不能自己改平台模板定义。改完之后租户要不要重登才看见新侧栏：**未定**。

### 首页模块归属

决定本地生活一套首页里，哪些模块通用、哪些按业态开。本页增加拼团、秒杀两种，默认通用（全部本地根，新根自动纳入）。不并进活动三坑。除此两行外不增删其它种类。

- 通用：当前全部本地业态，以后新增的本地根自动纳入。
- 自定义：只对勾选的业态生效，新根不会自动勾。

预约默认仅餐饮；本店服务默认餐饮+美发。在线商城无独立小程序，不走这页。「我的」页不走本表。

## 商品管理

平台类目、品牌、只审在线商城商品、全站商品列表、评价。不审本地生活普通商品，也不审本地生活店自己发的拼团秒杀。商城活动报名另走营销里的审核，不混进商品审核台。

### 平台类目

树可改。发品必须挂到叶子；计佣仍取该叶子所属一级。停用一级或节点后，已上架不可再售，不改商品行，已下单不改快照。筛选选中祖先时，结果须含挂在子孙叶子上的货。

### 品牌管理

品牌库保留。发品可选，不强制。未点名字段沿用现页。

### 商品审核

只办理在线商城送审。页签：待审核 / 已驳回。可单条或批量通过 / 驳回；批量逐条独立，失败列出原因。价格给人看用元。通过后众享源品可售。本地生活普通商品不出现在待审办理范围。

编辑后是否要重新送审：**未定**，本页不编成「改了必审」或「改了不必审」。通知文案未点名则沿用现页。

### 商品列表

平台侧查看，不是供应商发品页。金额用元。

### 评价管理

看评价、改显示状态。众享源品详情展示已提交的真评价，不在这页编评价。

## 用户管理

### 用户列表

现码一个用户列表。业务上已分「店内池」和「众享源品池」。是否拆成两个菜单：**未定**。本页不编造成已经拆开。

## 订单管理

平台看单、看售后。售后只读，没有「平台介入中」、没有仲裁办理。金额给人看用元。状态书面语与订单主状态对齐：待付款 / 已付待履约 / 履约中 / 已完成 / 已取消 / 已关闭。没有中间「待评价」主状态。确认收货即完成。细则在《订单支付与结算》。

### 订单列表

筛选、详情。列用来源、履约方式。在线商城的顾客端本轮未付单可以存在，不要把它当成已经扣到账。

### 售后管理

看售后单。页签沿用现页：全部 / 待处理 / 已退款 / 已拒绝 / 已撤销。没有同意、拒绝、仲裁按钮。部分退、退货物流本期无此路径。

## 营销管理

平台优惠券还在。没有已删的秒杀管理、拼团审核。另有商城秒杀、商城拼团。

### 平台优惠券

众享源品用平台券。供应商不发店铺券。店内券和平台券不是一张，细则在《优惠券》。未点名字段沿用现页。

### 商城秒杀 / 商城拼团

平台创建场次。供应商用已审货报名后，本页审。通过后在线商城的顾客端可见可买。不拿这套去管本地生活店内活动。到期没成团关未付单。细则在《拼团与秒杀》。

## 内容管理

轮播、公告、两套协议、板块。众享源品购物首页只读平台轮播；没数据就不轮，不用静图冒充。附近顶上的灯片走板块子列表，不是这一套。店内首页轮播不走这里。

### 轮播管理

平台 banner。众享源品首页读这里。不强制运营必须先配图才能验收其它主链。

### 公告管理

有此菜单，沿用现页。

### 协议管理

本地生活用的用户协议 / 隐私。

### 众享源品 - 在线商城协议

与上一页分开。在线商城的顾客端打开服务协议 / 隐私，读这一套，不要套本地生活那份。

### 板块

可新增，标识用英文数字。类型商品或子列表。商品型：只有已审通过的在线商城货能申请，平台审过才上架。子列表：平台自配。跳转可以是电商详情、带搜索框的搜索结果、另一个已启用板块、https 外链。不是 https 不能保存。手机 App / H5 用系统浏览器打开外链。微信小程序复制链接并提示去 App 或浏览器，小程序里仍展示这条。不编造域名白名单。板块本批不改支付方式。细则在《平台运营与现码保留》。

## 市场管理

### 推广员管理

现码保留。本期不改造、不纳入必验。佣金、等级不编。

## 周边管理

无周边分类。只留平台 CPS 目录。店内附近怎么筛、在线商城的顾客端附近怎么筛，见《周边与到店服务》，本页不重写两边规则。

### 周边CPS

平台维护目录。本地店只能引用并上下架。平台下架后，店内和众享源品附近都不再出。在线商城供应商没有周边菜单。

## 财务管理

结算、提现、佣金、流水。本地生活佣金是对账，禁止假入账去增加可提现余额。在线商城按商品一级类目快照抽佣后再结算。抽佣公式不在本页重写。给人看用元。最低额等未点名数字不编造。

### 结算管理 / 提现审核 / 佣金报表 / 商户流水

有这些页，沿用现页能办的事。不另定一套财务产品。

管理员、角色、菜单、API、参数配置、快递公司、登录日志、操作日志。现码「短信配置」菜单已停用，不作为给人看的入口。参数里支付 / 商城字段清单未点名，不编造。

### 管理员 / 角色
