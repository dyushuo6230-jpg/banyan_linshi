# 租户后台（在线商城）

同一套租户后台，另一套模板。供应商登录后经营在线商城的顾客端货源：挂叶子送审、接单、发货、提现。可报秒杀、拼团、板块。没有独立小程序给顾客装，顾客只在众享源品逛。

无装修、无员工 / 角色、无店铺券、无周边。发品必须挂平台类目叶子并送审。规则见《商品类目与审核》《众享源品怎么逛买》。抽佣按商品所属一级快照，见《业态经营类目与抽佣》。活动报名见《拼团与秒杀》。板块见《平台运营与现码保留》。

## 登录

只用入驻主账号。本期无子账号、无员工菜单。会话规则同平台网页：忙不踢、闲必踢、退出或改密立刻作废。登录框不要写死账号密码，也不要浏览器自动填。细则在《登录会话与口令》。

## 工作台

供应商经营概览。不是审品台（审品在平台）。

## 店铺资料

可改 Logo、简介、联系人、电话。店名只读。业态、可售一级只展示，过审后供应商不能自己改一级绑定。没有「是否自营」。

## 商品

### 商品列表 / 发布商品 / 库存 / 评价

商品列表可按平台类目筛：选中祖先须含子孙叶子上的货。存量挂在非叶子上的，可单条改挂或列表批量改挂到人手选的叶子，一条一条独立，系统不自动猜。库存、评价沿用现页。

店铺分类菜单已删。发品页若还留分类，可选、非必填；缺店铺分类不能否决保存。

#### 发布商品表单要点

三步：基础信息 → 规格价格 → 详情。金额填**元**。提交 = 送审。草稿保持驳回；再提交或上架，回到待审。

| 项 | 怎么填 | 选错会怎样 |
|---|---|---|
| 商品名称 | 必填 | 空不能保存 |
| 平台类目 | 必选**最末叶子**。树只含本店入驻已选一级及其下级 | 只点了一级或中间层、超出入驻范围、未挂一级：不能保存为可售、不能送审通过 |
| 主图 | 必传 |  |
| 售价 | 必填，元 |  |
| 库存 | 必填 |  |
| 店铺分类 | 可选 | 不以缺分类否决 |
| 品牌 | 可选 | 不强制 |
| 规格 | 可单 / 多 | 沿用现页 |

未过审不能出现在众享源品当在售。店铺推荐开关不把货推进在线商城顾客端推荐池。编辑后是否要重新送审：**未定**。

## 订单

### 订单列表 / 订单详情 / 售后 / 快递查询

平台统一收款。本轮顾客端不真扣款，后台仍要能看、能发货。发货在详情里办，不在列表行上点一下就发。无核销码。

书面语页签同本地生活那套主状态。顾客端口语可以用待发货 / 待收货。在线商城的顾客端本轮未付单不要标成已付。

快递查询仅本模板有。售后：待处理整单全额退或拒绝；有待处理售后时不能发货、确认收货。部分退、退货物流无此路径。

## 物流设置

仅本模板有。运费模板沿用现页。本地三套没有这一行。

## 财务

资金总览、结算账单、账户流水、提现、银行卡。平台代收后按一级类目抽佣再结。给人看用元。最低额未点名不编造。

本地生活那三套没有资金总览 / 提现 / 银行卡。

## 数据统计 / 消息中心

有交易统计。无通道用量。消息中心沿用现页。

## 秒杀报名 / 拼团报名 / 板块报名

一级菜单。只能勾已审通过的货。下一页勾货，跨页还留着，本页可全选，每批最多 30。失败后再提交改回待审。平台审过之后，顾客才能在在线商城的顾客端看见。本地生活没有这三行。

## 本模板没有的

装修、桌台、预约、店铺券、员工、角色、支付进件、OSS、短信、WiFi、周边、周边 CPS、会员、内容轮播。侧栏没有就是没有，不要写成藏起来。直访旧路由不作为功能说明。不要把店内「秒杀 / 拼团」自发菜单写进本模板。
