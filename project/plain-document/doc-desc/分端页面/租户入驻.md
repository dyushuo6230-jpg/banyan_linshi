# 租户入驻

全业态同一套入驻页。申请人在这里交资料，通过前进不了租户后台。不是租户网页，也不是众享源品「我的」里已经藏起来的入驻入口。

规则全文见功能需求《租户入驻与审核》。抽佣、一级可售范围见《业态经营类目与抽佣》。店员出餐不在这一端。

## 推广入驻码

推广场景带着有效入驻资格打开本页。码失效、没有推广信息，现页提交不了，须重新取得资格。推广体系本身本期不改造、不验收成新功能，见《平台运营与现码保留》。

## 登录 / 校验手机

须先有可用的入驻资格。凭证过期或无效，提交按钮走不通。同一手机已经待审或已经通过，不能再交一份；驳回后只能提新单，不能改原单再送。细则在《租户入驻与审核》和《登录会话与口令》。

票里不要指望带着手机号给前端乱传。联系电话在本页手填或带入，须 11 位。

## 填写申请

现用就是这一套提交审核页。所有业态都走这里，不按餐饮、美发、商超、在线商城拆四套产品。选项只出现「入驻可选」开着的根；关掉的根顾客看不见。

本地生活（全部不是在线商城的根，含以后新增）不选经营类目下级、不选一级。选了在线商城，才出现可售一级。

没有「是否自营」。身份证、行业许可证不升格成本期必填；现用提交页也不问这两项。

### 表单要点

| 项 | 怎么填 | 选错会怎样 |
|---|---|---|
| 业态 | 必选一个开着的根 | 不选不能提交 |
| 可售一级 | 仅在线商城出现。必选 1～3 个**启用中**的一级 | 个数不合、没有启用中的一级，不能提交。本地生活不要出现这一块 |
| 主体类型 | 企业 / 个体户，必选 | 不选不能提交 |
| 营业执照照片 | 必上传，且识别成功 | 没图、识别失败，不能提交。换一张清晰原件 |
| 店铺名称 | 必填 | 空不能提交。过审后店名在租户后台只读 |
| 联系电话 | 必填 11 位 | 位数不对不能提交。待审或已通过的同一手机不能再提 |

执照识别出来的企业名、法人、住所等沿用现页展示，不另发明一套分业态证件。费率死数字不在本页填。

## 提交结果

提交后待审。成功会进结果页，只看申请状态，不在这里发品、不在这里接单。

- 通过：按该业态套租户菜单，以后从租户后台进。
- 驳回：原单结束。不能改原单再送，只能提一份新的重新排队。
- 待审：该手机不能再交一份。

没有对应菜单模板的业态，平台不能审核通过。那是审核端的事，本页申请人看不见模板配置。

## 我的店铺 / 进度

只展示申请走到哪一步。经营商品、出餐、核销都不在入驻页。通过之后换租户后台；顾客端看不见审核过程。
