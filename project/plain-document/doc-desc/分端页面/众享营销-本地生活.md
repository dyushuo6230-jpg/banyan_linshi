# 众享营销 - 本地生活

店内小程序。打开的是**这一家店**，不是众享源品在线商城的顾客端。一套首页，模块按平台「首页模块归属」过滤。用户在店铺池。认店只约束本端：下单、支付不能信顾客端随便传的店号。

底部 Tab 由该店装修配置。现用订单页是新订单列表 / 详情，不要把拷贝来的旧商城订单页当本期说明。

履约规则见《本地生活怎么履约》。钱进该店见《订单支付与结算》。附近两边不要写串，店内规则见《周边与到店服务》。

## 进店首页

顾客打开该店小程序进首页。轮播来自**该店装修**，不是平台 banner，也不是众享源品那套图。

模块按平台配的归属显示或隐藏。拼团、秒杀坑默认通用；没有进行中的活动该坑空着。发活动仍店自发、平台不审。没有外卖入口当本期能力。

#### 按业态会看到的差别

- **餐饮（及从餐饮拷来的新根）**：可有堂食预约、扫桌点餐。有桌台。
- **美发 / 商超（及从这两套拷来的新根）**：选服务 / 选商品，付完到店核销，无桌台。
- 不做外卖。第四种履约没有。

## 点单 / 选商品 / 选服务

顾客在本店选菜、选商品或选服务。未选店内分类或分类已停用的货，不能再买。

### 商品 / 菜品详情 / 结算

详情看本店货。结算付钱进**该店账户**。可用本店券，不用平台券。下单须登录。认店：不能靠前端指定店号串到别家。金额用元。

## 扫桌（仅餐饮拷贝源）

顾客到店扫合法桌号，按这张桌点单。无桌、桌号无效：不能按这张桌下单。付钱后店员出餐或确认完成。

## 核销（美发 / 商超及同样拷贝源）

顾客先付，生成核销码。到店整单一次核销。成功 → 已完成，跳过待评价主状态。本期不设核销天数，也没有到期自动退。拼团不另出一张主码。全额退完：该单码不能再核，不补第二张主码。有待处理售后时不能再核。

## 附近

按**该店已勾本地业态**筛选。CPS 只出平台目录且本店上架的项。不要写成在线商城的顾客端那种「全部本地根」。细则在《周边与到店服务》。

### 店家详情

进另一家本地店，仍是店铺池，不是众享源品供应商。

## 订单

现用列表 / 详情。状态口语：待付款、待核销（美发/商超已付待履约）、已完成、已取消、已关闭。没有「待评价」主状态。已完成可以写评价。

未付倒计时：到期打开列表、详情或去支付，立刻关单，到点不能再付。金额用元。

可申请退款：仅已付还没完成的整单。部分退本期无此路径。

## 我的

店铺池账号。展示本店会员身份。不和众享源品打通。同一部手机在店 A、店 B、在线商城的顾客端是三个号。见《用户账号与用户池》。

登录态放在请求头。店内票不能拿去调在线商城的顾客端。

## 店员页（同一小程序，不是租户 Web）

店员用顾客端这一套小程序办事，不是租户网页，也不是另一套独立 App。

### 店员页 / 退款办理 / 优惠券（店员）

「我的」里，具备租户身份才看到店员页。店员工具入口给核销员 / 收银相关权限。

- **餐饮**：待出餐列表，出餐发货。出餐成功后订单走向已完成（不进待评价）。
- **美发 / 商超**：核销入口：输入或扫核销码，整单一次。非核销员无此权限。
- 退款办理：有待处理售后时先处理售后，不能同时出餐 / 核销。
- 店员侧优惠券沿用现页，不是平台券。

老板也可以在租户后台看单、核销；顾客看见的结果仍是这一家店的订单变成已完成。

## 现码有、本期不当主链的

金豆、充值、次卡、生日、共益、旧版订单 / 分类酷页。页面可能还在，不作为本期闭口说明。

**扫码进店：** 顾客扫这家店的店码，进中间页登录或注册，本店设备一人一机，通过后才出该店推广链。开通没有合法渠道，人能看见失败。密码错不注册。中间页具体网址、密码最少几位**未定**。这是店里已经在跑的现状，本期不必验完整小魔推，也不要写成必须交付的新功能。租户侧栏仍然看不见小魔推。
