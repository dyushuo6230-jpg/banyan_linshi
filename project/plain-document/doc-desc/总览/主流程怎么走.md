# 主流程怎么走

一条主链从入驻走到钱。细则在功能需求，这里只把分叉点说清。

## 主链

```text
申请人在入驻页选业态（在线商城还要选一级类目）
  → 平台在后台审核
  → 通过后套该业态的租户菜单
  → 本地生活：店内自己分类发品（平台不审）→ 上架即可本店可售
       → 餐饮：顾客扫桌点单 → 付到该店 → 出餐后订单已完成
       → 美发/商超：顾客先付 → 到店核销 → 核销成功订单已完成
  → 在线商城：挂平台类目叶子并送审 → 通过后众享源品可售
       → 顾客在在线商城的顾客端看货、加购或立即购买 → 付给平台（本轮按钮在、不真扣款）
       → 按商品所属一级类目抽佣后再结给供应商
       → 可选：平台开秒杀/拼团场 → 供应商用已审货报名 → 平台审过 → 顾客可进、可下未付单
```

## 谁在哪一步看见

- **入驻 H5**：申请人选根、交执照；在线商城必须选 1～3 个启用中的一级。没有「是否自营」这一问。
- **平台后台**：审店通过后，这家店按业态出现对应侧栏。审品只办理在线商城的货。可开商城秒杀/拼团场、审报名、管板块。
- **租户后台 · 本地生活**：发品、看本店订单、出餐或核销相关能力在菜单里。拼团秒杀租户自己上下架，平台不审、不建场次。
- **租户后台 · 在线商城**：发品必须挂叶子再送审；通过后在线商城的顾客端才能卖。没有店内小程序可配。有秒杀报名、拼团报名、板块报名。
- **众享营销 - 本地生活**：顾客为这一家店买；店员在小程序里出餐或核销。履约完成写成已完成，不进待评价。首页按归属可以出拼团、秒杀坑。
- **众享源品**：顾客看见已审过的货，可以加购、可以下未付单。本轮去支付不调起真通道。审过的商城活动也可以进。

## 三句分流（不要在总览展开）

- **履约**：跟该店业态从哪套拷来。餐饮扫桌；美发/商超整单一次核销。没有外卖这条路。核销有没有天数、过不过期自动退，见功能需求《本地生活怎么履约》。
- **券**：本地生活各店发店内券；在线商城的顾客端只用平台券。见《钱和券怎么算》和功能需求《优惠券》。
- **登录**：两个用户池，两套登录态。认店只约束本地生活。见功能需求《用户账号与用户池》《登录会话与口令》。

抽佣看哪一级、空费率怎么办，总览只看到《钱和券怎么算》；公式不在这篇展开。
