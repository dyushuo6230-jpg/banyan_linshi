# 钱和券怎么算

先分清钱进谁的账户、抽佣看哪棵树上的哪一层。费率死数字资料没给，这里不编。通道商户号、手续费清单见技术设计部署，本篇不写。

## 钱进谁账户

| 哪一端 · 哪业态 | 谁付钱 | 人看见钱落到哪 |
|---|---|---|
| 众享营销 - 本地生活 | 顾客在该店小程序付 | 进**这一家店**的收款账户 |
| 众享源品 - 在线商城 | 顾客在在线商城的顾客端付（目标态） | 进**平台**，抽佣后再结给该供应商 |

本轮在线商城的顾客端**不调起**微信 / 支付宝 / 金豆。支付按钮还在，订单可以停在未付。这不等于没有订单，也不等于以后没有结算。本地生活该收到店的，仍收到店。

给人看、给人填的金额用**元**。

## 抽佣看哪

权威在树上的**节点**，不在店铺资料里那个旧抽佣格子。

- 本地生活：看该店**业态根**上的费率。
- 在线商城：看这件商品所属**平台类目一级**。发品必须挂叶子，计佣仍向上取这一级。入驻时多选一级只表示以后能卖哪些，不把几个费率平均成「本店一个数」。

下单当时拍一张快照。平台事后改节点，已下的单不改。

| 节点上怎么配 | 新单怎样 |
|---|---|
| 空，或写成 0 | 这笔新单**不抽佣**，已挂一级的货仍可卖 |
| 商品还没挂上一级 | **不可售、不能下单**。不要把它当成「按 0 抽」放行 |
| 一级或类目停用 | 已上架的不能再卖；已经打下的单，快照不动 |

本地生活的抽佣用来对账，不要做成一笔假入账。商城按快照抽完再结。细则在功能需求《业态经营类目与抽佣》《订单支付与结算》。

## 券不是一张

| 券 | 谁发 | 谁能用 |
|---|---|---|
| 店内券 | 本地生活各店自己发 | 只在本店 |
| 平台券 | 平台发 | 众享源品在线商城的顾客端用 |

在线商城供应商不发店铺券，租户后台没有这张菜单。不要把两类券互相当成「全场通用」。门槛、叠加、过期未点名的，沿用现页，总览不编。

售后、部分退、退货物流不在这篇。部分退和退货物流本期没有这条路，见《本期做什么和不做什么》。
