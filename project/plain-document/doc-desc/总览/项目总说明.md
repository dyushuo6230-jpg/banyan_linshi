# 项目总说明

这是一套**多租户、多业态**的入驻和经营系统，不是单店收银，也不是单用户商城。

种子业态根是餐饮、美发、商超、在线商城。本地生活这一侧以后还可以按规则新增本地根；新根只能从餐饮、美发、商超三种履约里拷一份，不发明第四种到店做法。

## 两条产品线，不要收成一个商城

| 产品线 | 谁在用 | 钱怎么走 |
|---|---|---|
| 众享营销 - 本地生活 | 某店自己的小程序；顾客到这一家店消费 | 付到**该店**账户 |
| 众享源品 - 在线商城 | 多供应商货架；顾客在在线商城的顾客端逛、下单 | 付给**平台**，再按类目抽佣后结给供应商 |

两套不是「一个用户、一个租户、一个后台」换皮肤。店 A 的顾客、店 B 的顾客、在线商城的顾客端里的人，可以是同一部手机上的三个号。

## 租户怎么进来

申请人走同一套入驻页，选「允许入驻」的业态根。平台审过之后，进**同一套租户后台**，侧栏按该店业态套菜单，不是四套互不相干的后台网址。

- 餐饮 / 美发 / 商超：有店内小程序；普通商品店内上架即可本店可售，平台不审。
- 在线商城供应商：没有独立小程序；货要挂平台类目、送平台审核，通过后才出现在众享源品。

平台**不自己开自营店**。身份看业态，不看自营标记。

## 本期要把什么扩开

现有系统以餐饮向本地生活为主。本期要把同一套系统扩成「本地生活可增根 + 在线商城」，并且登录、会话、口令一次过关：忙着干活不被无故踢、闲置必须重登、退出或改密后旧登录立刻作废、不能串店、库里没有明文密码。

众享源品这一端：后台和货源、审品、订单、结算要能闭口；顾客打开的现用页，已经出现的能力要接到在线商城自己的接口并能办完，或按已确认的表藏掉。本轮顾客端不真扣款，支付按钮还在。可以加购、可以下未付单。这不等于已经真扣到账。
