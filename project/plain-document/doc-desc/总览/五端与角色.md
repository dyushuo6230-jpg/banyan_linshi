# 五端与角色

谁在哪一端办事。五端不是五个互不相干的产品；租户后台是一套系统、四套菜单。

## 五端

| 端 | 谁用 | 走进来之后看见什么 |
|---|---|---|
| 平台后台 | 平台运营、平台管理员 | 侧栏审入驻、维护业态树和菜单模板、审在线商城的货、平台券和财务。开商城秒杀/拼团场并审报名，维护板块。不审本地生活普通商品，不审本地生活店自己发的拼团秒杀。 |
| 租户后台 | 已通过的租户主账号；本地生活还可以有子账号 | 同一套网址。餐饮/美发/商超/在线商城侧栏不同。在线商城供应商有店铺资料，没有员工/角色，也没有小程序装修。 |
| 租户入驻 H5 | 还没通过的申请人 | 从入驻页选业态、交执照。在线商城还要选 1～3 个启用中的一级类目。通过前没有租户后台。 |
| 众享营销 - 本地生活 | 该店顾客；店员 | 顾客打开**这一家店**的本地生活小程序：首页、点单或核销、订单。店员出餐、核销也在这套小程序里的店员页，不是租户网页，也不是另一套独立 App。 |
| 众享源品 - 在线商城 | 在线商城顾客 | 手机 App / 小程序 / H5 同一套。看已审过的货、加购、下未付单、在「我的」登录。底部四栏：购物 / 附近 / AI助手 / 我的。本轮不强制绑微信，也不真扣款。供应商没有独立小程序可给顾客装。 |

## 角色

| 谁 | 在哪一端 | 干什么 |
|---|---|---|
| 平台运营 | 平台后台 | 审店、配树和菜单、审商城货、平台券、对账、开商城活动场、审报名、管板块。不给本地生活普通商品盖章。 |
| 入驻申请人 | 入驻 H5 | 选允许入驻的业态根，提交执照。待审或已通过的同一手机不能再提一份；驳回后只能提新单。 |
| 餐饮租户 | 租户后台 + 本地生活小程序 | 店内发品不送审；顾客扫桌点餐；可自己发布拼团秒杀。 |
| 美发租户、商超租户 | 租户后台 + 本地生活小程序 | 店内发品不送审；顾客付完到店核销；可自己发布拼团秒杀。 |
| 在线商城供应商 | 仅租户后台 | 挂叶子送审；通过后货出现在在线商城的顾客端。无独立小程序、不发店铺券。有秒杀报名、拼团报名、板块报名。 |
| 本地生活消费者 | 某店小程序 | 为这一家店下单，钱进该店。认店只约束这一端。 |
| 众享源品用户 | 在线商城的顾客端 | 须在在线商城的顾客端自己注册。看货、加购、下未付单。和店内号不是同一个号。 |
| 租户子账号 | 仅本地生活租户后台 | 跟主账号同一套口令规则。在线商城供应商不用子账号。 |
| 推广员 | 现码还在 | 现状保留。本期不改造、不纳入必验。 |

## 不要对错号

同一部手机：

1. 打开店 A 小程序 → 店铺池里的一个号  
2. 打开店 B 小程序 → 另一个号  
3. 打开众享源品 → 在线商城顾客端用户池里再一个号  

店内的登录态不能拿去调在线商城的顾客端。认店（必须带着本店）只约束众享营销 - 本地生活，不拿来管众享源品。
