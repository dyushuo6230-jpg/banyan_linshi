# 本期做什么和不做什么

验收线和「页面还在、不必验」集中写在这里，避免散落在各模块里第一次出现。量化运营指标（成交额、转化率等）资料没给，**未定**，不编。

## 要做、要能闭口

- **业态能入驻、一套后台能按模板工作。** 允许入驻的根，申请人能提交；平台审过套上该业态菜单。本地根以后可按规则增加，拷贝源只有餐饮或美发/商超。
- **本地生活履约能走完。** 餐饮扫桌点单付到店，出餐后已完成；美发/商超付完到店核销。普通商品店内上架即可本店可售，平台不审。店内小程序要能闭口上线。店内首页按归属可以出拼团、秒杀坑。
- **入驻、平台后台、租户后台其余功能开发完成。** 能闭口就闭口。不要因为在线商城的顾客端还没做完，就把后台、本地生活、入驻留到下次。
- **在线商城供应商侧闭口。** 发品送审、平台审核、接单发货、抽佣结算、店铺资料都要做完。另有秒杀报名、拼团报名、板块报名。
- **众享源品顾客端现用页要能办完，或按已确认的表藏掉。** 可以没货、可以空态，不能只弹一句「敬请期待」当交差。短信或账密能登录，「我的」能看出已登录，不强制绑微信。加入购物车能进购物车，购物车能改数量、结算进未付单；立即购买同样进未付单。支付按钮和组件还在，本轮不要求真扣到账。
- **平台能开商城秒杀场、拼团场。** 供应商用已审过的货报名，平台审过之后，在线商城的顾客端能进活动、能下未付单。到期没成团：未付单关掉，活动占用放掉。本批没有真退款。
- **平台能管板块。** 商品型要审过才上架；子列表平台自己配。在线商城供应商一级有板块报名。附近顶上的灯片走子列表，不是购物首页那套轮播。
- **本地生活店档案能填、附近详情能看。** 老板在「店铺」补省市区、坐标、顶图、介绍图、营业说明。源品和店内附近详情吃这套。先存坐标，不算距离、不导航。
- **登录安全五条过关。** 忙着操作不被无故踢；闲置必须重登；退出或改密后旧登录立刻作废；不能串店；库里没有明文密码。网页用登录态加防伪；小程序走自己的票。认店只测本地生活。未过这五条不能当生产已上线。

## 明确不做

- 外卖。餐饮只做到店扫桌。
- 发现。底部没有发现入口，不对接发现业务。
- 源品 AI 接真业务。底部可以留「AI助手」，进了是假页；视频、生图子页本批不做。
- 本轮在线商城的顾客端真扣款成功。按钮保留，目标态以后再接通道。
- 好友助力。首页助力入口藏掉，不做助力业务。
- 另做一套限时折扣规则。图上的限时折扣点进商城秒杀列表。
- 板块按商品改支付通道。通道仍跟平台。
- 部分退、退货物流主路径。
- 新做一套地址表。在线商城的顾客端地址复用现成的用户地址。
- 把类目正式名单、根上的费率死数字写进说明或验收。未定就写未定。
- 平台自营店，以及用自营标记筛选、结算、套菜单。
- 推广员、小魔推改造并纳入必验。现码可以留着，侧栏该看不见的按已确认口径处理，不当作本期新功能验收。
- 众享源品在线商城的顾客端不新做小魔推，也不把扫码进店写成在线商城的顾客端能力。本地生活店码进店可以当现状讲清，本期不必验完整小魔推。
- 短信二次验证、设备列表、异地登录提示、给顾客端额外做一套 30 分钟闲置等增强。登录只验上面那五条。

## 页面还在，但不验收像素 / 假页

有设计图的源品现用页按图还原。购物车、订单继续用旧页，不卡像素。没有设计图的页（含商城拼团秒杀自编页、AI 假页）不卡像素。

银行卡、全民推广、官方公告、联系客服、余额/消费券/金豆格：点了可以「敬请期待」，不做真金豆账户。真开店、当供应商先走入驻页，顾客端入驻入口留着、点了同样提示。

未合进主分支的开发进度，不要在会上说成生产已经如此。
