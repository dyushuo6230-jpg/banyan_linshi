# 名词对照

开会时先对这张表。说「商城」之前，问一句：是本地生活小程序，还是在线商城的顾客端？

| 别和这个混 | 应该怎么叫 | 一句话 |
|---|---|---|
| 本地生活 / 到店 / 店内小程序 / 店 App | 众享营销 - 本地生活；白话优先写本地生活小程序 | 某一家店自己的小程序。顾客为这家店下单，钱进该店账户。 |
| 大厅 / 优选 / 商城 App / 共益优选 | 在线商城的顾客端（产品全称：众享源品 - 在线商城） | 多供应商货架。顾客在这一端逛，钱进平台，再抽佣后结给供应商。 |
| 四个 App、四套后台 | 四个业态根 + 一套租户后台 | 餐饮、美发、商超、在线商城是业态。后台是一套，侧栏按模板不同。 |
| 经营类目、店铺类目 | 业态树 / 入驻选的根 | 申请人入驻时选哪一种业态；本地生活抽佣看业态根。 |
| 平台类目、商城分类 | 平台商品分类树 | 在线商城发品挂叶子；计佣仍看所属一级。不是店内自己建的分类。 |
| 店铺池 / 商城池 / 「一个手机一个号」 | 两个用户池 | 同一手机：店 A 小程序、店 B 小程序、众享源品，可以是三个号。 |
| 商家端、商家 App | 禁止再写 | 没有这两个产品。老板改菜单、发品走网页**租户后台**。出餐、核销在本地生活小程序的店员页。 |
| 商家后台、商户后台 | 租户后台 | 已通过的租户用的那套网页。不是平台后台。 |
| 商家、商户（指入驻经营的那一方） | 租户 | 餐饮租户 / 美发租户 / 商超租户；在线商城这一业态说到职责时仍叫供应商。 |
| 附近 | 店内周边 vs 众享源品附近 | 店内按**本店已勾的本地业态**；在线商城的顾客端附近是**平台级全部本地根**，不跟某供应商勾选走。 |
| 券 | 店内券 vs 平台券 | 本地生活各店自己发、只在本店用。在线商城的顾客端只用平台券。供应商不发店铺券。 |
| 到店 | 履约方式，不是第五业态 | 餐饮扫桌、美发/商超核销。不要把「到店」登记成一种业态根。 |
| 自营 | 本期没有这条身份 | 平台不自己开店。不要按自营筛选、结算或套菜单。 |
| 微信商户号、支付商户号 | 仍叫商户号 | 这是支付通道用语，不要改成租户。 |

## 自己检查一句

刚才说的「商城」，如果既可以指某店小程序、又可以指在线商城的顾客端，就是叫混了。本地生活说店名；在线商城的顾客端说众享源品。
