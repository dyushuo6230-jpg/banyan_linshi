# 拼团秒杀怎么落地

两条流程，不要套成一套。本地生活仍是店自己发、平台不审。众享源品是平台开场、供应商报名、平台审。成交都走同一套下单付钱，不另做支付通道。

规则全文在《拼团与秒杀》。图见《拼团秒杀-泳道》。

## 出现在哪些端

- **本地生活租户后台**：创建、上下架。
- **本店顾客**：看见进行中的活动可以买。首页按归属可以出拼团、秒杀坑，没有进行中的活动就空着。
- **平台**：侧栏没有已删的秒杀管理、拼团审核。另有商城秒杀、商城拼团，下场次、审报名。直访旧地址也要拒绝。
- **在线商城供应商**：秒杀报名、拼团报名，只能报已审货。
- **在线商城的顾客端**：审过的场次可进、可下未付单。接口可以露出源品活动，不暴露本地生活拼团秒杀。

## 怎么串起来

**本地生活：** 租户上架 → 本店可见，不经平台审。下架后新参失败，旧单不自动关。美发 / 商超不另出核销主码。

**众享源品：** 平台创建场次 → 供应商报名 → 平台审过 → 顾客可见可买 → 未付单。到期没成团关未付单、放掉占用。本批没有真付，也就没有真退。

## 关键约束

- 平台已删的经营入口不要写回来。新菜单不是旧菜单换皮。
- 库存不足不能超卖；没写数字就不编。
- 两种流程允许状态不一样，禁止拿店自发去套源品，也禁止拿平台审去套店内。
- 不要把本地生活活动接到在线商城的顾客端接口。

## 和正式设计的关系

正式营销设计是真源。本篇不改玩法。

- 平台给店发活动通知：资料没写。
