# 履约扫桌与核销

履约只出现在本地生活。跟拷贝源走：餐饮扫桌，美发 / 商超核销。店员在同一套小程序办事，租户后台也能核、也能看出餐，不要理解成只有网页。

规则全文在《本地生活怎么履约》。图见扫桌、核销泳道和核销时序。

## 出现在哪些端

- **店内顾客**：扫合法桌或先付拿码。
- **店员**：待出餐或核销入口，须有对应权限。
- **租户后台**：桌台仅餐饮；美发 / 商超可核码。
- **在线商城供应商**：无此能力。

## 怎么串起来

付钱进该店 → 餐饮出餐或确认完成变成已完成；美发 / 商超整单一次核销变成已完成。都不进待评价。有待处理售后不能出餐、核销。全额退后码作废、不补第二张主码。

认店：不能信顾客端传来的店号。

## 关键约束

- 不把核销做成餐饮主路径，不把扫桌做成商超主路径。
- 不做外卖、不发明第四种履约。
- 不设核销天数、没有到期自动退。
