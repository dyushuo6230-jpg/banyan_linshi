# 商品两种流程

一个商品能力、两种流程。本地：店内分类、上架即可本店卖，平台不审。商城：挂叶子、送审，通过后在线商城的顾客端可售。审核台不拆成两个产品。

规则全文在《商品类目与审核》。图见商品两张泳道和审品时序。

## 出现在哪些端

- **租户后台 · 本地**：必选店内分类。可推本店推荐栏，只作用于本店。
- **租户后台 · 商城**：挂叶子送审。店铺分类可空。
- **平台审核台**：只办理在线商城。不审本地普通商品，不审拼团秒杀。
- **在线商城的顾客端**：只看见已过审、仍可售的货。

## 怎么串起来

可售要同时满足：本地已上架且分类未停用；商城已过审、已挂一级、类目未停用。平台推荐和店铺推荐分开，店铺推荐不推进在线商城的顾客端货池。

编辑后是否重新送审：**未定**。

## 关键约束

- 本地货不进在线商城的顾客端。
- 未挂一级不可售。
- 品牌可选、不强制。
