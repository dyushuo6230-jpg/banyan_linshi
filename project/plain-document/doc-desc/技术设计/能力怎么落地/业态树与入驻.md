# 业态树与入驻

树由平台维护。入驻页只读开着的根。通过后绑定该店业态，并套这一套菜单。新本地根的履约跟拷贝源走，不新写第四种到店做法。

规则全文在《业态经营类目与抽佣》《租户入驻与审核》。图见入驻泳道和时序。

## 出现在哪些端

- **平台**：维护根、入驻是否可选、节点费率、启停、菜单模板。
- **入驻页**：只读可选根；商城再选 1～3 个启用中的一级。
- **租户后台**：过审后侧栏按快照。商城发品时校验可售一级范围。

## 怎么串起来

平台有种子四根。本地可增根，拷贝源只能是餐饮或美发 / 商超。入驻只读树 → 待审 → 通过套菜单。没有模板不能通过。商城可售一级记在入驻绑定上，发品挂叶子时必须落在这些一级下面。

## 关键约束

- 入驻不问自营。驳回只能提新单。
- 到店不是业态根。
- 费率死数字不编。

## 和正式设计的关系

树与入驻正式设计在对应模块。本篇只说落在哪一端、怎么串。

## 未定 / 本期不做

- 不把多个一级费率平均到店铺。
