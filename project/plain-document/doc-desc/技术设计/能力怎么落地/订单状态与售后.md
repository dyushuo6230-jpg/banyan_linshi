# 订单状态与售后

主状态没有待评价。确认收货、出餐、核销成功都写成已完成。未付到期：打开列表 / 详情或去支付立刻关成已取消，定时仍会关。售后只办已付未完成的整单；平台只读。

规则全文在《订单支付与结算》《售后与退款》。图见支付结算夹和售后评价夹。

## 出现在哪些端

- **后台书面语**：待付款 / 已付待履约 / 履约中 / 已完成 / 已取消 / 已关闭。不要待发货、待收货、已付款这种页签。
- **顾客口语**：在线商城的顾客端可说待发货 / 待收货；本地美发 / 商超已付显示待核销。
- **现用订单页**：本地生活现用页和在线商城的顾客端订单页都要对齐上述展示；不要拿拷贝来的旧商城订单页当本期说明。

## 怎么串起来

未付 → 本地已付后出餐或核销到已完成（没有履约中）。在线商城的顾客端目标态：已付待履约 → 履约中 → 确认收货即已完成。本轮在线商城的顾客端常停未付。

售后仅已付待履约或履约中。租户整单全额退或拒绝。有待处理售后不能履约。已完成只能评价。

## 关键约束

- 部分退、退货物流本期无此路径。
- 平台没有仲裁办理口。
- 倒计时分钟数图上和本篇都不写死。

## 和正式设计的关系

正式交易设计是真源。本篇不写状态数字当给人看的页签名。

- 拆单部分成功：未定。
