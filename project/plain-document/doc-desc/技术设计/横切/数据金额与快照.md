# 数据金额与快照

给人看、给人填用元；库里仍是分。新单抽佣按下单当时节点费率快照，事后改树不改旧单。共库不是两个库：隔离靠业态、用户池、订单归属。

公式只认功能需求《业态经营类目与抽佣》。本篇不搬数据字典。

## 出现在哪些端

- **所有给人看金额的页**：元。租户提现按元填，提交按分入库。配置里最低提现仍按分存，界面要换算。
- **不用人点**：下单当时拍抽佣快照。未挂一级不能卖、不能下单。
- **结算**：有效订单 = 已完成且无卡住的售后。

## 怎么串起来

业态树节点上有费率。本地生活新单看业态根快照；在线商城的顾客端新单看商品所属一级快照。空或 0 = 该新单不抽佣，已挂一级仍可卖。店铺资料旧抽佣格子不再当新单权威。

两个用户池、两类订单、两类券记在同一套库的不同归属上，不要理解成拆库。需要表名时看正式数据文档。

类目或店内分类停用：已上架不可再售，已下单不改快照。

## 关键约束

- 未挂一级不要当成「按 0 抽」放行。
- 不以自营标记做结算口径。
- 不把 Redis 几号库、逐表字段写进本篇。
- 费率死数字、类目正式名单：**未定**。
