## 功能在哪看到（人话 6 问）

1. **哪一端：** 众享源品 C 端（`go-uni-app-online`）换皮用的令牌和底栏造型，不是后台、不是本地生活独立端。
2. **谁：** 换皮时的实现与验收，不是新业务角色。
3. **怎么走进来：** 点名页换皮之后，在详情底栏、首页顶栏、全站底栏、商品列表到底处看见。
4. **人在哪看见：** 立即购买；底栏五坑；详情主价；首页金顶右上购物袋；列表拖到底的空态。
5. **怎么操作：** 按下列已确认规则画和验。本决策不改现码。
6. **现在怎样 / 改完怎样：** 现码未换皮。文档令牌按本决策改完；落地等点名页。

## 已确认规则

1. **金主按钮深字压金（UI-BTN-001=A）。** 详情底栏「立即购买」、同类金胶囊（如「个人主页」）用 `{colors.text-primary}` (#222222) 压 `{colors.brand-gold}`，对得上分类选中胶囊，对比约 9.91:1。白字只给黑「搜索」等深底。视觉验收 **不卡** 详情 PNG 上的白字立即购买。
2. **《Tab Bar交互》一张图两件事（UI-TAB-SRC-001=A）。** 上半：四个侧边图标的选中/未选中交互（灰线稿 ↔ 青柠填色）。下半：商品列表拖到底空态「别再搜，我到底啦~」，**不是**底栏的一部分。禁止把这张图当成完整五坑底栏。
3. **底栏结构听整栏图，中间 AI 听橙红标（UI-AI-001=A）。** 五坑、白底、中间缺口抬高、选中侧边青柠填色，以整页底栏（图 2：购物 / 附近 / AI助手 / 发现 / 我的）为准。**AI 助手保留图 2 橙红圆形 AI 标，凸在缺口里**，不得改成图 1 青柠卡通。第四坑文案与路由仍按 UI-DEC-002 做购物车，发现业务仍不做，图标暂用发现造型。
4. **详情现价单独加大（UI-PRICE-001=A）。** 列表/首页双列现价用 `display` 20px / 40rpx；详情主价用 `price-xl` 28px / 56rpx。都是 `{colors.price}`。
5. **首页右上购物袋与底栏第四坑都留（UI-CART-DUAL-001=A）。** 首页金顶右上描边购物袋保留，进现有购物车。底栏第四坑另做购物车入口（UI-DEC-002）。详情底栏最左「购物」仍按详情图，不因本条删除。
6. 本决策 **不** 修改 `go-uni-app-online`。令牌写入 `design.md` 后须重跑 `build_tokens_json.py`。未点名页不得换皮。
