## 功能在哪看到（人话 6 问）

1. **哪一端：** 众享源品 C 端分类页。
2. **谁：** 逛店顾客。
3. **怎么走进来：** 底栏「分类」。
4. **人在哪看见：** 左栏选中金卡；右侧白卡里三列圆图；点倒三角后的「全部分类」面板。
5. **怎么操作：** 点左栏、点圆图、点三角下滑面板。
6. **现在怎样 / 改完怎样：** 现码已是白边进阴影、箭头在内、grid 三列、面板可滚。本条把验收改成听现码。不改 `category.vue`。

## 已确认规则

1. **左栏选中（表 B）。** 未选中同高同字号。选中：白边包金芯、白边在阴影内、箭头在金卡内、选中块加高、圆角 10rpx。循环不得改回外侧箭头或选中与未选同高。
2. **竖条。** CSS 白底，顶角 10rpx。**禁止** `side-bg.png` 大胶囊切图当竖条底拉伸。
3. **三级圆图（表 E）。** CSS grid 三列均分。禁止 flex 换行成两列。
4. **全部分类（表 F）。** 标题固定，列表超出可滚。不把 `520rpx` 升令牌。
5. **防循环洗回。** 分类 32A 听 UI_SPEC 0.1.4 第 4 节 + 本合同 + 现码。不得按 0.1.3 / 《分类.png》改回米金条、外侧箭头、两列、不可滚。
6. **二级槽 / 全部分类其它现码。** 槽高 64rpx、胶囊 46rpx、三角 `bottom: -15rpx`、不铺米金遮罩。全部分类 overlay + 520rpx 可滚，选中金底深字。循环不得改 `.main` 左距 20rpx。
7. **本决策不修改 `category.vue`。** UI_SPEC 0.1.4 已于 2026-09-19 第 29 节批准。DEC-071 §4 已为 v1.3.0。
