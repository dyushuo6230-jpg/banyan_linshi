## 功能在哪看到（人话 6 问）

1. **哪一端：** 众享源品 - 在线商城 C 端分类页，不是后台、不是本地生活、不是首页。
2. **谁：** 逛店顾客。
3. **怎么走进来：** 底栏「购物」进首页 → 底栏「分类」；页标题「商品分类」。
4. **人在哪看见：** 整块浅底外框的角；左栏竖条和选中金卡的角；外底板从顶往下的底色和内缩。
5. **怎么操作：** 打开分类页就能看见。不用登录。
6. **现在怎样 / 改完怎样：** 现码已是分层圆角和新底板。本决策把验收改成听现状；不对《分类.png》顶上那条米金卡像素。代码已在，本决策不改 `category.vue`。

## 已确认规则

1. **分层圆角（UI-CAT-RADIUS-001=A）。** 外底板 `16rpx`。左栏竖条与左栏选中金卡 `10rpx`（约 5px）。不是同一套圆角。循环不得为了「数字统一」改成全 10 或全 16。
2. **外底板底色听现状（UI-CAT-BOARD-GRAD-001=A）。** `#fff8df → #fffdf4 → #f8f8f8 → #f6f6f6`，内边距 `16rpx`。这是修订，不是一比一原图。循环不得刷回顶白边 + `#fff6d6` 米金条。
3. **不升 locked 令牌。** 奶油色 `#fff8df` / `#fffdf4` 只写分类页覆盖。落到的灰用已有 `surface-page` `#F6F6F6`。不改 `design-tokens.json`。
4. **二级左右遮罩。** 跟现码底板顶色走，或不再铺 `#fff6d6`。不得借「规范还写着 div 遮罩」把米金条加回来。
5. **防循环洗回。** 后续 UI_SPEC / Contract / 分类 32A 必须写本条。只改口令、不写覆盖，视为未落地。
6. **本决策不修改 `go-uni-app-online`，不改写 UI_SPEC 0.1.3 正文。** 第 30 节 Draft 0.1.4、第 29 节批准、Contract 同步须另开口令。DEC-071 §5 由本条同步修订为 v1.2.0。
