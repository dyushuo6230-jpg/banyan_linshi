## 功能在哪看到（人话 6 问）

1. **哪一端：** 众享源品 C 端（`go-uni-app-online`）首页，不是后台、不是本地生活、不是分类页。
2. **谁：** 逛源品的买家。
3. **怎么走进来：** 底栏「购物」进首页，下滚过 618 专区。
4. **人在哪看见：** 双列商品上方那一排横向分类，选中那一粒的底、星、下箭头尾巴。
5. **怎么操作：** 点某个分类名，选中态换到该粒。不用登录。
6. **现在怎样 / 改完怎样：** 现码选中是浅金胶囊。规范已定听切图组 A；落地等后续第 30 节写入 UI_SPEC 覆盖，再点名首页 32A。本决策不改代码。

## 已确认规则

1. **仅首页横向分类选中为页面覆盖（UI-HOME-CHIP-001=A）。** 选中背景用 `docs/project/ui-design/products/gongyi_online/materials/assets/` 下的 `首页横向分类选中背景15`（含 @2x / @3x）：黑底、星、下箭头小尾巴。未选中仍白底细边。
2. **不升级应用令牌。** locked `chip` 仍是选中浅金。分类页左栏、顶栏胶囊、其它金选中不因本条变黑。
3. **本条不启用组 B/C/D。** 分类切图不因首页覆盖启用。分类页左栏箭头与二级代码金气泡改由 **DEC-071 v1.1.0** 批准，不在本 DEC 范围。
4. **防循环洗回。** 后续 UI_SPEC 覆盖、Contract、首页 32A 口令必须写明：首页横向分类选中听组 A，不得按定稿浅金胶囊或系统 `chip` 令牌改回去。只改口令、不写覆盖，视为未落地。
5. **本决策不修改 `go-uni-app-online`，不改写 UI_SPEC 0.1.0 正文。** 物资清单启用、第 30 节 0.1.1 Draft、Contract、32A 须另点名步骤。
