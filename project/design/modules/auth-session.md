## 1. 范围

| 项 | 口径 |
|---|---|
| 职责 | 口令不可逆；登录；短票/可作废长票；作废名单；网页 Cookie+CSRF；小程序 Header；入驻票（票面无手机号）；本地生活认店 |
| 非职责 | 不拥有用户主数据与分池（`user`）；不审店（`onboarding` 只验票）；不收钱；不按 mall / mall-online 拆两套用户模块 |
| 暴露面 | admin / merchant 网页会话；mall 店铺池票与认店；mall-online 众享源品 - 在线商城池票（进程未建，语义预留）；入驻 H5 持票 |
| 稳定 ID | `auth-session`（ADR-017） |

三端凭证隔离：平台后台、租户后台、C 端票不得互相当作身份。mall 票与 mall-online 票不得互认（ADR-002）。退出/改密只作废本端。

DEC-005 已采用的默认时间（产品未另定则用此，改数字须另决策）：后台闲置 **30 分钟**；后台同一段登录寿命 **12 小时**；C 端长票约 **7 天**无活动作废；短票 30～120 分钟，快过期且会话仍在则换新票。C 端**不做** 30 分钟闲置。

## 2. 组件

| 组件 | 位置（逻辑） | 职责 |
|---|---|---|
| PasswordStore | admin / merchant | 只存不可逆口令；重置只亮一次；停写明文旁路 |
| AdminSession | admin 网页 | 忙不踢、闲必踢、闸立刻废；Cookie+CSRF；超管角色每次以库为准 |
| MerchantSession | merchant 网页 | 与平台同一套可立刻作废；登录失败锁定与平台对齐；会话内带本店身份（不从租户票删除店铺身份） |
| CShortLong | mall / mall-online | 短票调业务；长票只换短票；可作废 |
| Revocation | 各进程独立键前缀或独立 redis.db | 作废本端票。具体 db 号 **TBD**，须避开现码占用 |

## 3. 调用流程

### 3.1 后台口令与会话

1. 入驻通过或重置：随机密码只亮一次（弹窗或短信），之后只存不可逆。刷新再也看不到。列表/详情无明文。
2. 首次登录强制改密；超管首次必须改密。各端登录页不写死账号、密码；无默认弱口令进生产。平台超管登录名为 `ZadminDister`（DEC-064）。登录与密钥框声明不要浏览器自动填（DEC-066）。
3. 历史明文清空。换清明文或换密钥后全员按新口令重登。
4. 登录后：持续操作刷新闲置（忙不踢，可超过原固定寿命）。停手超过 30 分钟须重登。同一段最长 12 小时须重登。退出、改密、重置、禁用立刻作废（闸立刻废）。租户与平台同一套，不能只验票签到过期。
5. 一账号同一时段以服务端当前会话为准。短票快过期且会话仍在则换新票。
6. 取消超管后，下一请求按库中角色授权，旧会话不能再执行超管专属操作。平台超管只属于 `ZadminDister`；那四项及配套接口不对普通角色开放（DEC-065）。
7. 租户登录失败锁定与平台同一规则（次数沿用平台现状，不编造）。

### 3.2 网页 vs 小程序

网页后台：HttpOnly + Secure + SameSite Cookie，写操作 CSRF。**禁止**先 localStorage 再迁 Cookie。脚本读不了网页会话 Cookie。

小程序：Header 带短票，按短+长换票。不走网页 Cookie 方案。

跨域/网关细节 **TBD**，不得改变上述语义。

### 3.3 C 端（店铺池 + 众享源品 - 在线商城池）

1. 登录发短票 + 可作废长票。长票只能换短票。
2. 退出/改密/封号/长票闲置到期作废。打开端或短票失效用长票换短票，失败则重新登录。
3. 众享源品 - 在线商城登录方式：手机号或账号密码（DEC-003）。**不**给众享营销 - 本地生活自动打开同一套密码登录。
4. 消费者票用用户标识，尽量不把微信身份放在可解开票面。
5. 401：前端换票重试，新票按 Cookie 或小程序规则写入；禁止把票和密码打进控制台。失败才回登录。
6. mall-online 独立 jwt.secret 与作废名单键；众享源品 - 在线商城票 mall 不认，mall 票 mall-online 不认。

### 3.4 入驻票

发放时手机号不在可解开票面；提交时服务端仍能对应手机号。过期/作废不能提交。丢失须按现码重新获取，不编造新渠道。`onboarding` 只验票，不发票。日志不出现完整入驻票。

### 3.5 认店（仅众享营销 - 本地生活）

当前店 = 服务端用小程序身份解析出的店。购物车、下单、券、支付、预约**禁止**信任客户端传来的店号作为记账店铺。伪造店 B 不能记到店 B。

众享源品 - 在线商城是多店商城，**不**套「当前小程序 = 唯一店」。租户后台仍信租户会话里的本店身份，与 C 端认店不要混。

### 3.6 传输与日志

全站 HTTPS；HTTP 登录拒绝或跳转。日志/网关对密码、完整票、授权头、明文旁路口令、小程序密钥脱敏。生产密钥不进文档、不进 Git。

### 3.7 本期明确不做

短信二次验证、设备列表、异地登录提示、加密 JWT、登录密码再套 RSA、C 端 30 分钟闲置、从租户票删除店铺身份。

## 4. 状态机

```text
session_active  →  revoked   （退出/改密/重置/禁用/闲置到期/寿命到期）
lock_open       →  lock_held （连续失败达平台同等规则）
must_change_pwd 直至改完
```

作废后旧短票/长票立即失败。换密钥 = 全员重登。

## 5. 逻辑数据（不冻结 DDL）

现码：库有明文旁路口令候选；JWT 可解出 merchant_id；入驻票曾含手机号类信息。目标：

| 实体（逻辑） | 权威 | 含义 |
|---|---|---|
| Credential | 本模块 | 不可逆口令；无 text_password 业务含义 |
| Session | 本模块按进程 | 服务端登记的当前会话；闲置与寿命 |
| RefreshGrant | C 端 | 可作废长票语义 |
| RevocationList | 按进程隔离 | 本端作废 |
| ApplyGrant | 入驻 | 票面无手机号；服务端映射申请人 |
| ShopBinding | mall | 小程序 → 店 |

不在本模块存：用户池字段（`user`）、入驻申请主数据、订单。不写 Redis 键名、不写头字段名。

## 6. 操作清单（路径留 G9）

| 操作 | 调用方 | 幂等 |
|---|---|---|
| 登录 / 登出 | 三端各自 | 登出重复调用仍为已作废 |
| 重置口令只亮一次 | 有权限角色 | 再次读取失败 |
| 换短票 | C 端 | 长票作废则失败 |
| 校验入驻票 | `onboarding` | 废票失败 |
| 解析当前店 | mall 业务 | 不信客户端店号 |
| 作废本端 | 退出/改密 | 不影响另一进程 |

## 7. 事务、并发、一致性

| 场景 | 口径 |
