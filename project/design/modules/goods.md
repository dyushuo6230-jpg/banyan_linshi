## 1. 范围

| 项 | 口径 |
|---|---|
| 职责 | 一个商品能力域、两种发品流程；品牌库附属（可选不强制）；同一审核台可混勾批量审；在线商城挂树节点并校验可售一级 |
| 非职责 | 不拥有树（`tree`）；不拥有店业态/可售一级绑定（`onboarding`）；不写支付与抽佣快照（`trade`）；不经营拼团秒杀场次（`group-seckill`）；不拆两个商品模块、不拆独立审核模块 |
| 暴露面 | 发品：merchant。审核：admin。本店可售读：mall。众享源品 - 在线商城可售读：mall-online（进程未建，只预留读可见集） |
| 稳定 ID | `goods`（ADR-017） |

两种流程（ADR-009），不是两张独占表、不是两套审核菜单。

## 3. 调用流程

### 3.1 本地生活普通商品（餐饮 / 美发 / 商超）

1. 租户维护店内分类。发品必选店内分类，未选不能送审/可售（REQ-030）。
2. 不选经营类目树。不要求入驻时选平台类目。
3. 提交平台审核。未过审、驳回：本众享营销 - 本地生活不可售。
4. 平台通过后：本众享营销 - 本地生活按店内分类可售。租户仍可自行下架。
5. **不得**进入众享源品 - 在线商城货源（DEC-016）。mall-online 可见集排除本地生活普通商品。
6. 拼团/秒杀不走本流程（DEC-004）。

### 3.2 在线商城商品

1. 供应商用树形选择器，选项来自 `tree` 的在线商城子树（与计佣同一套，DEC-012）。可选到二级/三级；计佣所属一级由 `tree` 解析，本模块保存挂点并缓存所属一级 ID 便于校验（权威解析仍以树为准）。
2. 所属一级必须落在该店入驻已选一级内（只读 `onboarding`）。超出范围：不得送审通过。
3. 未挂一级：不得送审通过、不得作为众享源品 - 在线商城可售、**不得下单**（DEC-013）。拦截下单属 `trade`；本模块提供「是否可售」判定：未挂一级 = 不可售。不发明缺省费率。
4. 未选品牌不得否决送审或可售（DEC-009）。现码发品页无品牌选择器不挡主路径。
5. 平台通过后：众享源品 - 在线商城可展示可买（付钱见 `trade`）。不是平台自营商品。
6. 审核中重复提交、驳回后再提：草稿保持驳回；提交或上架且需审则回待审（DEC-043）。本地生活普通商品不审（DEC-026）。

### 3.3 同一审核台

1. 列表含：在线商城业态商品 + 本地生活普通商品。可按业态筛选。
2. 拼团秒杀不进本队列。
3. 逐条或勾选后批量通过 / 批量驳回。混勾允许。每条记录审核人、时间、结果。
4. 通过效果按业态：本地生活 → 本店可售；在线商城 → 众享源品 - 在线商城可售。本地生活通过后仍不进众享源品 - 在线商城。
5. 租户不可审自己、不可批审自己的货。
6. **批量逐条独立（DEC-044）：** 成功的生效，失败的跳过并返回原因。不因一条失败整批回滚。不得把失败条标成通过。
7. 驳回再提：草稿保持驳回；提交/上架回待审（DEC-043）。

### 3.4 可售判定（给 `trade` / C 端）

| 渠道 | 可售当且仅当 |
|---|---|
| 本众享营销 - 本地生活（本地生活） | 普通商品：审核通过 + 租户未下架 + 已选店内分类。不含拼团秒杀本规则 |
| 众享源品 - 在线商城 | 在线商城商品：审核通过 + 租户未下架 + 能归属某一级且该一级 ∈ 店可售一级 |

本模块回答「能不能当普通商品卖掉」。下单、库存扣减、抽佣快照属 `trade`。

## 4. 状态机

审核语义沿用现码，不把列名写成业务规则。现码候选：待审 / 通过 / 驳回。

```text
pending  →  approved
pending  →  rejected
```

可售还叠加租户上下架（现码另有草稿/上架/下架/违规下架）。**可售** = 审核通过 ∧ 上架 ∧ 渠道规则满足。通过后租户可下架，下架后不可售。

上线迁移（DEC-017）：开关日已在本店可售的本地生活普通商品 → 视为已通过。之后新建必须送审。不含拼团秒杀、不含众享源品 - 在线商城货源。在线商城存量不在 DEC-017 覆盖范围，不得在本文默认同样「视为已通过」。

驳回后再提：草稿保持驳回；提交或上架且需审则回待审（DEC-043）。状态机增加 `rejected → pending`（仅提交/上架）。

## 7. 事务、并发、一致性

| 场景 | 口径 |
|---|---|
| 单条审核 | 更新审核结果 + 写记录 同一本地事务 |
| 批量 | 每条独立落结果。不整批回滚（DEC-044）。失败条不得显示为通过 |
| 与树 | 送审时校验挂点；之后树改名不换一级身份。节点停用后已上架商品按 DEC-035：读路径不可再售；不得静默删挂点；不得批量改下架字段 |
| 与入驻 | 只读可售一级。平台改绑定后不在新绑定内的货不可再售、不改商品行、不自动迁货（DEC-044） |
| 与下单 | **无**跨模块分布式事务。`trade` 再验可售与一级 |
| 并发双审 | 条件更新：仅 `pending` 可审；第二下返回已处理 |

| 项 | 口径 |

## 9. 性能、灰度、回滚、测试

| 项 | 口径 |
|---|---|
| 性能 | 审核列表按待审过滤。C 端可售查询须能排除未过审。量化 SLA **TBD** |
| 灰度 | 本地生活新发必须待审。上线存量按 DEC-017。测试环境允许清库，不为测试数据做「视为已通过」工程 |
| 回滚 | 回退本模块代码。不把「本地生活不审也能卖」恢复为业务规则 |
| 测试 | 未选店内分类不可售；本地生活未过审本店不可买；通过后本店可买且不进众享源品 - 在线商城；在线商城未挂一级不可送审通过/不可售；超出店一级拒绝；未选品牌可送审；混勾批量每条有记录；拼团秒杀不在本队列；停用一级或店内分类后不可再买且不改商品上架字段 |

Given/When/Then（设计级）：

- Given 餐饮发品未选店内分类；When 送审或上架；Then 不能作为可售。
- Given 美发商品未过审；When 本店顾客打开；Then 不能买到。
- Given 在线商城商品未通过；When 众享源品 - 在线商城浏览；Then 不能当在售买到。
- Given 在线商品无法归属一级；When 送审或下单校验；Then 拒绝，不给 0 费率。
- Given 平台混勾本地生活与在线商城待审；When 批量通过；Then 各按业态可售且每条有记录。
- Given 上线日某本地生活服务已在本店可售；When 按 DEC-017 迁移；Then 视为已通过。
- Given 已过审在线商品所属一级停用；When 众享源品 - 在线商城下单；Then 拒绝且不改该商品上架字段。
- Given 店内分类停用；When 本店加购；Then 不可再售。
