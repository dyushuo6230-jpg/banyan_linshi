## 1. 范围

| 项 | 口径 |
|---|---|
| 职责 | 注册；共表分池；池内唯一；账号启用/禁用 |
| 非职责 | 不签发票、不作废会话（`auth-session`）；不按 mall / mall-online 拆两套用户表；不审店；不收钱；不下单 |
| 暴露面 | mall：店铺池。mall-online：众享源品 - 在线商城池（进程未建，语义预留）。后台启用/禁用沿用现码入口 |
| 稳定 ID | `user`（ADR-017） |

**一张表、两个池，不是多张表。** 继续使用现有 `user` 表，**不新建**众享源品 - 在线商城用户表（DEC-003）。众享源品 - 在线商城用户**不是**虚拟店会员，不占用官方 `merchant_id` 冒充自营（DEC-006）。

两池：

| 池（逻辑名，不是列名） | 唯一性 | 登录方式本期 |
|---|---|---|
| 众享营销 - 本地生活池 | 店 + 手机号 | 沿用现码（微信等）；**不**自动开与众享源品 - 在线商城同一套账号密码（REQ-072） |
| 众享源品 - 在线商城池 | 商城池 + 手机号/账号 | 手机号或账号密码（REQ-071）；口令存储属 `auth-session` |

同一手机号可以对应三个互不替代的账号：店 A、店 B、众享源品 - 在线商城。店 A 会员不能直接当店 B 或众享源品 - 在线商城用户。

## 2. 组件

| 组件 | 位置（逻辑） | 职责 |
|---|---|---|
| RegisterShop | mall | 在指定店的店铺池注册；池内按店+手机号唯一 |
| RegisterMallOnline | mall-online | 在众享源品 - 在线商城池注册；不绑某家店、不写官方店身份 |
| AccountQuery | 本池各端 | 按池查找账号；缺池或池不匹配则当不存在 |
| EnableDisable | 沿用现码后台 | 启用/禁用沿用现码（资料未重写状态机） |
| PoolGuard | 被 `trade` / `auth-session` 只读 | 认人必须带池；禁止串池 |

进程只作暴露面。数据共库。不按进程独占一张用户表。mall 不服务众享源品 - 在线商城池；mall-online 不服务店铺池。

## 3. 调用流程

### 3.1 店铺池注册（众享营销 - 本地生活）

1. 当前店来自 `auth-session` 认店，**不信客户端店号**。
2. 在该店的店铺池查找手机号。已存在：本店会员，不新建。
3. 不存在：在**同一张** `user` 表新增一条店铺池账号，归属该店。不得把店 B 或众享源品 - 在线商城的同号账号当成已注册。
4. 打开店 B 小程序：即使同号已在店 A 注册，仍须在店 B 再注册（REQ-070）。

### 3.2 众享源品 - 在线商城池注册 / 登录对象

1. 在众享源品 - 在线商城池按手机号或账号查找。未注册须单独注册，不能用店铺池账号顶替。
2. 仅有众享营销 - 本地生活账号时，用该密码登众享源品 - 在线商城：**不能**当作已注册众享源品 - 在线商城用户（REQ-071）。
3. 登录成功后的短票/长票由 `auth-session` 签发；本模块只提供「本池账号是否存在、是否启用」。
4. 不得把众享源品 - 在线商城用户写成某家官方店的会员，也不得用 `is_self` 或空店铺身份冒充自营。

### 3.3 启用 / 禁用

沿用现码启用/禁用。资料未重写细则，本文不发明新状态机。禁用后：本池账号不可再作为登录对象；是否立刻作废会话由 `auth-session` 执行（闸立刻废），本模块不发票。

### 3.4 给只读方

| 只读方 | 读什么 | 本模块不做什么 |
|---|---|---|
| `auth-session` | 本池账号是否存在、是否启用；签发对象 | 不签发票、不作废 |
| `trade` | 下单/查单/支付回调认人：`用户标识 + 池` | 不写订单 |
| mall | 仅店铺池 | 不读众享源品 - 在线商城池当本店会员 |
| mall-online | 仅众享源品 - 在线商城池 | 不读店铺池当商城用户 |

缺池或池不匹配：当该人不存在。支付回调不得跨池认人（REQ-073）。

## 4. 状态机

```text
enabled   →  disabled  （沿用现码禁用）
disabled  →  enabled   （沿用现码启用）
```

无第三套「众享源品 - 在线商城专用」状态机。池不是状态，是身份维度。

## 5. 逻辑数据（不冻结 DDL）

现码：`user` 按 `merchant_id` 按店隔离。目标：仍是**这一张表**，增加**池**语义，使众享源品 - 在线商城与店铺账号可并存且互不替代。

| 实体（逻辑） | 权威 | 含义 |
|---|---|---|
| UserAccount | 本模块 | 一行一个池内账号；继续落在现有 `user` 表 |
| ShopPoolKey | 本模块 | 店 + 手机号 唯一 |
| MallOnlinePoolKey | 本模块 | 商城池 + 手机号/账号 唯一 |
| EnableFlag | 本模块 | 启用/禁用沿用现码 |

**列名已确认（DEC-045）：** `user.user_pool`、`order_info.user_pool`；`1`=店铺池，`2`=众享源品 - 在线商城池。存量一律 1，含 `merchant_id=0`。索引 `(user_pool, merchant_id, mobile)`，本批不加 UNIQUE。不得拆成 `user_shop` / `user_online` 两张表，也不得按进程复制两套用户表。

不在本模块存：会话、作废名单、口令明文或不可逆口令的存储方案（口令属 `auth-session`）、订单。
