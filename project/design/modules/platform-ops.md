本文件是 G8 **Approved**（ADR-039）。已 **Baselined**（TECH_BASELINE=v0.1.5）。不能当作已开工。不改业务代码。不创建 `app/mall-online`。REST 路径与表结构以日后 `api/`、`database/` 为唯一真源；本文只给逻辑边界。G6 架构已 Approved（ADR-040），仅引用。待配置保持 TBD，批准后也不得编造。**编码以 PRD v0.1.19 / DEC-039 为准：** 众享源品 - 在线商城首页读平台 `banner`；本地生活仍不读本表。盖章稿「禁止接到任何 C 端」已被 DEC-039 部分替代。

## 1. 范围

| 项 | 口径 |
|---|---|
| 职责 | 平台 `banner` 表与 admin「内容 → 轮播管理」现码；菜单和表保留；众享源品 - 在线商城首页可读（DEC-039） |
| 非职责 | 不读各供应商 `merchant_banner` 做在线商城的顾客端；不新建众享源品 - 在线商城根菜单；不拥有审店/审品/树/四套菜单/财务/小魔推 |
| 暴露面 | admin 维护。mall-online / 众享源品 - 在线商城首页读本表。mall / 众享营销 - 本地生活 **不**读本表做首页 |
| 稳定 ID | `platform-ops`（ADR-017） |

三套轮播**不是**同一套：

| 表（现码名，不是新设计） | 主人 | 本期 C 端 |
|---|---|---|
| 平台 `banner` | 本模块 | 众享源品 - 在线商城首页（DEC-039）；无数据可空或占位 |
| 店铺 `merchant_banner` | 店铺现码，不属本域 | 本地生活店内轮播（装修） |
| 周边 `nearby_banner` | 周边现码，不属本域 | 周边现状 |

众享源品 - 在线商城首页轮播**以**平台 `banner` 为准（REQ-110 / DEC-039）。不要求运营必须先配图。本地生活不以本表为准。

小魔推属 `promotion`（ADR-015、DEC-010）。「设为自营」已退出业务规则（DEC-006 / REQ-112），本模块不收回该能力，本期也不为删 `is_self` 列。

## 2. 组件

| 组件 | 位置（逻辑） | 职责 |
|---|---|---|
| BannerAdmin | admin 现码 | 沿用轮播 CRUD；不新写页面清单 |
| BannerKeep | 共库 `banner` | 保留表与存量；禁止删除「为了减范围」 |
| GongyiHomeRead | mall-online / 众享源品 - 在线商城首页 | 读启用中的平台 `banner`（DEC-039）；无数据可空或占位 |
| NoLocalLifeRead | mall / 众享营销 - 本地生活 | **禁止**把本表接到店内首页 |

数据共库。不按进程独占 banner 表。mall-online **因 DEC-039** 读平台 banner 做众享源品 - 在线商城首页。

## 3. 调用流程

### 3.1 平台后台维护

1. 平台运营打开现码轮播管理，增删改沿用现码。
2. 保存只写平台 `banner`。不得写入 `merchant_banner` 或 `nearby_banner`。
3. 不强制运营必须先配图。

### 3.2 C 端

1. 本地生活首页轮播继续走店铺 `merchant_banner`（装修），不读平台 `banner`。
2. 周边继续走 `nearby_banner`。
3. 众享源品 - 在线商城首页读平台 `banner`（DEC-039）。
4. 不因此单开众享源品 - 在线商城根菜单。

### 3.3 明确不交接给本域

| 他人 | 本模块不抢 |
|---|---|
| `onboarding` | 审店 |
| `goods` | 审品 |
| `tree` | 业态树 |
| merchant 暴露面 | 四套菜单模板 |
| `trade` | 财务 |
| `promotion` | 小魔推、推广员注入 |
