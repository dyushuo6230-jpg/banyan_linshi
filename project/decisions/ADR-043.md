- 主题：是否将 G9 三夹从 Draft 转为 Approved
- 选择：方案 A
- 限制条件：NONE
- 被拒方案：B（保持 Draft，开始 G10）、C（保持 Draft，也不批准、不开 G10）
- 知情决策证据：INFORMED_REVIEW → INFORMED_CONFIRMATION → DECISION_APPLY

## 已确认规则

1. 下列三夹为 **Approved**，作为本期 API / 数据 / 工程规范真源：
   - `api/`
   - `database/`
   - `standards/`（含 `PROJECT_STRUCTURE.md` 与 `deploy/sql` 可重复增量约定）
2. **不是** Baselined。不改业务代码。不开开发批次。不创建 `app/mall-online`。不写真实 SQL。
3. TBD 继续待配置，批准后也不得编造。
4. G6 / G7 / G8 保持已批准。正文口径不改。
5. 本期仍跳过 G9.5。**不**自动进入 G10。G9.1 另开题。

## 未扩大

- 不启动 G10
- 不生成 G9.1 应用目录
- 不把待配置清零
