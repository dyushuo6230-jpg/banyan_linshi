- 选择：方案 A

- 被拒方案：B（先写 `auth-session`）、C（先批准已有 `tree` / `onboarding`、本轮不写下一模块）

## 已确认规则

1. G8 第三份详细技术设计是 `goods`（商品）。
2. 产物：`docs/project/design/modules/goods.md`，状态 **Draft**，不是 Approved / Baselined。
3. `tree.md` / `onboarding.md` **保持 Draft**，不升格 Approved。
4. 只设计该模块。不生成 `trade` / `auth-session` / `group-seckill` 等其余模块。不批准 G6 架构。不创建 `app/mall-online`。不改业务代码。
5. 待配置（驳回再提/编辑是否重审、批量部分成功是否整批回滚、类目停用后已上架商品）保持 TBD，不得编造。

## 未扩大

- 不批准任何 G8 设计为 Approved
- 不启动 `trade` 及后续模块设计
- 不冻结 OpenAPI / DDL（属 G9）
