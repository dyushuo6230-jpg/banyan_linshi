- 主题：平台 banner 与尚无主人的平台侧配置做成独立技术模块；板块是否并进本域
- 选择：方案 A；v1.1.0 板块进本域，不并进 banner 表、不并进首页模块归属
- 限制条件：本批板块不覆盖支付（DEC-026 通道仍跟平台）；三表不进 PRD
- 被拒方案：B（并进入驻或业态树，或把 admin 进程当成模块）、C（G7 不列技术模块）；把板块并进 banner 或 DEC-046 归属
- 知情决策证据：INFORMED_REVIEW → INFORMED_CONFIRMATION → DECISION_APPLY；v1.1.0 袋内 BAG-D6/D15/D21/D23 后第 39C 纳入
- 关联变更：CR-045、CR-047

## 已确认规则

1. 平台运营是 **独立**能力域技术模块。收口平台 `banner` 表与「轮播管理」现码，以及 **v1.1.0 板块**（列表/内容/租户报名）。不并进入驻或业态树，也不把 admin 进程当成模块（ADR-008）。
2. banner 菜单和表 **不删除**。众享源品 - 在线商城**购物首页**读取以 **DEC-039** 为准。附近顶 banner 用板块子列表，不是购物首页平台 banner 表（DEC-069）。不因此新建众享源品 - 在线商城根菜单。众享营销 - 本地生活不展示平台 banner **不** 视为缺陷。
3. **不** 拥有审店（入驻，ADR-013）、审品（商品，ADR-009）、业态树（ADR-013）、四套菜单（merchant 暴露面，ADR-008）、订单财务（交易，ADR-049）、小魔推（推广，ADR-015）。板块商品报名审核属于本域运营审核，不是商品域审品（审品仍 ADR-009）。
4. 不得把平台 `banner`、店铺 `merchant_banner`、周边 `nearby_banner`、板块子列表混成一套。板块不是 DEC-046 首页模块归属。不是 ToB 轮播/入口/分类/产品。
5. 进程仍只作暴露面：现码入口在 admin；mall-online 读平台 banner 做购物首页（DEC-039），按板块标识取当前板块内容（DEC-069）。数据仍共库，不按进程独占表。
6. 模块英文 ID 字符串本题不冻结。实现表名/索引/SQL 编号不进本 ADR 与 PRD。
7. **本 ADR 不生成** `MODULE_BOUNDARIES.md`。G7 仍为部分完成。
