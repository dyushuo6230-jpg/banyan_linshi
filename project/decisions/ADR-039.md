## 已确认规则

1. `docs/project/design/modules/platform-ops.md` 状态为 **Approved**，作为平台 `banner` 与 admin 轮播管理现码的本期边界真源。
2. **不是** Baselined。不改业务代码。不开开发批次。不创建 `app/mall-online`。
3. 只收口平台 `banner`。三套不混：平台 `banner` / 店铺 `merchant_banner` / 周边 `nearby_banner`。小魔推不属本域。众享源品 - 在线商城首页读取以 **DEC-039** 为准（本 ADR 当时禁止对接 C 端已被部分替代）。不单开众享源品 - 在线商城根菜单。
4. 已标明的 TBD 继续待配置，批准后也不得编造（改挂、根菜单本期均为禁止，不是可写死的「以后默认改挂」）。
5. 文档进度 G8 行仍按整夹 Draft 计，**不**因十份均 Approved 而在本题升格整夹。
6. **不**批准 G6 五份架构。**不**进入 G9。本批到此停止。
