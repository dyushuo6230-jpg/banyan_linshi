## 已确认规则

1. G8 第四份详细技术设计是 `trade`（交易）。
2. 产物：`docs/project/design/modules/trade.md`，状态 **Draft**，不是 Approved / Baselined。
3. `tree.md` / `onboarding.md` / `goods.md` **保持 Draft**，不升格 Approved。
4. 只设计该模块。不生成 `group-seckill` / `auth-session` / `fulfillment` 等其余模块。不批准 G6 架构。不创建 `app/mall-online`。不改业务代码。
5. 待配置（结算周期、部分成功拆单、退款状态机、订单完善字段清单）保持 TBD，不得编造。

## 未扩大

- 不批准任何 G8 设计为 Approved
- 不启动 `fulfillment` 及后续模块设计
- 不冻结 OpenAPI / DDL（属 G9）
