## 已确认规则

1. `docs/project/design/modules/group-seckill.md` 状态为 **Approved**，作为本地生活拼团/秒杀活动生命周期的本期设计真源。
2. **不是** Baselined。不改业务代码。不开开发批次。不创建 `app/mall-online`。
3. `tree.md` / `onboarding.md` / `goods.md` / `trade.md` / `fulfillment.md` 保持已批准。其余四份 G8 设计 **保持 Draft**，本次不批准。
4. **不** 因此批准 G6 五份架构。**不** 进入 G9。
5. 已标明的 TBD 继续待配置，批准后也不得编造，包括：活动进行中租户停用细则、拼团是否出核销码、平台原审核菜单如何改名、超卖件数。
6. 文档进度 G8 行仍按整夹 Draft 计，不因只批一份升格。
7. **不改**已批准 `trade` / `fulfillment` 正文。成交走 `trade` 店账户；履约按业态读 `fulfillment`。
