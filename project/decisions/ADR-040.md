- 主题：是否将 G6 五份总体架构从 Draft 转为 Approved
- 选择：方案 A
- 限制条件：NONE
- 被拒方案：B（先升 G8 整夹、G6 继续 Draft）、C（G6 保持 Draft、开始 G9）
- 知情决策证据：INFORMED_REVIEW → INFORMED_CONFIRMATION → DECISION_APPLY

## 已确认规则

1. 下列五份状态为 **Approved**，作为总体架构本期真源：
   - `architecture/SYSTEM_CONTEXT.md`
   - `architecture/OVERALL_ARCHITECTURE.md`
   - `architecture/SECURITY_ARCHITECTURE.md`
   - `architecture/DEPLOYMENT_ARCHITECTURE.md`
   - `architecture/NON_FUNCTIONAL_REQUIREMENTS.md`
2. **不是** Baselined。不改业务代码。不开开发批次。不创建 `app/mall-online`。
3. 已标明的 TBD 继续待配置，批准后也不得编造，包括：本机端口是否死写成 8035、生产域名/证书、最短密码、QPS/SLA、消息/搜索/监控产品、灰度回滚细则（ADR-005 仍延期）。
4. G7 `MODULE_BOUNDARIES.md`、G8 十份设计保持已批准，本题不改其口径。
5. **不** 升 G8 整夹。**不** 进入 G9。

## 未扩大

- 不把 G8 整夹升为 Approved
- 不启动 OpenAPI / DDL
- 不把待配置清零
