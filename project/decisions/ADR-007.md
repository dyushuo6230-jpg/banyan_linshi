- 主题：mall 与 mall-online 复制后，技术模块按什么切、共享库表归谁
- 选择：方案 A
- 限制条件：NONE
- 被拒方案：B（按进程复制两套技术模块）、C（四个后端进程直接当四个技术模块）
- 知情决策证据：INFORMED_REVIEW → INFORMED_CONFIRMATION → DECISION_APPLY

## 已确认规则

1. 技术模块按**能力域**设稳定 ID（用户、商品、订单、支付、登录等；具体名称与清单本题不冻结）。
2. mall 与 mall-online 是同一能力域在两个进程上的**暴露面**，不是两套技术模块。模块 ID ≠ 进程名。
3. 数据仍共库。所有权按业务域 + 用户池/业态，**不按进程独占表**。`user` 仍共表分池（DEC-003）。本地生活订单权威在 mall；众享源品 - 在线商城订单权威在 mall-online。
4. mall-online 只暴露众享源品 - 在线商城 C 端能力。扫桌、认店、店账户支付、本地生活拼团秒杀 C 端只属于 mall（ADR-004）。
5. 不因此分库、不抽公共包、不创建 `app/mall-online`、不写路由清单正文（仍留 G8）。
6. 下单 + 支付 + 费率快照落在拥有该订单的进程内；不新增跨进程分布式事务。
7. **本 ADR 不生成** `MODULE_BOUNDARIES.md`。其余拆分争议未确认前，G7 评审/应用为部分完成。
