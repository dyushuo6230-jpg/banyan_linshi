## 已确认规则

1. 交易是 **一个**能力域技术模块，含下单、支付、抽佣费率快照。订单与支付不是两个技术模块。
2. 通道差异保留：本地生活支付到该店账户、回调走 mall（REQ-100）；众享源品 - 在线商城平台统一收、回调走 mall-online（REQ-101、ADR-003）。这是该模块内的两种通道 / 暴露面。
3. 下单 + 支付 + 费率快照仍落在**拥有该订单的进程**内；不新增跨进程分布式事务（ADR-007）。不合并 mall 与 mall-online。
4. 租户订单与平台对账仍是同一工作台口径，可按业态 / 通道筛，不因此拆成「订单中心 + 支付中心」两套菜单，也不按业态拆两套订单模块。
5. 数据仍共库，按业态、用户池、通道区分，不按「两个支付模块」或「两套订单模块」独占表。
6. 结算周期、部分成功拆单、退款状态机本题不编造（ADR-003 未覆盖）。
7. 模块英文 ID 字符串本题不冻结。
8. **本 ADR 不生成** `MODULE_BOUNDARIES.md`。G7 仍为部分完成。
