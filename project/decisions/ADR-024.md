## 已确认规则

1. G8 第五份详细技术设计是 `fulfillment`（履约）。
2. 产物：`docs/project/design/modules/fulfillment.md`，状态 **Draft**，不是 Approved / Baselined。
3. 已有 `tree` / `onboarding` / `goods` / `trade` **保持 Draft**，不升格 Approved。
4. 只设计该模块。不生成 `group-seckill` / `auth-session` 等其余模块。不批准 G6 架构。不创建 `app/mall-online`。不改业务代码。
5. 待配置（核销有效期、过期是否退款、部分核销、清台细则）保持 TBD，不得编造。

- 不启动 `group-seckill` 及后续模块设计
- 不冻结 OpenAPI / DDL（属 G9）
