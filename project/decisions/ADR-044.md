- 主题：是否按 `PROJECT_STRUCTURE.md` 生成正式 UI 应用目录
- 选择：方案 A
- 限制条件：只生成目录和映射；不启用正式 UI_SPEC；不改 Element Plus / 小程序 / 众享源品 - 在线商城现有 UI；不编写未提供的后台设计规则；后台 UI 升级另议
- 被拒方案：B（跳过 G9.1 去 G10）、C（G9.1 和 G10 都不做）
- 知情决策证据：INFORMED_REVIEW → INFORMED_CONFIRMATION → DECISION_APPLY

## 已确认规则

1. 为下列 **6 个真实前端** 填写 `UI_APPLICATION_MAPPING.yaml`，并创建 `ui-design/products/{application_slug}/`（禁止虚构 `admin` / `miniapp` slug）：
   - `admin_web` → `nunu-go-api/app/admin/web`
   - `merchant_web` → `nunu-go-api/app/merchant/web`
   - `local_life_miniapp` → `go-uni-app`
   - `gongyi_online` → `go-uni-app-online`（devices：ios / android / harmony / miniapp / h5）
   - `onboarding_h5` → `nunu-go-api/app/h5`
   - `gongyi_h5_host` → `nunu-go-api/app/h5-online/web/dist`（整包产物进 Go embed，不是第二套逛买产品；DEC-049）
2. 将 G5.5 `UI_SCOPE_MAP` 五个逻辑终端对到上述 slug。`gongyi_h5_host` 无独立逻辑终端。
3. `ENABLE_UI_SPEC_GENERATION` 保持 **false**。`UI_CONSTRAINT_MODE` 保持 **NONE**。目录内若有 `UI_SPEC.md`，仅为占位，**不是**正式规范，**不能**当验收。
4. 不改业务代码，不改现有前端页面与组件库用法。两个后台继续现码 Element Plus；众享营销 - 本地生活与众享源品 - 在线商城继续现有已写页面（众享源品 - 在线商城页面口径仍 DEC-008）。
5. 不编写未提供的后台 Element Plus 设计规则（主题、间距、密度等）。后台 UI 升级 **另议**，本题不批准、不排期。
6. 本期仍跳过 G9.5。**不**自动进入 G10。不创建 `app/mall-online`。

## 未扩大

- 不启用正式 UI_SPEC
- 不生成 EFFECTIVE_UI_CONTRACT
- 不启动 G10
- 不把待配置清零
- 不把 PRD / G6 / G7 / G8 / G9 收成 Baselined
