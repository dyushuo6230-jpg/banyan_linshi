- 主题：是否将 G8 整夹从 Draft 转为 Approved
- 选择：方案 A
- 限制条件：NONE
- 被拒方案：B（整夹保持 Draft，开始 G9）、C（整夹保持 Draft，也不进 G9）
- 知情决策证据：INFORMED_REVIEW → INFORMED_CONFIRMATION → DECISION_APPLY

## 已确认规则

1. `design/modules/` 整夹进度行为 **Approved**。十份设计文件本身已是 Approved（ADR-030～039），本题不改其口径。
2. **不是** Baselined。不改业务代码。不开开发批次。不创建 `app/mall-online`。
3. 已标明的 TBD 继续待配置，批准后也不得编造。
4. G6 五份总体架构、G7 `MODULE_BOUNDARIES.md` 保持已批准。
5. **不** 进入 G9。**不** 写 OpenAPI / DDL / 工程规范正文。

## 未扩大

- 不启动 G9
- 不把待配置清零
- 不把十份设计升为 Baselined
