## 已确认规则

1. `docs/project/design/modules/trade.md` 状态为 **Approved**，作为下单、支付、抽佣费率快照、结算的本期设计真源。
2. **不是** Baselined。不改业务代码。不开开发批次。不创建 `app/mall-online`。
3. `tree.md` / `onboarding.md` / `goods.md` 保持已批准。其余六份 G8 设计 **保持 Draft**，本次不批准。
4. **不** 因此批准 G6 五份架构。**不** 进入 G9。
5. 已标明的 TBD 继续待配置，批准后也不得编造，包括：结算周期、部分成功拆单、退款状态机、订单完善字段清单。
6. 文档进度 G8 行仍按整夹 Draft 计，不因只批一份升格。
7. 本题 **不改正文**「已付之后餐饮走向扫桌」。扫桌时点以已确认 PRD / `fulfillment` 为准（下单前扫桌），不在本 ADR 重开。

## 未扩大

- 不批准其余六份设计
- 不批准总体架构 Approved / Baselined
- 不把待配置清零
- 不重开扫桌时点
