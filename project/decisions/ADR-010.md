- 主题：ToB 营销后端与 H5 落在哪个进程
- 选择：独立进程，从 mall-online / h5-online 形态复制再裁，只服务 ToB
- 限制条件：见下文；端口与域名以 DEC-067 为准
- 被拒方案：接到现有 mall；接到 mall-online；与源品共用静态进程
- 知情决策证据：用户书面确认部署单独新决策 + 产品轻量第四条线
- 背景：PHP ToB 站迁 Go；专用小程序；与本地生活、众享源品 - 在线商城隔离。

## 已确认规则

1. 新建独立进程：`nunu-go-api/app/mall-tob`（API）、配置目录 `config/mall-tob`。工程形态：从 `mall-online` 整棵复制再裁，首期落地 ToB 只读业务与必要壳接口。
2. 新建独立静态进程：`nunu-go-api/app/h5-tob`，配置目录 `config/h5-tob`。托管 `go-uni-app-tob` 整包 H5；**HTTP 前缀 `/wap/`**（DEC-067）。
3. 配置形态：`local` / `test` / `prod` + `.yml.example`；真实 yml 不进 Git。
4. `sms`、`db`、`redis`、`upload`、`storage` 可沿用与 mall 同连接（独立进程 ≠ 必须独立库）。`jwt.secret`、微信小程序配置、JWT Redis 键前缀须与 mall / mall-online **隔离**（实现前缀示例：`shop:mall-tob:*`）。
5. 本机端口与外网域名、发布 embed 顺序、客服页与校验文件路径：**只认 DEC-067**。
6. 前端工程 `go-uni-app-tob` 只打 mall-tob；禁止开发代理指向 8032 / 8035 / 8033。
7. PRD 以业务范围验收（CR-042）；不以「目录是否存在」单独当业务条款，但施工必须维持独立进程。

## 未扩大

- 不在本 ADR 冻结 Redis db 数字
- 不规定 ToB 与源品/本地生活用户池合并
- 不把 PHP 壳接口清单写入本 ADR（过渡实现，非正式能力清单）
