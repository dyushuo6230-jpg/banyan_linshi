- 主题：商品做成一个技术模块，还是按本地生活 / 在线商城拆开
- 选择：方案 A
- 限制条件：NONE
- 被拒方案：B（拆成两个商品技术模块）、C（商品之外再拆独立审核模块）
- 知情决策证据：INFORMED_REVIEW → INFORMED_CONFIRMATION → DECISION_APPLY

## 已确认规则

1. 商品是 **一个**能力域技术模块。本地生活与在线商城是该模块内的两种流程 / 暴露面，不是两个商品模块。
2. 流程差异保留：本地生活用店内分类、过审后本店可售、不进众享源品 - 在线商城；在线商城用经营类目树、过审后众享源品 - 在线商城可售（DEC-016）。
3. 平台商品审核仍是 **同一工作台**，可混勾批量通过/驳回（DEC-018）。不因此拆成两套审核菜单或独立审核模块。
4. 租户仍是一套后台、四套菜单模板（DEC-002、ADR-008）。
5. 数据仍共库，按业态与可售渠道区分，不按「两个商品模块」独占表。
6. 模块英文 ID 字符串本题不冻结。
7. **本 ADR 不生成** `MODULE_BOUNDARIES.md`。G7 仍为部分完成。
