- 主题：推广员入驻注入与小魔推做成独立技术模块，还是拆进入驻/商城，还是不算模块
- 选择：方案 A
- 限制条件：NONE
- 被拒方案：B（推广员并进入驻、小魔推并入 mall/商品）、C（G7 不列技术模块，只脚注「现码保留」）
- 知情决策证据：INFORMED_REVIEW → INFORMED_CONFIRMATION → DECISION_APPLY

## 已确认规则

1. 推广是 **独立**能力域技术模块，同时托管「推广员入驻注入」（REQ-120）和「小魔推」现码（REQ-111、DEC-010）。不并进入驻（ADR-013），不并入商品，也不只当脚注。
2. 推广员入驻注入 **不是** 小魔推（DEC-010）；二者是同一域里两块现码，不是本期两套改造。
3. 本期 **不删除、不改造、不纳入必验**。入驻、菜单、发品、逛买、登录、支付不以完整小魔推为交付物。不批准停用或拆掉小魔推。
4. 进程仍只作暴露面：现码入口继续在 mall / merchant（及众享营销 - 本地生活）上可用。mall-online **不**因此新做小魔推。入驻 H5 仍由入驻域提供页面，推广域只保留现码注入，不拥有审店。
5. 数据仍共库，沿用现码表与入口，不按进程独占表。登录密钥仍走认证会话（ADR-012、DEC-005）。
6. 模块英文 ID 字符串本题不冻结。四套菜单是否露出小魔推、推广员是否改造、金豆/积分细则本题不编造。
7. **本 ADR 不生成** `MODULE_BOUNDARIES.md`。G7 仍为部分完成。
