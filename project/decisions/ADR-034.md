## 已确认规则

1. `docs/project/design/modules/fulfillment.md` 状态为 **Approved**，作为餐饮扫桌、美发/商超核销的本期设计真源。
2. **不是** Baselined。不改业务代码。不开开发批次。不创建 `app/mall-online`。
3. `tree.md` / `onboarding.md` / `goods.md` / `trade.md` 保持已批准。其余五份 G8 设计 **保持 Draft**，本次不批准。
4. **不** 因此批准 G6 五份架构。**不** 进入 G9。
5. 已标明的 TBD 继续待配置，批准后也不得编造，包括：核销有效期、是否一次以外次数、过期是否退款、部分核销、退款后码如何作废、被误迁的美发/商超如何补核销。
6. 文档进度 G8 行仍按整夹 Draft 计，不因只批一份升格。
7. **不改**已批准 `trade.md` 正文。扫桌时点以 PRD / 本份 `fulfillment` 为准（下单前扫桌）。

- 不批准其余五份设计
- 不批准总体架构 Approved / Baselined
