## 已确认规则

1. 本期技术模块稳定 ID **冻结为以下 10 个**。模块 ID ≠ 进程名。admin / merchant / mall / mall-online **不是**技术模块。

| 稳定 ID | 中文 | 依据 |
|---|---|---|
| `tree` | 业态与经营类目树 | ADR-013 |
| `onboarding` | 入驻 | ADR-013 |
| `goods` | 商品 | ADR-009 |
| `group-seckill` | 拼团秒杀 | ADR-011 |
| `fulfillment` | 履约 | ADR-014 |
| `trade` | 交易（下单+支付+抽佣快照+结算） | ADR-049 |
| `user` | 用户 | ADR-012 |
| `auth-session` | 认证会话 | ADR-012 |
| `promotion` | 推广 | ADR-015 |
| `platform-ops` | 平台运营 | ADR-016 |

2. PRD 业务模块到技术模块映射：

| PRD | 技术模块 | 说明 |
|---|---|---|
| M01 | `tree` | 抽佣**快照**仍在 `trade` |
| M02 | `onboarding` | 入驻只读 `tree`，不拥有树 |
| M03 | 无（merchant 暴露面） | 四套菜单不是技术模块（ADR-008、DEC-002） |
| M04 | `goods` | 品牌库附属商品域（DEC-009） |
| M05 | `fulfillment` + mall 暴露面 | 认店走 `auth-session`；付钱走 `trade` |
| M06 | `group-seckill` | 成交走 `trade`；本期仅本地生活 |
| M07 | 无（mall-online 暴露面） | 逛买读 `goods` / `user` / `trade` |
| M08 | `user` | 共表分池 |
| M09 | `auth-session` | 票按进程隔离 |
| M10 | `trade` | 两种支付通道 |
| M11 | `platform-ops` | 仅 banner；小魔推在 `promotion` |
| M12 | `promotion` | 与小魔推同一域、两块现码 |

3. **不进**本期技术模块清单：消息、任务、通知、搜索、监控容灾（ADR-005 延期）。
4. G8 设计文件按上述 10 个 ID 落文档。不因此创建 `app/mall-online`，不改业务代码，不改页面。
5. **本 ADR 不生成** `MODULE_BOUNDARIES.md`。G7 拆分争议已齐；边界正文已由 **ADR-018** 生成 Draft。
