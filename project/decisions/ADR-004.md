- 主题：mall-online 工程如何从 mall 长出
- 选择：方案 A
- 限制条件：NONE
- 被拒方案：B（新建瘦服务、不复制点餐/核销/认店代码）、C（先抽公共 internal 包再两边引用）
- 知情决策证据：INFORMED_REVIEW → INFORMED_CONFIRMATION → DECISION_APPLY

## 已确认规则

1. 开发批次中按 mall 的目录与启动方式（`cmd/server`、`internal`、`api`、配置加载）**复制一套独立工程**到 `nunu-go-api/app/mall-online`。两个进程，不是一个二进制。
2. 复制后**不得对外暴露本地生活专用能力**，包括但不限于：扫桌点餐、认店、店账户支付、本地生活拼团秒杀 C 端接口。须有路由/能力清单，清单正文留 G8。
3. 不抽本期公共 internal 包给 mall 与 mall-online 共用（方案 C 不做）。
4. 配置、JWT、支付口径仍分别遵循 ADR-001、ADR-002、ADR-003。
5. 现在 `ALLOW_CODE_CHANGES=false`，本 ADR **不创建目录、不改业务代码**。
