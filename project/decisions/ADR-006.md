## 已确认规则

1. 生成本期 G6 Draft，且仅为 **Draft**，不得标 Approved / Baselined：
   - `architecture/SYSTEM_CONTEXT.md`
   - `architecture/OVERALL_ARCHITECTURE.md`
   - `architecture/SECURITY_ARCHITECTURE.md`
   - `architecture/DEPLOYMENT_ARCHITECTURE.md`
   - `architecture/NON_FUNCTIONAL_REQUIREMENTS.md`
2. 只采用已批准 PRD 与 ADR-001～005。延期项在 Draft 中标 TBD，不编造产品名或方案。
3. 不生成 `MODULE_BOUNDARIES.md`（属 G7）。不创建 `nunu-go-api/app/mall-online`。不改业务代码。
4. Draft 不能当作已开工；未另开开发批次前不得实施。

## 未扩大

- 不批准架构 Approved / Baselined
- 不启动 G7 模块边界写入
- 不把无编号待配置写成已确认
