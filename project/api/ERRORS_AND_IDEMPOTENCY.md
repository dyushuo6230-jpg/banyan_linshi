HTTP 状态与业务码沿用现码习惯。下列是本期必须可区分的**语义**，不是新发明的数字码表（数字码实施时映射现码，不在此编造码值）。

## 1. 必须可区分的失败语义

| 语义 | 典型场景 |
|---|---|
| UNAUTHENTICATED | 无票、废票、过期 |
| FORBIDDEN | 租户写树、审自己、串进程用票 |
| WRONG_POOL | 订单/用户读写池不匹配 |
| NO_BUSINESS_TYPE | 第五业态、到店当业态 |
| NO_COMMISSION_LEVEL | 在线商城未挂一级：不可售、不可下单 |
| APPLY_NOT_PENDING | 重复通过入驻 |
| GOODS_NOT_AUDIT_PASS | 未过审当可售 |
| PAY_CHANNEL_MISMATCH | 本地生活单进平台号或众享源品 - 在线商城单进店账户 |
| TREE_ROOT_IMMUTABLE | 删除四根或改稳定 code |
| CREDENTIAL_ONCE | 旁路口令二次读取 |

批量审核：失败条不得显示为通过。整批是否回滚 **TBD**，响应必须给出每条结果。

## 2. 分页

沿用现码页码分页。列表默认不返回已停用树节点（入驻/发品选择器）。审核列表应能按待审、业态过滤。

## 3. 幂等

| 场景 | 口径 |
|---|---|
| 入驻审核通过 | 同一申请只开一户 |
| 下单 | 业务单号防重 |
| 支付回调 | 已付则忽略第二次成功回调，不改快照、不双入账 |
| 树创建 | 请求号或业务键防双插 |
| 登出 | 重复调用仍为已作废 |

无消息队列（ADR-005）。补偿不新编主题名。

## 4. 兼容

- 新字段用加、不改旧字段含义。
- 旧 `merchant_category` 可读，不作新申请权威。
- mall-online 新进程新票，不要求旧 mall 票升级互认。
- 现码未改路径保持；删除的仅是 mall-online 上的本地生活专用路由。
