## 1. 进程与鉴权

| 进程 | 端口现状 | 鉴权 | 票互认 |
|---|---|---|---|
| admin | 8031 | Cookie + CSRF | 不认 C 端票 |
| merchant | 8033 | Cookie + CSRF | 不认 C 端票 |
| mall | 8032 | Header 票；认店只限本进程 | 不认 mall-online 票 |
| mall-online | 未建（建议 8035） | Header 票；独立 jwt.secret | 不认 mall 票 |
| 入驻 H5 | 8034 静态 | 入驻票 Header/现码通道；票面无手机号 | 废票不可提交 |

C 端短票 + 可作废长票约 7 天；C 端不做 30 分钟闲置。后台：忙不踢 / 闲必踢（30 分钟）/ 闸立刻废 / 寿命 12 小时（DEC-005 已采用默认）。jwt.expire 配置秒数 **TBD**。

## 2. 暴露面（能力域 → 进程）

与 `MODULE_BOUNDARIES.md` 第 6 节一致。mall-online **不暴露**：扫桌、认店、店支付、本地生活拼团秒杀 C 端、新做小魔推。复制 mall 后删除这些路由（ADR-004）；清单以实施时对照现码 router 为准，本文不假装已有完整删除列表。复制后若仍挂扫码进店，属缺口，不是已批准能力（DEC-010 v1.1）。

## 3. 本期变更操作（逻辑名 → 建议路径）

路径按现码风格建议，实施可微调但不得改语义。未列出的现码登录/发品/下单/支付回调继续用。

### tree（仅 admin 写）

| 操作 | 方法 | 建议路径 | 幂等 |
|---|---|---|---|
| 整树/子节点 | GET | `/api/v1/business-tree` | 是 |
| 创建子节点 | POST | `/api/v1/business-tree/nodes` | 请求号或业务键防双插 |
| 改名/排序/费率 | PUT | `/api/v1/business-tree/nodes/:id` | 按 id |
| 启停 | PUT | `/api/v1/business-tree/nodes/:id/status` | 是 |
| 解析所属一级 | GET | `/api/v1/business-tree/nodes/:id/commission-level` | 是 |

只读方（merchant / mall / mall-online / 入驻）可提供只读 GET，不得写。拒绝第五业态根。

### onboarding

| 操作 | 调用方 | 建议 | 备注 |
|---|---|---|---|
| 读四根与一级 | H5 | GET `/api/v1/business-tree` 只读 | 一级个数强制 **TBD** |
| 提交申请 | H5 | 现码入驻提交 + 业态/一级字段 | 资质清单 **TBD** |
| 待审列表/通过/驳回 | admin | 现码审店路径扩展 | 通过：开户+绑定同一本地事务 |
| 读店铺业态与可售一级 | 各后台 | GET 店铺详情扩展字段 | |

无自营问项。`sales_id` 可注入，不得改 status。

### goods

| 操作 | 调用方 | 口径 |
|---|---|---|
| 本地生活发品 | merchant | 店内分类；送审；过审后本店可售 |
| 在线商城发品 | merchant | 挂树；未挂一级不可送审通过 |
| 审核列表/详情 | admin | 可筛业态；可混勾 |
| 批量通过/驳回 | admin | 每条独立结果；整批回滚 **TBD** |

品牌可选。拼团秒杀不进本审核台。

### trade

| 操作 | 进程 | 口径 |
|---|---|---|
| 下单 | mall | 店身份来自认店；本地生活按业态根费率快照 |
| 下单 | mall-online | 众享源品 - 在线商城池；按商品所属一级快照；无一级拒绝 |
| 支付/回调 | 各进程本通道 | 店账户 → mall 域名；平台号 → mall-online 域名 |
| 退款/结算 | 拥有该单的进程 | 沿用现码；周期 **TBD** |

禁止跨进程分布式事务。完善订单字段沿用现表、本期不加列（DEC-039）。

### fulfillment

| 操作 | 口径 |
|---|---|
| 扫桌 | 餐饮 **下单前**；mall |
| 核销 | 美发/商超 **支付成功后**；有效期 **TBD** |
| 餐饮核销码 | 本期不做 |

### user / auth-session

| 操作 | 口径 |
|---|---|
| 店铺池注册 | mall；同店同号返回已有 |
| 众享源品 - 在线商城池注册 | mall-online；不得用店铺池顶替 |
| 登录/登出/作废 | 各端本进程 |
| 重置口令 | 只亮一次 |
| 认店 | 仅 mall |

最短密码按 DEC-062 验收设密（后台 10 位四类至少三类；顾客端 8 位字母+数字）。池列名 **TBD**。

### group-seckill / promotion / platform-ops

- 拼团秒杀：仅 merchant + mall；平台不审；mall-online 不暴露。是否出核销码、进行中停用 **TBD**。
- 推广：现码路径保留，不新编必验接口。
- 平台 banner：admin 现码轮播管理保留；众享源品 - 在线商城首页读取（DEC-039）。
