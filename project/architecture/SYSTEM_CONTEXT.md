## 3. 系统边界（本期五端）

```text
                    ┌──────────── 微信 / 支付宝等支付通道 ────────────┐
                    │         阿里云短信 / OSS（沿用 mall 连接）        │
                    └─────────────────────┬───────────────────────────┘
                                          │
┌─────────┐  ┌──────────┐  ┌─────────┐  ┌──────────┐  ┌──────────────┐
│入驻 H5  │  │平台后台  │  │租户后台 │  │本地生活  │  │众享源品 - 在线商城 C 端 │
│h5      │  │admin     │  │merchant │  │go-uni-app│  │go-uni-app-   │
│:8034   │  │:8031     │  │:8033    │  │→ mall    │  │online        │
└────┬────┘  └────┬─────┘  └────┬────┘  └────┬─────┘  └──────┬───────┘
     │            │             │            │               │
     │            │             │            │               │ mall-online :8035
     │            │             │            │               │ h5-online :8036
     ▼            ▼             ▼            ▼               ▼
  静态托管     admin API    merchant API   mall API     mall-online API
  app/h5                    （一套系统）   :8032         众享源品 - 在线商城
  入驻部分 embed                             本地生活        平台统一收
                                          支付到店        H5 整包进 Go
```

众享源品 - 在线商城 H5：独立进程 `nunu-go-api/app/h5-online`，本机 **8036**，外网根路径进首页（DEC-049）。`go-uni-app-online` 开发代理打 **8035**。

## 4. 外部依赖

| 依赖 | 用途 | 引用 | 备注 |
|---|---|---|---|
| MySQL | 业务库，mall 与 mall-online **同一套** | ADR-001 | 独立进程 ≠ 独立库 |
| Redis | 会话作废、验证码等；同一实例，键或 db 隔离 | ADR-001、ADR-002 | mall 现用 db 2；mall-online 数字不冻结 |
| 阿里云短信 | 沿用 mall 的 sms 连接 | ADR-001 | |
| 阿里云 OSS / 上传 | 沿用 mall 的 upload/storage | ADR-001 | |
| 微信支付（店） | 本地生活支付到租户 | REQ-100 | 仅 mall |
| 微信支付（平台商户号） | 众享源品 - 在线商城统一收 | REQ-101、ADR-003 | 仅 mall-online；商户号数值 TBD |
| 微信小程序 | 本地生活认店；众享源品 - 在线商城独立 appid 配置项 | DEC-005、ADR-003 | 不得默认抄 mall 的 appid |

忽略且不做考虑：`nunu-go-api/mall-uniapp`、仓库根 `admin/`、`uni-app/`、`niucloud`。
