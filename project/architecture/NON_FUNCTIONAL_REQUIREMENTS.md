本文件是 G6 **Baselined**（ADR-040；TECH_BASELINE=v0.1.5）。资料未给 GMV、QPS、SLA 等量化指标，**不得编造**。监控与容灾细则延期（ADR-005）。待配置保持 TBD，批准后也不得编造。

**叠加 DEC-049 v1.0.2：** mall-online 本机 8035；众享源品 - 在线商城 H5 独立二进制 8036。`go-uni-app-online` 开发代理已打 8035。

## 1. 正确性与一致性

| 项 | 要求 | 引用 |
|---|---|---|
| 抽佣 | 新单用下单时节点费率快照；未挂一级不可售不可下单 | REQ-103、DEC-001、DEC-013 |
| 用户 | 分池不串号；订单带池 | REQ-070～073、DEC-003 |
| 支付 | 本地生活到店账户；众享源品 - 在线商城平台统一收 | REQ-100、REQ-101 |
| 会话 | 作废本端不得误伤对端 | ADR-002、DEC-005 |
| 业态迁移 | 无业态老店默认餐饮；不以 `is_self` 迁成在线商城 | DEC-011、DEC-006 |

事务边界（下单+支付+快照）的库表实现留 G8。消息驱动的最终一致 **TBD**（ADR-005）。
