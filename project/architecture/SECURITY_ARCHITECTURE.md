本文件是 G6 **Baselined**（ADR-040；TECH_BASELINE=v0.1.5）。不能当作已开工。不编造密钥、商户号。口令复杂度见 DEC-062（废止 DEC-039「不另定」）。消息/审计产品延期 ADR-005 处标 TBD。待配置保持 TBD，批准后也不得编造。

## 1. 目标

落实登录验收五条，并保证两套 C 端互不串票、互不串池、支付回调互不串进程。

| 验收条 | 含义 | 引用 |
|---|---|---|
| 忙不踢 | 后台持续操作不被无故踢下线 | REQ-080～091、DEC-005 |
| 闲必踢 | 离开超过闲置须重登（后台；C 端 30 分钟闲置本期不做） | REQ-080、PRODUCT_PRD §5.4 |
| 闸立刻废 | 退出或改密后旧会话立刻失效 | REQ-080～091、DEC-005 |
| 串不了店 | 客户端不能伪造店号进入他店；认店只限本地生活 | REQ-080、DEC-005 |
| 库无明文密码 | 口令不以明文旁路可登录 | REQ-080、DEC-005 |

## 2. 身份与用户池

| 规则 | 引用 |
|---|---|
| 复用 `user` 表，用池区分「众享营销 - 本地生活」与「众享源品 - 在线商城」；不新建众享源品 - 在线商城用户表 | DEC-003、REQ-070～073 |
| 池内唯一；众享源品 - 在线商城不是虚拟店；订单带池防串号 | DEC-003 |
| 同一手机号在店 A 小程序、店 B 小程序、众享源品 - 在线商城是三个独立账号 | REQ-070、PRODUCT_PRD §4 |
| 众享源品 - 在线商城须单独注册；手机号 + 账号密码 | REQ-071 |
| 池字段技术落地留 G8，不得改变分池语义 | DEC-003 未覆盖项 |

## 3. 认证通道

| 端 | 票模型 | 引用 |
|---|---|---|
| 平台后台、租户后台（网页） | Cookie + CSRF；本期不改为纯 Header | DEC-005、REQ-080 |
| 众享营销 - 本地生活 | Header 票；由 mall 签发与校验 | DEC-005、ADR-002 |
| 众享源品 - 在线商城小程序 / App / H5 | Header 票；由 mall-online 签发与校验 | DEC-005、ADR-002 |
| 入驻 H5 | 沿用现码入驻认证，不在本文发明新模型 | REQ-010 |

Cookie/CSRF 跨域配置细节待设计，不得改变「网页 Cookie、小程序 Header」口径。

## 4. 会话隔离（mall vs mall-online）

| 规则 | 引用 |
|---|---|
| mall-online **独立** `jwt.secret`，不得抄 mall | ADR-002 |
| 作废名单独立键前缀，或独立 `redis.db`；仍同一 Redis **实例** | ADR-002、ADR-001 |
| 众享源品 - 在线商城票不得被 mall 当作有效登录；反之亦然 | ADR-002 |
| 退出或改密只作废**本端**票，不得误伤另一端 | ADR-002、DEC-005 |
| `expire` 秒数、具体 Redis db 号不冻结（mall 现用 db 2） | ADR-002 |

生活化理解：两家店的门禁卡不能互开；作废众享源品 - 在线商城登录，不能把顾客在店里小程序的登录一并踢掉。

## 5. 授权与认店

| 规则 | 引用 |
|---|---|
| 租户后台按业态套菜单模板；隐藏不是安全边界，敏感能力须服务端校验 | DEC-002、REQ-020～021 |
| 认店**只约束众享营销 - 本地生活**；众享源品 - 在线商城无认店 | DEC-005 |
| 平台身份只看业态，不以 `is_self` 为自营规则 | DEC-006、REQ-112 |
| 在线商城供应商无独立小程序 | REQ-062 |
| 租户子账号口令规则随 M09；权限细节待配置 | REQ-080、PRODUCT_PRD §3 |

## 6. 支付与回调安全

| 规则 | 引用 |
|---|---|
| 本地生活：支付到该租户账户，回调走 mall | REQ-100 |
| 众享源品 - 在线商城：平台商户号统一收，不是店账户，也不是平台自营店收款 | REQ-101、DEC-006、ADR-003 |
| mall-online 独立 `wechat`；`pay_notify_url` / `refund_notify_url` 指向 **mall-online 自己的域名** | ADR-003 |
| 不沿用「按当前店切商户号」的本地生活逻辑 | ADR-003 |
| `mini_appid` / `mini_secret` 独立配置项，不得默认抄 mall；数值 TBD | ADR-003 |
| 未配齐支付通道前可先搭进程和登录，不编造商户号 | ADR-003 |
