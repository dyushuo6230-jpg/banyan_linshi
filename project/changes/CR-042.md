- 变更原因：ToB 营销已独立进程与后台配置落地，正式产品总册仍只有「本地生活 + 源品」，与代码和运维现实不一致。
- 业务规则变化：总册承认 ToB 为独立营销端（不是第四个本地业态根，也不是源品商城）；写清本期做/不做；端口域名不进 PRD 正文（见 DEC-067）。
- 影响范围：PRODUCT_PRD v0.1.40；模块索引一行；REQ-130；交付批次 DEV-012；协作规则补 ToB 禁串。
- 兼容 / 迁移 / 回滚：不改已确认的本地生活与源品规则。回滚须新 CR。
- 知情决策证据：用户书面 `部署=单独新决策；产品=轻量第四条线；规则=全纳分层；慎入=不进正文`。

## 不包含

- 营销子页面文件名清单、PHP 壳接口清单、种子数据行（慎入项，不进正式正文）
- 把 ToB 并入用户池或抽佣主链
- 客户留资闭环、数据看板后台配置页（本期明确不做）
