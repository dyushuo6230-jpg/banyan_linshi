- 变更原因：盖章 PRD v0.1.5 仍写「在经营类目树下挂一级、发品选项来自经营类目树」。实施已确认：结构权威在平台类目，经营类目不再挂子节点，只配费率/排序/启停。须把该口径收进 PRD，避免入驻/发品按过期真源编码。
- 业务规则变化：见 DEC-021。不推翻 DEC-001 / DEC-012 / DEC-013（同一套一级、未挂一级不可售）。
- 影响范围：PRODUCT_PRD v0.1.6、M01 REQ-002/004/007、M04 REQ-031/034、TRACE、OPEN_ITEMS。
- 兼容 / 迁移 / 回滚：不并表删除平台类目；不灌类目清单为行业标准。回滚须新 CR，不得把经营类目再做成第二套一级。
- 知情决策证据：DEC-021 已 APPLY；本窗用户确认「起草这一张 CR，收入 PRD」

## 不包含

- 通用树具体节点名称清单（DEC-012：不冻结进 PRD）
- 平台类目「添加子类目」等操作按钮（实现，不是新业务规则）
- 库表列名、增量 SQL 编号、接口 `source` 字段
- 类目停用后已上架商品（仍待配置）
- 入驻强制几个一级（仍待配置）
