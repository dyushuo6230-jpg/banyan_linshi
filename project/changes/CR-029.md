- 变更原因：后台订单/售后/金额展示仍夹杂旧口头语与平台介入入口，与 DEC-052 书面口径不一致；本批确认 C 端现用众享营销 - 本地生活 + 众享源品 - 在线商城一并对齐口语与售后入口。
- 业务规则变化：见 DEC-054。
- 影响范围：PRODUCT_PRD v0.1.30 Draft；M05、M06 REQ-050、M07 REQ-060、M10 REQ-105/107。无增量 SQL。不加订单字段。
- 兼容 / 迁移 / 回滚：库内金额仍为分；状态数字仍 10/20/30/50/60/70，售后 10/20/30/40。DEC-052 旧文件只读。回滚须新 CR。删仲裁/待收退货入口后，以后超管退款或退货收货主路径必须新开决策。
- 知情决策证据：袋内 D1～D6、D7A/B/C、D8、D9、CEND-SURF/STATUS/REFUND 均已确认应用；本窗 `对照表确认，按第 42 节 APPLY`

## 功能在哪看到

见 DEC-054「功能在哪看到」。短句：【平台/商家后台】运营与商家从「订单管理 / 售后 / 结算 / 评价」看见书面语、只读售后、元价签；【众享营销 - 本地生活现用页、众享源品 - 在线商城】顾客从「我的 / 订单」看见口语状态与仅 20/30 的申请入口。现在后台仍可能写待发货、露出介入；改完后台用书面语、平台只看、C 端不要待评价主状态。
