- 变更原因：袋内确认做独立商城拼团秒杀，与本地生活租户自发、平台不审不同。
- 业务规则变化：平台创建秒杀场/拼团场；仅在线商城已审商品报名；平台审核通过后源品 C 端可进、可下未付单。到期未成团关未付单、放库存，本批无真退。菜单：平台「商城秒杀」「商城拼团」各下场次与报名审核；租户「秒杀报名」「拼团报名」。不恢复已删「秒杀管理 / 拼团审核」。
- 影响范围：M06 REQ-052；M07 REQ-131；M03；ADR-011；DEV-013。
- 兼容 / 迁移 / 回滚：本地生活拼团秒杀菜单与 DEC-004 不改。回滚须新 CR。
- 知情决策证据：BAG-D4=A、D16=A、D22=A。用户 2026-09-15「下一步」纳入。
