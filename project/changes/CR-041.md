- 变更原因：页面不写死默认值之后，浏览器仍可能把旧账号填进登录框，或把登录名塞进 AppID。已确认登录与密钥配置都声明不要自动填。
- 业务规则变化：见 DEC-066。
- 影响范围：PRD v0.1.39 总册与 M09；开放项、追踪；白话登录篇、平台/租户后台相关段。
- 兼容 / 迁移 / 回滚：不改代码。回滚须新 CR。不承诺 Chrome 对登录框 100% 不填。
- 知情决策证据：`AFL-001=A` → 复述 → `确认该决策：AFL-001=A` 限制条件 NONE。

## 不包含

- 改业务代码（须开工口令）
- 升 Ready、开新 DEV
- 承诺关掉用户已在浏览器里保存的密码填充
