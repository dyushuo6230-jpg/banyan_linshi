- 变更原因：分类页现码有「甄选上新」假入口，右侧一次只画一个二级；与平台类目浏览和图2多模块同屏不一致。已确认「有图一比一」会挡住按你的口径改这一页。
- 业务规则变化：见 DEC-071。分类页无「甄选上新」；只读平台类目；右侧全部二级模块同屏，点胶囊定位；选中未选中同尺寸。本页不再验收设计稿该项与选中加高。
- 影响范围：PRD v0.1.43；M07 REQ-060/064；DEC-008 v1.2.0；DEV-013 批内，不开 DEV-014。
- 兼容 / 迁移 / 回滚：无类目数据迁移。回滚须新 CR。不改本地生活分类、不改平台类目树接口。
- 知情决策证据：`D-CAT-UI=A` → `确认该决策：D-CAT-UI=A` 限制条件 NONE。
