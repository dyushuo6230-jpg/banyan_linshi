- 变更原因：用户要求众享源品 - 在线商城本期也能打微信小程序；多端在同一套代码里写，有平台差异必须条件编译，编译只保留对应平台代码，避免冗余。
- 业务规则变化：见 DEC-029 v1.2.0。必打端 = iOS / 安卓 / H5 / 微信小程序。鸿蒙仍非必打。前端接口限缩与「其余必须闭口」不变。
- 影响范围：PRODUCT_PRD §5.1/§12、M07 REQ-060/065、CODING_STANDARDS 第 7 节。
- 兼容 / 迁移 / 回滚：回滚须新 CR。本窗不改代码（DEC-025）。
- 知情决策证据：用户直接补口径。评判：合理——现码即 `go-uni-app-online` 多端；申请支付常见要微信小程序；条件编译是同一套代码打多端的必要写法，不是另起工程。未撑破「仅页面前端接口限缩」。

## 不包含

- 前端接口逐条清单、各端 ifdef 清单、appid、支付商户号
- 鸿蒙必打
- 改业务代码
