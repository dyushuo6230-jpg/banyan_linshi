- 变更原因：设计图首页快捷区与已拍板营销范围不一致，袋内 BAG-D7=C。
- 业务规则变化：好友助力入口藏，不做助力业务。限时折扣点进商城秒杀列表，不另做折扣规则。品牌联盟点进「超级品牌」板块；平台未配该板块则藏联盟入口。
- 影响范围：M07 首页快捷区；依赖 CR-044/045。
- 兼容 / 迁移 / 回滚：不做三套新营销。回滚须新 CR。
- 知情决策证据：BAG-D7=C。用户 2026-09-15「下一步」纳入。
