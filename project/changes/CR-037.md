- 业务规则变化：见 DEC-062。新设 / 改密 / 重置 / 注册按端校验；登录已有密码只核对错。
- 影响范围：PRD v0.1.35 总册与 M09 / M08；开放项、追踪、编码规范、安全/接口总览中「不另定」的表述；白话登录篇。
- 兼容 / 迁移 / 回滚：不改代码、不改表、不批量改存量哈希。回滚须新 CR。存量怎么换、超管改名、禁止浏览器回填不在本 CR。
- 知情决策证据：`PWD-001=A` → 复述 → `确认该决策：PWD-001=A` 限制条件：填写密码时写明该端规则。
