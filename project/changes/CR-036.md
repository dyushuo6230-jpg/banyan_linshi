## 对照（人话）

| 禁用 | 现称 |
|---|---|
| 商家后台、商户后台 | 租户后台 |
| 商家、商户（指入驻经营的那一方） | 租户 |
| 餐饮商户 / 美发商户 / 商超商户 | 餐饮租户 / 美发租户 / 商超租户 |
| 商家入驻 H5 | 租户入驻 H5 |
| 商家端、商家 App | 禁止再写。说到网页写租户后台；说到出餐核销写本地生活小程序的店员页 |
| 大厅、优选、共益优选（口头） | 在线商城的顾客端 |
| 多商户（人话） | 多租户 |

产品全称不动：平台后台；众享营销 - 本地生活；众享源品 - 在线商城。业态仍叫餐饮 / 美发 / 商超 / 在线商城。在线商城供应商仍叫供应商。
