## 已确认规则

1. 众享源品 - 在线商城本期页面范围以 `go-uni-app-online` **现有页面**为准。
2. 同一能力若同时有新页面和旧页面：**以新页面为主**；新页面没有该功能时，才使用旧页面。
3. 《线上商城前端收敛与接口对接需求说明》只作路径/模块对照，**不是** PRD 附件，**不能**批准为 UI_SPEC。
4. 该说明中与已确认规则冲突的条款**不采用**，包括但不限于：本期不做真实支付（与 REQ-101 冲突）、必须新建 mall-online 进程（与 REQ-066 / DEC-005 冲突）、把 AI/发现做成必须对接的业务（与 REQ-063 冲突）。
5. 正式 UI 规范本期仍关闭（`ENABLE_UI_SPEC_GENERATION=false`）。**v1.1.0：** 不因此免除有设计图页的还原。SRC-UI-003（BATCH-003 19 张 PNG）覆盖到的现用页，按图一比一还原（间距、文案、入口显隐以图为准）。购物车、订单继续用旧页，不像素验收。无 PNG 的页（含商城拼团秒杀自编页、AI 整页假页）不卡像素。AI 视频/生图子页本批不做。**v1.2.0：** 「商品分类」页书面例外见 DEC-071。**v1.2.3：** 分类页听 DEC-071 **v1.3.0** / UI-DEC-005 / UI-DEC-006 / `category.vue`：不编造假入口；树上有的一级照出；左栏选中白边包金芯、箭头在内、选中加高；三级 CSS grid 三列；全部分类可滚；外底板不对《分类.png》米金条。视觉循环不得按「选中装饰不撑格子」或外侧箭头改回现码。其它有图页仍一比一。源品正式 UI_SPEC 分闸见 UI-DEC-001，不在本条废止。
6. 图上多出来、与已拍板打架的入口，按 DEC-053 v1.1 及后续 CR 藏或改跳，不得长期「敬请期待」当闭口——AI 整页假页是已点名例外（REQ-063）。分类页名称是否出现只听平台类目树（DEC-071），不编造假入口。
