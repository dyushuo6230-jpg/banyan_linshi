- 主题：餐饮/美发/商超普通商品是否必须平台审核通过才能在本众享营销 - 本地生活可售
- 选择：方案 A
- 限制条件：NONE
- 被拒方案：B（维持只审在线商城）、C（送审但不挡售卖）
- 知情决策证据：INFORMED_REVIEW → INFORMED_CONFIRMATION → DECISION_APPLY
- 关联变更：CR-001

## 已确认规则

1. 餐饮 / 美发 / 商超的**普通商品**须平台审核通过后，才能在本众享营销 - 本地生活作为可售商品。未过审、驳回均不可售。
2. 在线商城商品仍须平台审核通过后，才能在众享源品 - 在线商城可售。
3. 本地生活普通商品**不得**因此进入众享源品 - 在线商城货源。
4. **不推翻 DEC-004**：拼团 / 秒杀仍由租户发布、平台不审。
5. 平台商品审核工作台处理：在线商城送审 **以及** 本地生活普通商品送审。
6. 现码审核字段如何落地留 G8/G9，不得在本 DEC 编造状态机字段名。

## 已被 DEC-026 替代的条款

第 1、5 条（本地生活普通商品必审、审核台同时审两类）已被 **DEC-026** 废止。第 2、3、4 条仍有效。

## 未扩大

- 存量已在售本地生活商品如何迁
- 审核台是否批量通过/驳回
- 驳回后再提、通过后编辑是否重新审核（仍待配置）
- 拼团秒杀审核（保持 DEC-004）
