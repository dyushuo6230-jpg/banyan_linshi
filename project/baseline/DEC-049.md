- 主题：众享源品 - 在线商城独立进程本机端口是否写死；测试/正式 API 与 H5 用哪几个域名
- 选择：本机 HTTP 端口写死 **8035**；**测试一律 `.gyyx.store`，正式一律 `.zhengdeyunqi.cn`**
- 限制条件：不编造商户号、jwt.secret、小程序 appid；测试/正式容器内监听仍按现码习惯 8000 + Nginx 反代，外网只认下列域名
- 被拒方案：本机端口继续不冻结；测试域名写成正式域 `.zhengdeyunqi.cn`
- 知情决策证据：会话正文用户给出域名并要求端口写死；2026-09-10 纠正测试后缀为 `.gyyx.store`；H5 根路径进首页、h5-online 本机 8036
- 关联变更：无（配置与交付计划，不改 PRD 业务规则）
- 更正：v1.0.0 误把测试 API/H5 写成 `*.zhengdeyunqi.cn`；v1.0.1 按用户纠正为测试 `*.gyyx.store`；v1.0.2 众享源品 - 在线商城 H5 整包进 `app/h5-online`，根路径、本机 8036

## 已确认规则

1. **本机 API 端口写死 8035。** 与 8031 admin、8032 mall、8033 merchant、8034 入驻 H5、**8036 众享源品 - 在线商城 H5** 不冲突。开发代理、`go-uni-app-online` `.env.development` 只打 `127.0.0.1:8035`。
2. **众享源品 - 在线商城 C 端只调 mall-online。** 测试/正式 API：
   - 测试：`https://test-shop-online-api-go.gyyx.store`
   - 正式：`https://shop-online-api-go.zhengdeyunqi.cn`
3. **众享源品 - 在线商城打包 H5：**
   - 测试：`https://test-shop-online-h5-go.gyyx.store/`（根路径进首页，不用 `/wap/`）
   - 正式：`https://shop-online-h5-go.zhengdeyunqi.cn/`
   - 本机静态进程 `app/h5-online` 端口 **8036**。`go-uni-app-online` 整包拷到 `app/h5-online/web/dist` 后 `go:embed` 打进二进制。不挂微信业务域名校验文件。
4. 支付/退款回调打对应环境的 **mall-online API 域名**，不打 mall（`shop-api-go`）也不打租户后台。
5. 真实 yml 不进 Git。example 只写域名与端口；密钥仍 `CHANGE_ME`。
6. **ToB 营销部署见 DEC-067**（本机 8037/8038，H5 挂 `/wap/`），与本决策并列，不互相替代。
