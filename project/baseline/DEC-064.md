- 主题：平台超管登录名还叫不叫 `admin`；登录页要不要把账号或密码写死在表单上
- 选择：方案 A
- 限制条件：NONE
- 被拒方案：B（只改测试站、正式仍叫 `admin`）、C（只改显示名、登录仍填 `admin`）
- 知情决策证据：INFORMED_REVIEW → 用户书面 `ADM-001=A` → 复述 → 用户书面 `确认该决策：ADM-001=A` 限制条件 NONE
- 关联变更：CR-039

## 已确认规则

1. **改名：** 平台超管这一条登录名从 `admin` 改为 `ZadminDister`。用 `admin` 登录失败。新装/种子只建 `ZadminDister`，不再建登录名为 `admin` 的超管。显示名「超级管理员」可保留。若库里已有别人占用 `ZadminDister`，停止改名、报给人，不覆盖。
2. **会话：** 该号已登录会话作废，须用新登录名再登。
3. **口令：** 仍是同一账号。存量强制改密（DEC-063）不因改名豁免：用新名字 + 当前密码能进改密页，改成 DEC-062 后台规则前不能进日常菜单。本条不另发密码、不交总清单。
4. **登录框不写死：** 所有给人登的页面（平台后台、租户后台、两套顾客端），账号和密码输入框都不写死默认值。平台现码预填 `admin` 必须空出来，也不预填 `ZadminDister`。对外站不得带着「选一个演示账号就填上账号/密码」的下拉。
5. **不改谁：** 租户、店员、两套顾客端的登录名。代码路径、文件夹、会话种类里叫 `admin` 的内部名（不是登录账号）。

- 超管独占已由 DEC-065 收口

- 不把明文密码写入任何项目文件
