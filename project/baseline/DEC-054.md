## 功能在哪看到（人话 6 问总览）

1. **哪一端、哪业态**
   - 平台后台、租户后台：餐饮 / 美发 / 商超 / 在线商城供应商同一套订单书面语与金额尺子。
   - 众享营销 - 本地生活现用页：餐饮 / 美发 / 商超各店顾客端。
   - 众享源品 - 在线商城：App / 小程序 / H5 同一套前端。
   - 不改：入驻 H5、拷贝源旧商城页。
2. **谁**：平台运营、租户（四业态）、众享营销 - 本地生活顾客、众享源品 - 在线商城顾客。不用人点的只有库内金额仍按分存。
3. **怎么走进来**：平台/租户侧栏「订单管理 → 订单列表 / 售后管理」；租户「财务管理 → 结算账单」「商品管理 → 评价管理」；平台「商品管理 → 评价管理」；众享营销 - 本地生活底部或「我的 / 订单」；众享源品 - 在线商城「订单」。
4. **人在哪看见**：列表 tab 与状态列、来源/履约/租户列、金额、售后按钮、评价列表两列、结算明细表、C 端订单状态文案与申请售后入口。
5. **怎么操作**：打开列表/详情看见文案与按钮；租户仅发货类且状态 20 在详情发货；平台售后只看不办；顾客仅 20/30 能申请售后。
6. **现在怎样 / 改完怎样**：后台不再用待发货/待收货/已付款当 tab；平台不再露出介入；价签按元；C 端继续口语，不要待评价主状态，70 写已关闭。

## 已确认规则

1. **后台状态书面语（D1）。** 平台后台、租户后台的订单 tab / 状态列 / 导出 / 租户首页待办，必须用 DEC-052 书面语：10 待付款、20 已付待履约、30 履约中、50 已完成、60 已取消、70 已关闭。禁止用待发货、待收货、已付款作 tab 名。租户须有「已关闭」tab。租户首页「已付待履约」仍统计 `status=20`。不按业态换 tab 名（美发/商超「待核销」延期）。
2. **平台列表来源与履约（D1）。** 平台「订单管理 → 订单列表」须有来源（各店 / 众享源品 - 在线商城）和履约（堂食 / 核销 / 发货）。展示列不是新库字段。
3. **平台售后只读（D2）。** 平台后台售后只看，不办理同意/拒绝/仲裁。同意与拒绝只在租户后台。平台售后 tab：全部 / 待处理 / 已退款 / 已拒绝 / 已撤销。详情只读。首页去掉「平台介入售后」，待办不再数售后 80。不再出现 80 平台介入。
4. **人看金额用元（D3）。** 平台/租户订单、售后、结算、流水、提现、统计：给人看用元。租户提现按元填、提交按分入库；满 1000 元再确认。`system_config` 最低提现金额仍按分存储。库内金额仍为分。
5. **拼团/秒杀价签用元（D4）。** 仍存在的平台/租户拼团、秒杀列表与表单：展示和输入用元，提交按分入库。不改活动规则、不改 C 端、不把已删的平台经营入口加回来。
6. **众享源品 - 在线商城详情单笔发货（D5）。** 仅履约=发货且订单 20：租户在**订单详情**办理发货 / 限时改运单。堂食、核销详情不出现发货。不在列表行内发货。CSV 导出保留。
7. **本期去掉平台仲裁办理入口（D6）。** 在 DEC-052「不跑仲裁主路径」之上：本期平台侧**连办理入口也不留**。以后超管退款必须新开决策，不能把已删入口改成真退。现码若仍回「本期不走」是现状，不是保留入口。
8. **平台「租户」列显示店名（D7A）。** 平台订单列表「租户」列显示店名；没有店名再显示编号。不加订单字段。
9. **租户结算明细改成表（D7B）。** 租户「财务管理 → 结算账单」点「明细」后给人看一行一行的表，金额按元。四业态同一菜单同一按钮。不改抽佣、不改入账、不加结算字段。
10. **本期去掉租户待收退货办理通道（D7C）。** 在 DEC-052「不跑待收退货主路径」之上：租户售后详情正门仍是全额退款 / 拒绝 / 同步退款结果。本期不做「确认收到退货 / 拒绝收货」。以后若要退货收货主路径必须新开决策。不含众享源品 - 在线商城顾客确认收到商品。
11. **评价列表两列（D8）。** 平台/租户「商品管理 → 评价管理」增加「订单号」「评价时间」。记录里有才显示，没有就空着。评价仍独立，不改订单主状态。不加库字段。不从评价点进订单详情。
12. **平台订单可选筛选（D9）。** 平台订单列表可按来源、租户、下单日期筛。**刚打开仍是全部**。不加订单字段。不改租户订单列表。
13. **本批 C 端只改现用众享营销 - 本地生活 + 众享源品 - 在线商城（CEND-SURF）。** 不改入驻 H5（没有顾客订单列表）。不改拷贝源旧商城页（旧页若仍能打开，本批接受旧文案）。产品五端没有单独「租户小程序」。
14. **C 端顾客口语（CEND-STATUS）。** 不改状态机数字。不要 40、不要「待评价」主状态。70 展示「已关闭」，不要用「已退款」当订单主状态。众享源品 - 在线商城 20/30 继续「待发货 / 待收货」。众享营销 - 本地生活现用「待支付 / 已支付 / 已出餐」可留。已完成（50）可有评价按钮；评完订单仍是已完成。本条不要求打通真评价提交；众享源品 - 在线商城商品详情评价仍按 DEC-053。
15. **C 端售后入口（CEND-REFUND）。** 「申请退款 / 申请售后」只在订单 20、30 出现。50 / 60 / 70 不能新申请。已有售后单仍可查看；待处理可撤销。不要平台介入。售后状态 10 待处理 / 20 已退款 / 30 已拒绝 / 40 已撤销。众享源品 - 在线商城售后不办顾客填退货物流；退货是否寄回线下协商。
16. **展示列不是加表。** REQ-107 原「不加新列」收口为：不加**订单库字段**（DEC-039 / DEC-052 第 8 条仍有效）；列表/评价表可以加展示列。
