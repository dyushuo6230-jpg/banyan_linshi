- 主题：小魔推是否纳入本期多业态验收；mall 已落地扫码进店要不要补进正式文档
- 选择：QUESTION-010=A（不纳入必验）；DOC-36A-1=B（只补写本地生活 / mall 已落地现状，在线商城的顾客端仍禁止）
- 限制条件：先正式后白话；不改代码；不加必验；不开新 DEV；不改 `admin_menu`；不升 Ready；在线商城顾客端上误挂的路由留缺口；待配置不编造
- 被拒方案：QUESTION-010 的 B（写入本期验收范围）、C（移出本期且不承诺现网继续可用）；DOC-36A-1 的 A（正式文档不承认扫码进店）、C（在线商城的顾客端也写成可扫码进小魔推）
- 知情决策证据：QUESTION-010 INFORMED_REVIEW → INFORMED_CONFIRMATION → DECISION_APPLY；DOC-36A-1=B 已二次确认并应用
- 收窄：v1.1.0 允许「补写已落地现状」，仍不改造产品、仍不纳入多业态必验。不废止 ADR-004。

## 已确认规则

1. 小魔推**现码保留**，本期**不删除、不改造**，不新写改造清单。
2. **不纳入**本期多业态必验。入驻、菜单、发品、逛买、登录、支付不以完整小魔推为交付物。
3. 现网小魔推能力继续作为现状存在；本题**不批准**停用或拆掉。
4. 推广员入驻注入（REQ-120）**不是**小魔推，不在本 DEC 处理。
5. 登录密钥隔离仍走 DEC-005，本题不重开。
6. **允许补写 mall / 众享营销 - 本地生活已落地现状**（不是改造、不是必验）：顾客扫店码 → 中间页登录或注册 → 本店设备一人一机。开通须有合法渠道，配不好人能看见失败（不写配置键名）。
7. 注册或绑设备失败不发推广链；密码错不注册。
8. 众享源品 - 在线商城 / mall-online **不新做**小魔推，**不应有**扫码进店入口。现码若仍挂该入口，记缺口，不写成已批准能力。删该路由另开工，本 DEC **不授权**改业务代码。
9. 中间页具体网址、密码最短位数、聚合密钥继续**待配置**，不编造。

- 是否删除 mall-online 上误挂的扫码入口（另批开发）
