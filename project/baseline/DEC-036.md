## 已确认规则

1. **抽回。** `LOOP_INVENTORY` 原「不问（本轮后置）」整包**不再后置**。不当成遗忘，也不当 DEC-025 解冻后编码时再问。本轮盘点内问完下列三题。
2. **高影响一题一轮。** 不得把退款、拼团停用与其它题压成一道选择题。低影响最多两题一组（第 3 题）。
3. **剩余队列（未决，不是本 DEC 的业务规则）：**
   - **LOOP-Q10** 核销有效期天数与过期自动退（高影响）
   - **LOOP-Q11** 拼团进行中停用细则（高影响）
   - **LOOP-Q12** 在线商城轮播接哪路 C 端，以及最短密码位数、时区、性能容量、订单字段清单（低影响可一组）
4. **资质每一栏文案不再问。** 继续 DEC-032：沿用现码执照页，不逐栏重写。
5. **本 DEC 不裁定 Q10～Q12 的答案。** 未二次确认前不得把预览推荐写成已确认。
6. **本窗不改业务代码。** LOOP-Q9=B **不等于**结束 DEC-025、不等于解冻编码、不等于开 DEV-003。
