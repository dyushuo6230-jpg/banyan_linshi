## 已确认规则

1. **资质：** 四业态同一套入驻 H5，沿用**当前 mall 入驻页**（`merchant_site`）已采集的营业执照（含该页现有 OCR 成功才能提交的行为）。不新编餐饮/美发/商超/在线商城分业态证件清单。不把接口闲置的身份证正反面、老入驻页上的行业许可证升格为本期必填或验收项。
2. **本地生活（餐饮/美发/商超）：** 入驻仍不选经营类目下级、不选平台类目一级。
3. **在线商城：** 业态选定后必须多选平台类目下**启用中的一级**，数量 **1～3 个**（含 1 和 3）。0 个不能提交；超过 3 个不能提交。选项以外的 ID 不能提交。
4. 多选一级只表示该供应商**可售范围**，**不**把多个一级费率平均到店。抽佣仍按商品所属一级快照（DEC-001 / DEC-021）。商品未挂一级仍不可售、不可下单（DEC-013）。
5. 过审后把申请上的 1～3 个一级 ID 写入该供应商绑定。本地生活店铺绑定的一级列表为空。
6. **本窗不改业务代码、不改入驻表。** 改校验与绑定默认等 DEV-003。升 Ready DEV-003 时按本 DEC 落地，不必再问资质清单或一级个数；若改规则须新 DEC/CR。
