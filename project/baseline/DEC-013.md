- 主题：在线商城商品未挂一级时订单如何计佣
- 选择：方案 A
- 限制条件：NONE
- 被拒方案：B（允许下单并用缺省/根节点费率）、C（允许下单且本单抽佣为 0）
- 知情决策证据：INFORMED_REVIEW → INFORMED_CONFIRMATION → DECISION_APPLY

## 已确认规则

1. 在线商城商品**必须**能归属到经营类目树的某一个**一级**节点，才能作为众享源品 - 在线商城可售商品。
2. **未挂一级**：不得送审通过、不得在众享源品 - 在线商城可售、**不得下单**。不发明缺省费率，也不把漏挂当成 0 抽佣。
3. 存量未挂一级的商品：先补挂到树上（且落在该店入驻已选一级范围内），再按原审核/上架规则出售。
4. 已产生且已写入一级快照的旧单：仍用快照，不因本题重算。
5. 本地生活仍按业态节点计佣，不走本规则。
6. 在线商城入驻是否强制选择 1～3 个一级：**不在本 DEC**，以后另定。
