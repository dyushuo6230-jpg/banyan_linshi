- 主题：美发/商超核销码核几次；过期是否自动退（不问天数）
- 选择：方案 A
- 限制条件：美发/商超整单一次核销，部分核销不做；不写天数；过期自动退待配置；不改库等到 DEV-007
- 被拒方案：B（一次核销并预先锁定过期自动退）、C（多次/部分核销）

## 已确认规则

1. **适用范围：** 仅美发、商超。餐饮仍扫桌、不走核销码。在线商城/众享源品 - 在线商城不暴露核销。
2. **整单一次核销：** 一笔已付订单发一张有效主码。本店核销成功即整单履约完成。已核销再核：不第二次履约。他店码失败。
3. **部分核销本期不做：** 不能按件数或次数核一部分。不是次卡。未核完要退走现码退款，不走「核一半」。
4. **不写核销天数 / 过期自动退：** **已由 DEC-037 收口**（本期不设天数、不做自动退）。
5. **本窗不改业务代码、不改订单表。** 发码与核销等 DEV-007。升 Ready DEV-007 时按本 DEC 落地一次核销；天数与过期自动退按 DEC-037，不得私写。
