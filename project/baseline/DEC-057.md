## 功能在哪看到（人话 6 问总览）

1. **哪一端、哪业态**
   - 众享营销 - 本地生活：餐饮 / 美发 / 商超顾客订单；美发/商超进行中文案；三业态已完成评价。
   - 众享源品 - 在线商城：顾客订单评价；商品详情评价。
   - 租户后台：在线商城商品列表批量改挂；四业态评价管理只看。
   - 平台后台：评价管理只看；售后仍只读。
2. **谁**：美发/商超顾客看状态；已完成顾客写评价；在线商城供应商批量改类目。部分退/退货仍不给任何人新入口。
3. **怎么走进来**：众享营销 - 本地生活「我的 / 订单」；众享源品 - 在线商城订单与商品详情；租户「商品管理 → 商品列表 / 评价管理」。
4. **人在哪看见**：美发/商超进行中状态词；评价按钮与详情评价区；商品列表批量改类目；售后页仍无部分金额、无填物流。
5. **怎么操作**：打开订单看文案；订单 50 提交评价；详情有已完成单才能写评；勾选旧货选一个叶子批量改挂。
6. **现在怎样 / 改完怎样**：部分退/退货入口仍没有。美发/商超 C 端 20 显示待核销。评价能写出记录，在线商城顾客端商品详情能看见。旧货可一次改挂到指定叶子。

## 已确认规则

1. **OPEN-01=A。** 本期仍整单全额退。租户待处理只能全额退或拒绝。不按金额部分退、不按件按行退。叠加 DEC-052 第 4 条，不改写旧文件。
2. **OPEN-02=A。** 本期不跑退货物流主路径。不填单号、不待寄回、不「确认收到退货才退款」。寄回线下协商。叠加 DEC-054 第 10/15 条，不改写旧文件。
3. **OPEN-03=A。** 仅众享营销 - 本地生活 · 美发、商超：顾客订单列表/详情里，状态 20 显示「待核销」。餐饮 C 端现用口语可留。众享源品 - 在线商城仍待发货/待收货。租户/平台后台仍用「已付待履约」，不按业态换 tab。状态机数字不改。收窄 DEC-054「美发/商超待核销延期」为：C 端做、后台不做。
4. **OPEN-04=B。** 打通真评价提交，并开放众享源品 - 在线商城商品详情真评价（叠加收窄 DEC-053 详情「宝贝评价 → 敬请期待」）。
   - 众享营销 - 本地生活（餐饮/美发/商超）与众享源品 - 在线商城：订单 50 可提交评价，写入「商品管理 → 评价管理」。
   - 众享源品 - 在线商城商品详情展示该商品已提交评价；有该商品已完成订单的顾客才能从详情去写；无已完成单不能写。
   - 购物、加购按 DEC-050 v1.1 / DEC-053 v1.1 闭口，不再「敬请期待」。评价不改订单主状态。60/70 不可评。本期不做评价先审后发。
5. **OPEN-05=B。** 在线商城租户商品列表可多选，批量改挂到人手选的一个叶子。目标必须是叶子且在该店入驻一级子树内。逐条独立：成功的改掉，失败的留下并提示。不自动改未勾选的。系统不猜「第一个叶子」。本地生活店内分类不走本条。单条编辑规则仍有效：回显原挂点，保存必须改成叶子。计佣仍向上取一级。
