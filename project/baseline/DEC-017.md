- 主题：本地生活普通商品改为必审后，已在售存量如何迁
- 选择：方案 A
- 限制条件：本期无真实租户/用户；测试可清空用户和租户数据；上线时默认已在售视为已通过
- 被拒方案：B（存量全改待审并立刻不可售）、C（不改不审、一编辑才送审）
- 知情决策证据：INFORMED_REVIEW → INFORMED_CONFIRMATION → DECISION_APPLY
- 关联变更：CR-002

## 已确认规则

1. **本期 / 测试**：当前环境无真实租户、真实用户。测试**允许清空**用户和租户数据。不为当前测试数据做「视为已通过」的存量迁移工程。
2. **上线时默认**：开关切换日，已在本众享营销 - 本地生活**可售**的本地生活**普通商品**，视为已通过；顾客仍可买。之后**新建**必须送审，过审前不可售。
3. 「已在售」按业务可售理解，不写库字段名。不含拼团/秒杀（DEC-004 不变）。不含众享源品 - 在线商城货源。
4. 本 DEC **不批准**生产环境删除真实用户或真实租户；清库仅约束当前无真实数据的测试。
5. 上线执行「视为已通过」时，可追溯为迁移结论，实现细节留 G8/G9。

## 已被 DEC-026 废止的条款

第 2 条「之后新建必须送审」及「已在售视为已通过」作为**本地生活审核迁移**条件已被 **DEC-026** 废止（本地生活普通商品不再进平台审核）。第 1、4 条测试清库仍有效。
