## 已确认规则

1. 资金口径（已确认，本题不改支付实现）：本地生活租户自填微信支付商户号，货款进该店微信账户（REQ-100）。在线商城付款到平台账户，再按现码结算/提现分给供应商（REQ-101、ADR-003）。

2. 侧栏有无（「无」= 删行）：

| 显示名 | 餐饮 | 美发 | 商超 | 在线商城 |
|---|---|---|---|---|
| 支付配置 `/shop/pay` | 有 | 有 | 有 | 无（随 DEC-023 去掉整组店铺管理） |
| 资金总览 `/finance/overview` | 无 | 无 | 无 | 有 |
| 结算账单 `/finance/settlement` | 有（抽佣/账期对账） | 有 | 有 | 有（货款结算） |
| 账户流水 `/finance/account-log` | 无 | 无 | 无 | 有 |
| 提现管理 `/finance/withdraw` | 无 | 无 | 无 | 有 |
| 银行卡 `/finance/bank` | 无 | 无 | 无 | 有 |

3. 本地生活「可提现余额」不是微信货款钱包，故去掉总览/流水/提现/银行卡，避免误导。结算账单先留着看平台记账。在线商城保留完整平台账本五件套，无店级支付配置。
4. 删侧栏不是安全边界。怎么向本地生活店收抽佣、结算文案是否改成「佣金账单」属 DEV-009，本题不改代码。
