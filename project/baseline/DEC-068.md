## 已确认规则

1. **废止 REQ-052「在线商城本期无拼团秒杀」。** 本地生活拼团秒杀仍 DEC-004：租户自发、平台不审。
2. **开场。** 平台创建秒杀场、拼团场（时间/名额等运营字段不在本题编造清单）。
3. **报名。** 仅在线商城供应商用**已审通过**商品报名。本地生活租户无本菜单。
4. **审核。** 平台审核通过后，众享源品 C 端「限时秒杀 / 拼团活动」可进、可下未付单（仍 DEC-050 不真扣款）。活动单平台统一收款。
5. **未成团。** 到期未成团：未付单已取消，释放活动占用。无真退。不改本地生活停用规则（DEC-038）。
6. **菜单。** 平台一级「商城秒杀」「商城拼团」，各下挂「场次」「报名审核」。在线商城租户一级「秒杀报名」「拼团报名」。不恢复已删「秒杀管理」「拼团审核」。本地生活拼团秒杀菜单不改。
7. **架构。** 第二种流程挂在拼团秒杀能力域（ADR-011），成交走交易能力域（ADR-049）。mall-online 暴露源品 C 端；不把本地生活活动接到 mall-online。

- 像素验收
- 活动表与本地生活活动表硬套同一套相反流程
