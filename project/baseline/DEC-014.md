- 主题：现码待平台审核的拼团/秒杀上线后如何迁
- 选择：方案 A
- 限制条件：NONE
- 被拒方案：B（待审全部作废、租户重发）、C（待审自动视为通过并上架）
- 知情决策证据：INFORMED_REVIEW → INFORMED_CONFIRMATION → DECISION_APPLY

## 已确认规则

1. 仅本地生活。在线商城本期仍无拼团秒杀（DEC-004）。
2. **已通过 / 已上架**的活动保留。
3. **待审**记录改为租户侧**未上架**（草稿或下架语义），**不**对 C 端可见，**不删除**。
4. 租户可直接上架，**不必**再经平台审核。
5. 不审不等于自动开卖。迁移须可追溯。
