- 主题：本地生活拼团/秒杀进行中租户停用后，能否新参加；已下单怎么办
- 选择：方案 A
- 限制条件：停用后不可新参；已下单不自动关不自动退；不改库等到 DEV-008
- 被拒方案：B（进行中禁止停用）、C（停用后未完成单自动退）
- 知情决策证据：INFORMED_REVIEW（会话正文）→ `LOOP-Q11=A` → 二次确认限制条件 → DECISION_APPLY
- 关联变更：CR-018

## 已确认规则

1. **仅餐饮/美发/商超。** 在线商城、众享源品 - 在线商城无拼团秒杀。平台不因本题增加强制下架菜单。
2. **停用/下架后：** 本店 C 端不能再新参团、不能再按该活动价新下单。旧链接直达也拒绝新参。
3. **已生成订单**（含未成团、已付待核销）不因停用改状态、不自动退。履约仍按业态（餐饮扫桌 / 美发商超一次核销）。
4. **客人要退走现码退款。** 不新编「因租户停用而失败」的退款任务。
5. 成团时间窗若现码已有则沿用；不新编因停用而失败的成团结果。
6. **本窗不改业务代码、不改 `admin_menu`。** 落地等 DEV-008。平台侧栏删行仍按 DEC-031。
