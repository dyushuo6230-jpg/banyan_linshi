## 3. 现码盘点结论（现状，非目标）

正式产品相关现码：

- 平台后台 8031、mall 8032、租户后台 8033
- 众享营销 - 本地生活 `go-uni-app`（餐饮向 + 入驻 H5 + 小魔推）
- 众享源品 - 在线商城前端 `go-uni-app-online`（页面在，后端独立服务不在）
- H5 托管：`app/h5`、`app/h5-online`
- 无业态字段；租户菜单单树；抽佣在店铺；用户按 `merchant_id` 按店隔离；商品已有 `audit_status`；订单有桌号无核销码；平台有拼团秒杀审核和 banner；`merchant.is_self` 列仍在（目标口径见 DEC-006：退出业务规则）
- 登录相关抽查：`merchant_user.text_password` 仍写仍返回；mall JWT 有 Redis 黑名单；租户 JWT 未检索到平台同类 Redis 白名单

不是本期 5 端：`app/home`（站点壳）。
