- 主题：四套租户菜单模板里小魔推侧栏是否露出
- 选择：方案 A
- 限制条件：只藏租户四套侧栏；代码和小程序页不拆；以后改造另议
- 被拒方案：B（仅在线商城隐藏）、C（本题不改露出）
- 知情决策证据：INFORMED_REVIEW → INFORMED_CONFIRMATION → DECISION_APPLY

## 已确认规则

1. 餐饮 / 美发 / 商超 / 在线商城 **四套**租户菜单模板中，小魔推侧栏项均 **隐藏**（REQ-022）。从餐饮复制模板后必须把该项设为隐藏，四套一致。
2. 小魔推 **代码、表、接口、众享营销 - 本地生活相关页不拆**。不批准删除或停用。不新写改造清单。
3. 本期仍 **不纳入**多业态必验（DEC-010 继续有效）。入驻、发品、逛买、登录、支付不以完整小魔推为交付物。
4. 隐藏不是安全边界：猜 URL 或直打接口仍须鉴权拒绝无权限请求。
5. 以后小魔推怎么改 **另开题**。推广员入驻（REQ-120）不是小魔推。众享源品 - 在线商城 / mall-online 不新做小魔推。
