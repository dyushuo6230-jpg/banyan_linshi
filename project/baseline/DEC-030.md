- 主题：在线商城侧栏已无店铺分类时，发品还要不要强制店内分类
- 选择：方案 A
- 限制条件：仅在线商城店铺分类可空且侧栏不恢复；餐饮/美发/商超店内分类菜单保留且发品必选
- 被拒方案：B（给在线商城恢复店铺分类菜单并继续强制）、C（系统自动造默认「未分类」）
- 知情决策证据：INFORMED_REVIEW（会话正文）→ `LOOP-Q3=A` → 二次确认限制条件 → DECISION_APPLY
- 关联变更：CR-011

## 已确认规则

1. **仅在线商城。** 餐饮/美发/商超侧栏保留「店铺分类」，发品必须选择店内分类；本众享营销 - 本地生活仍按店内分类售卖。不得把「可空」套到本地生活。
2. **在线商城不恢复**租户侧栏「店铺分类」。DEC-023 该行继续有效。
3. 在线商城发品 **必选平台类目**；**店铺分类可空**（未选不得作为保存/送审/众享源品 - 在线商城可售的否决条件）。
4. 众享源品 - 在线商城按 **平台类目** 展示，不以供应商店内分类为逛货权威。
5. 不删店铺分类表。已有在线商城商品若曾挂店内分类，本期不强制清洗。
6. 改发品页与接口校验等到盘点结束恢复编码之后，商品批次 **DEV-006**（DEC-025）。本窗不改代码、不改 `merchant_menu`。

- 类目停用后已上架商品：**已由 DEC-035 收口**
- 入驻强制几个一级（Q5）
- 按业态拒绝预约/会员/查件接口
