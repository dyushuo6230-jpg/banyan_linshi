## 已确认规则

1. 租户后台仍是一套系统、四套模板（DEC-002）。下列**已点名**显示名与有无为本期租户侧栏验收口径：

| 显示名 | 餐饮 | 美发 | 商超 | 在线商城 |
|---|---|---|---|---|
| 工作台 | 有 | 有 | 有 | 有 |
| 店铺 / 员工 / 角色 | 有 | 有 | 有 | 有 |
| 桌台 | 有 | 无 | 无 | 无 |
| 装修（含首页「轮播图」配置） | 有 | 有 | 有 | 无 |
| 内容管理 → 轮播管理 | 无 | 无 | 无 | 有 |
| 小魔推 | 隐藏 | 隐藏 | 隐藏 | 隐藏 |
| 商品 | 有（店内分类） | 有 | 有 | 有（平台类目送审） |
| 秒杀 / 拼团 | 有 | 有 | 有 | 无（v1.1.0：改「秒杀报名」「拼团报名」有，见第 9 条） |
| 支付 / 订单 / 售后 / 财务 | 有 | 有 | 有 | 有 |

2. **本地生活**（餐饮/美发/商超）首页轮播只在**装修**里配；侧栏**不保留**「内容管理 → 轮播管理」。
3. **在线商城**无装修；首页轮播入口为「内容管理 → 轮播管理」。本期不把该入口写成众享源品 - 在线商城首页已接线（现码众享源品 - 在线商城首页不以店铺 `merchant_banner` 为已确认真源）。
4. **周边轮播**仍在「周边管理」，不并进装修首页，不与店铺首页轮播、平台 `banner` 混用。
5. 四套小魔推侧栏隐藏（DEC-019）。在线商城无独立小程序装修。本地生活无拼团秒杀以外的「报名」菜单。
6. **其余**现码侧栏项（如 WiFi、短信、OSS、快递、优惠券、预约、会员、运费、统计、消息、周边管理等）先按现码那棵单树**原样复制进四套**，本题**不再按业态推断**显隐。已确认删减优先于复制。
7. **平台**侧栏显示名沿用现码，本题不起新名（平台新菜单见 DEC-031 v1.1）。
8. 路由页不等于侧栏菜单。隐藏不是安全边界。本窗不改 `merchant_menu` 库、不改业务代码。
9. **v1.1.0（DEC-068 / DEC-069）。** 在线商城模板一级有「秒杀报名」「拼团报名」「板块报名」。表中「秒杀/拼团 → 在线商城=无」废止。不恢复已删平台「秒杀管理」「拼团审核」。本地生活拼团秒杀菜单名不改。员工/角色仍无（DEC-028）。内容轮播仍无（DEC-039）。改库不塞 DEV-010/011/012，见 DEV-013。
