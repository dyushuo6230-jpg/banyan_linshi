## 功能在哪看到（人话 6 问总览）

1. **哪一端、哪业态：** 众享源品 - 在线商城收银台（不真扣）；众享源品 - 在线商城地址（复用）；平台「商品管理 → 平台类目」；平台经营类目根/一级费率；下单后的抽佣快照。
2. **谁：** 顾客支付/填地址；平台运营配树和费率；系统下单时写快照。
3. **怎么走进来：** 在线商城顾客端待付款去支付；「我的」地址；平台类目/经营类目页。
4. **人在哪看见：** 支付是否弹出通道；地址是否另套；类目树有没有写死名单；费率空或 0 时结算佣金为 0。
5. **怎么操作：** 本轮点支付不调起；地址走现能力；类目运营自建；费率可空可填 0。
6. **现在怎样 / 改完怎样：** 真扣款、新地址表、正式类目名单、根费率死数字仍不做。抽佣：空或 0 都不收。未挂一级仍不能卖。

## 已确认规则

1. **OPEN-06=A。** 众享源品 - 在线商城本轮不调起微信/支付宝/金豆。可下未付单；按钮保留以便申请通道。不得把未付标成已付。叠加 DEC-050，不改写旧文件。众享营销 - 本地生活支付到店不改。金豆账户不做。
2. **OPEN-07=A。** 众享源品 - 在线商城地址继续复用现用户地址能力，不加第二张表。叠加 DEC-053 第 3 条，不改写旧文件。
3. **OPEN-08=A。** 不把平台类目节点清单写进 PRD 或正式种子。结构仍在「商品管理 → 平台类目」维护。不编造「食品/饼干」名单。
4. **OPEN-09=A。** 不把餐饮/美发/商超根费率写成固定百分数。运营在经营类目页自填。在线商城一级费率同样自填，不定「食品 8%」。
5. **费率空或 0 = 不抽佣。** 本地生活业态根、在线商城所属一级：节点费率为空或为 0，新单快照按不抽佣（0%）。订单仍可成交（须已满足挂一级等可售条件）。运营忘填则平台抽 0，不报错拦截。叠加收窄 DEC-021「空 = 未配置 ≠ 0%」，不改写 DEC-021 旧文件。
6. **未挂一级仍不可售。** DEC-013 有效：在线商品未挂一级不可售不可下单，不得用 0% 或缺省费率冒充已挂一级放行。已付快照不因后来改费率重算。
