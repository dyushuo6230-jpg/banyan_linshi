## 已确认规则

1. **落地顺序（LOCAL-ADD-WHEN=A）：** 先经营类目可增本地根 + 克隆商户菜单 + 入驻可选；再首页模块归属、周边分类改业态、平台/店 CPS。不与 DEV-007 扫桌核销缠在一起，不放到履约之后。

2. **本地根可增：** 在线商城仍是唯一非本地业态根。原四根（餐饮/美发/商超/在线商城）不可删除。新增本地根须填名称、代码、费率，并必选一套已有本地业态做菜单快照拷贝（禁止在线商城）。**DEC-047 收窄：** 拷贝源只许餐饮/美发/商超，禁止再拷另一个新增根；无引用的新根可删。拷贝后商户菜单多一个页签。履约跟克隆来源走：餐饮=扫桌；美发/商超=核销。不发明第四种履约。禁止「到店」作业态代码。

3. **入驻可选（LOCAL-APPLY-GATE=A）：** 每个业态根有「入驻可选」。关：入驻 H5 不出现；已有店和已提交待审不改业态。新本地根默认关，菜单拷完后再打开。四个原根默认开。至少保留一个根为开。一级类目不另加入驻开关，继续用启停（DEC-032/035）。审核补选可列出全部业态根（含已关闭），以免待审单无法过。

4. **首页模块归属（LOCAL-HOME-MAP=B）：** 平台 **商户管理 → 首页模块归属**。一行一个已有首页模块，适配模式通用或自定义。通用=当前全部本地根（新根自动纳入）。自定义=多选本地业态，新根不自动勾。**v1.1.0：** 本页增加「拼团」「秒杀」两种，默认通用；不并入活动三坑。无进行中活动则该坑空。发活动仍租户自发、平台不审（DEC-004）。除此两行外本页不增删其它模块种类。店铺装修（目标页=首页）只列出本店业态被允许的模块；C 端首页同样过滤。「我的」页不走本表。默认：顶部分类/轮播/公告/会员/活动/推荐=通用；在线预约=自定义仅餐饮；本店服务=自定义餐饮+美发；拼团/秒杀=通用。活动三坑可配标题/链接/图片；推荐标题可配。在线商城无装修、不进本页。不是源品、不是平台板块（DEC-069）。

5. **平台侧栏（LOCAL-ADMIN-MENU=A）：** 删「周边分类管理」。周边管理下加「周边CPS」。另加「首页模块归属」于商户管理下。改 `admin_menu` 以本 DEC 为准，覆盖 DEC-031 中「其余现码侧栏一律有且不改名」里周边仅分类管理、以及不新建菜单的限制（仅本 DEC 点名的两处：删分类、加 CPS 与模块归属）。

6. **周边分类：** 商户列表勾选值改为本地业态代码（可多选）。只给本地生活店勾。该众享营销 - 本地生活周边只展示已勾业态。众享源品 - 在线商城附近筛选项也是动态本地业态（平台级，与某店勾选无关）。`nearby_category` 停用业务。在线商城仍不设周边。旧分类 ID 不迁移。

7. **CPS（LOCAL-CPS-DEFAULT=A）：** 平台维护一份 CPS 目录（增删改、上下架），对应众享源品 - 在线商城显示。本地生活租户只引用该目录，不能增删改内容，只能上下架，对应本众享营销 - 本地生活；无行=下架。平台下架则众享源品 - 在线商城与店 C 端都不出。在线商城无「周边CPS」菜单（DEC-023 已删）。点击拉起第三方小程序：平台填第三方 appid+path；本地店 extraData 传 `merchant_id`、`shop_name`、本店 appid；众享源品 - 在线商城只带 `from=mall-online`，不传某供应商。旧租户自填 CPS 行不再给 C 端。不编造更多 extraData 键。
