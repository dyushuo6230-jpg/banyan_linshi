## 已确认规则

1. **协议按业态隔离。** `agreement.biz_type`：`1`=本地生活（众享营销 - 本地生活），`2`=众享源品 - 在线商城。在线商城顾客端协议用 `code`：`service`（用户服务协议）、`privacy`（隐私政策）。平台后台「协议管理」只管本地生活；「众享源品 - 在线商城协议」单独菜单，只编辑 `biz_type=2`。众享源品 - 在线商城 C 端只读在线商城顾客端协议，不得串读本地生活协议。
2. **推荐双轨。** 商品「平台推荐」（既有 `is_recommend`）管众享源品 - 在线商城货池/展示；「店铺推荐」（`is_shop_recommend`）仅租户侧/本店场景。店铺推荐开关**不得**改变众享源品 - 在线商城是否可售或是否进在线商城顾客端推荐池。
3. **收货地址复用。** 众享源品 - 在线商城用户地址用现表 `user_address` 与现接口能力（列表/增删改/默认），**不新建地址表**。省市区选用现行政区划（`region` / `regions`）。下单选址走该套能力。
4. **众享源品 - 在线商城 C 端能力（v1.1.0 收口，叠加 DEC-050）。**
   - 商品详情：加入购物车写入购物车；立即购买选规格后进未付单。底栏在购物与加购之间加收藏（空心+「收藏」/红实心+「已收藏」，再点取消）；四钮间距相等。店详情不加收藏。
   - 「我的」：**不藏**门店入驻、供应商入驻，点了「敬请期待」；真开店/当供应商先走入驻 H5。隐藏个人主页。余额/消费券/金豆留三格，点了敬请期待，不做真金豆账户。待评价只进已完成且未评的单，不当订单主状态。足迹、收藏用无搜索商品列表。银行卡、全民推广、官方公告、联系客服点「敬请期待」。设置可进，隐藏切换语言。
   - 底栏四 Tab：购物 / 附近 / AI助手 / 我的。无发现。
   - 订单详情「首页」回到众享源品 - 在线商城首页，不回到众享营销 - 本地生活。

## 不包含

- 顶部安全区、主按钮实色等纯 UI（用户明确不录入）
- 接口字段映射、空桩、本地联调 IP 等纯实现
- 本轮真扣款、金豆账户、入驻开通
