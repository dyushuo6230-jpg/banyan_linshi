- 主题：平台轮播 banner 删除、摘菜单还是保留
- 选择：方案 A（保留；按限制条件收口，不等于纳入本期 C 端验收）
- 限制条件：现码确认平台 banner 未对接任何 C 端；本期保留菜单和表，不删除、不纳入众享源品 - 在线商城验收；是否改挂给众享源品 - 在线商城首页留后续，本期不写死
- 被拒方案：B（业务废弃/删除办理能力）、C（保留并纳入本期验收）
- 知情决策证据：INFORMED_REVIEW → INFORMED_CONFIRMATION → DECISION_APPLY
- 关联冲突：CONFLICT-006 已关闭

## 已确认规则

1. 平台后台**保留**轮播管理菜单和 `banner` 表及存量数据，本期**不删除**。
2. 现码事实：平台 `banner` **未对接**众享营销 - 本地生活、众享源品 - 在线商城或其它 C 端。本地生活首页轮播来自店铺 `merchant_banner`；周边来自 `nearby_banner`。不得把这三套混成一套。
3. 本期**不把**平台 banner 作为众享源品 - 在线商城或任何 C 端的验收项；不要求运营必须配置，也不要求任何 C 端展示该表数据。
4. 本期**不**因此新建众享源品 - 在线商城根菜单，也**不**把 banner 改挂到众享源品 - 在线商城。

## 未扩大、仍为待配置（不在本 DEC 内）

- 以后是否把该 banner 改挂给众享源品 - 在线商城首页：**已由 DEC-039 收口**（众享源品 - 在线商城首页读本表；本地生活仍不以本表为准）
- 平台是否单独开众享源品 - 在线商城根菜单（与 REQ-023 菜单名称相关，不在本题）

第 3、4 条中「不纳入众享源品 - 在线商城验收、不改挂」以 **DEC-039** 为准。菜单和表仍按本 DEC 保留、不删除。
