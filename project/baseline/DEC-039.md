## 已确认规则

1. **众享源品 - 在线商城首页**现有轮播位改读**平台** `banner`。有数据就轮；没数据可空或留占位。不强制运营必须先配图。不接各供应商 `merchant_banner`，不接周边 `nearby_banner`。
2. **在线商城供应商**侧栏删除「内容管理 → 轮播管理」；父级「内容管理」若因此为空则一并删行（「无」= 删行，不是隐藏）。餐饮/美发/商超装修里的店内轮播不动；表 `merchant_banner` 留下给本地生活用。
3. **平台**「内容管理 → 轮播管理」菜单和 `banner` 表保留。不因此新建众享源品 - 在线商城根菜单。
4. **时区：** `BUSINESS_TIMEZONE=Asia/Shanghai`（沿用现码 Docker / 用量统计口径，不是新编数字）。
5. **最短密码位数：** ~~不写入 PRD 数字，本期不验收「必须 N 位」。~~ **已废止。** 现行以 DEC-062 / CR-037 为准。本文件其余条（banner、轮播菜单、时区、容量、订单字段）仍有效。
6. **性能容量：** 本期不写 QPS / 并发 / SLA，不验收压测数字。
7. **订单字段：** 沿用现码 `order_info` 及关联表已有列。REQ-104「完善」本期不加字段、不另出必填清单；缺增补表不视为缺陷。
8. **本窗不改业务代码、不改 `admin_menu` / `merchant_menu`。** 删供应商菜单落地等恢复编码后 DEV-002；在线商城的顾客端接线等 DEV-010。平台侧栏改库仍按 DEC-031。

## 对先前决策的收口

- DEC-007：菜单和表仍保留、不删；**众享源品 - 在线商城首页这一坑改挂平台 `banner` 并纳入该坑能看见配置图的验收**（有配置才看见）。众享营销 - 本地生活仍不以平台 `banner` 为准。
- DEC-020：四套表中在线商城「内容管理 → 轮播管理」由有改为**无**。本地生活仍无该侧栏、轮播只走装修。
- GAP-005：关闭。不是把供应商轮播接到在线商城的顾客端，而是在线商城的顾客端读平台表、供应商空菜单删除。
