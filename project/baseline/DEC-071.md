## 已确认规则

1. **不编造假入口；树上有的一级照出。** C 端不得另做「甄选上新」运营聚合假入口。左栏名称只听平台类目树：树上有这一级，就按普通一级渲染（第一项也不收窄、不加高成另一套格子）；树上没有就不画。不要把它当演示项专门藏掉。
2. **只读平台类目。** 左栏 = 启用中的一级（默认第一项）。当前一级下，顶栏胶囊和下拉「全部分类」= 该一级的二级。每个内容卡片 = 一个二级；卡片内圆图 = 该二级下的三级。无图用占位圆。不是店铺分类，不编造类目。
3. **多模块同屏、点选定位。** 右侧一次画出当前一级下**全部**二级模块。点顶栏或下拉里的某个二级，内容区滚到对应卡片，不得清掉其它模块只留一块。点左栏换一级时，顶栏和内容换成该一级下全部二级，并回到顶部。点卡片标题/箭头进该二级商品列表；点圆图进该三级列表。没有二级则一块空卡，点了进该一级列表。平台未配类目则左栏、右侧皆空。
4. **选中装饰。** 未选中每一项同一宽高、同一字号。选中听 **UI-DEC-006 / 现码**：白边包金芯、白边在阴影内、上下箭头切图画在金卡**里面**、选中块加高。禁止把箭头改回格外，禁止把选中改回与未选同高。顶栏（二级）胶囊：未选中白胶囊与选中胶囊**同一高度、同样大圆角、顶底对齐**；倒三角不算进盒子。选中用**代码**金底 + 渐变 + 白字 + CSS 倒三角；组 B 整图只作观感参考，**禁止**当 `background-image` 拉伸。胶囊 + 三角作为整体有阴影；三角底边正好顶住三级内底板白卡顶部。三级圆图 CSS grid 三列，禁止 flex 挤成两列。「全部分类」超出在面板内滚动。
5. **图层。** 外底板（左栏 + 二级槽 + 三级区共用）听 **UI-DEC-005 / 现状**：圆角分层——外底板 `16rpx`，左栏竖条与选中金卡 `10rpx`（约 5px），不是同一套圆角。底色奶油落到页灰 `#fff8df → #fffdf4 → #f8f8f8 → #f6f6f6`，内边距 `16rpx`。**不对**《分类.png》顶上那条米金做像素验收。二级左右遮罩 **不铺** `#fff6d6`。奶油色不升 locked 令牌。左栏是单独竖条皮。二级是单独槽。三级每个模块用内底板白卡。左栏裁切时顶底渐变溶进**现码底板色**（顶 `#fff6d6`、底白）；无裁切时顶底同等圆角和边距。
6. **与 DEC-008 的关系。** 本页是「有 PNG 按图还原」的书面例外：不把树上没有的名称编成假入口；外底板听 UI-DEC-005；左栏选中/三级 grid/全部分类滚动听 UI-DEC-006。搜索条、左栏结构、卡片圆图、二级金气泡仍对照《分类.png》能对上的部分。其它 SRC-UI-003 有图页仍一比一。视觉细则写入源品 UI_SPEC Partial 覆盖。
7. **施工批次。** 在 DEV-013 内改源品 C 端分类页（只打 mall-online）。v1.3.0 口径已写入 UI_SPEC 0.1.4 Approved；分类 32A 听 Approved 第 4 节 + 现码，不得按 v1.1.0 外侧箭头改回去。
