- 主题：第二轮已点名侧栏有无（店铺分类、预约、会员、通道用量、店铺管理、快递查询、周边）
- 选择：方案 A（按下表删行；在线商城快递查询改挂订单）
- 限制条件：通道用量仅在线商城无，餐饮/美发/商超有。本批只改 `merchant_menu` 模板有无与父级，不改发品校验、预约接口、会员接口、通道统计接口、C 端。本批结束走 CR 收进 PRD
- 被拒方案：B（在线商城仍留店铺/员工/角色）、C（本批不改这些项）
- 知情决策证据：INFORMED_REVIEW → 用户纠正通道用量口径 → 二次确认 `DEC-023=A` → DECISION_APPLY

## 已确认规则

1. 「无」= 从该业态模板删行，不是隐藏。隐藏仍只用于小魔推（DEC-019）。

| 显示名 | 餐饮 | 美发 | 商超 | 在线商城 |
|---|---|---|---|---|
| 店铺分类 `/goods/category` | 有 | 有 | 有 | 无 |
| 预约订单 `/order/book` | 有 | 无 | 无 | 无 |
| 会员管理及子菜单 | 有 | 有 | 有 | 无 |
| 通道用量 `/stat/usage` | 有 | 有 | 有 | 无 |
| 快递查询 `/shop/express` | 无 | 无 | 无 | 有（挂在订单下） |
| 店铺管理及子菜单（店铺/员工/角色/支付/OSS/短信/WiFi 等） | 有 | 有 | 有 | 无 |
| 周边管理及子菜单 | 有 | 有 | 有 | 无 |

2. 在线商城无独立店内分类，发品用平台类目（REQ-031）。发品是否强制店铺分类见 **DEC-030**（可空、侧栏不恢复）。
3. 在线商城会员在平台「用户列表」看；本批不改平台用户页。
4. 通道用量：仅在线商城业态供应商走平台通道、租户侧不统计；本地生活三套保留。
5. 本条是对 DEC-020「其余项先复制」的已点名删减。财务子菜单有无见 DEC-024。

## 未扩大

- 在线商城发品去掉店铺分类必填、改为平台类目选择器（已由 DEC-030 覆盖）
- 预约/会员/通道用量/查件接口按业态拒绝
- 在线商城店招、员工、角色改由何处维护（已由 DEC-028 覆盖）
- 周边 C 端是否下线
