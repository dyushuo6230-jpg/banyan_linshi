- 主题：共表分池如何落库；不得把 `merchant_id=0` 当成众享源品 - 在线商城
- 选择：方案 A
- 限制条件：不创建 `app/mall-online`；众享营销 - 本地生活本期不开众享源品 - 在线商城那套账号密码登录；不编造 C 端锁定次数；openid 全局唯一不改
- 被拒方案：B（不加列、靠现码字段凑合）；C（伪造 `merchant_id` 冒充众享源品 - 在线商城）
- 知情决策证据：INFORMED_REVIEW `DEV005-Q1` → `DEV005-Q1=A`（用户写作 `EV005-Q1=A`）→ APPLY

## 已确认规则

1. **列：** `user.user_pool`、`order_info.user_pool`。`1`=店铺池，`2`=众享源品 - 在线商城池。
2. **存量：** 现有行一律 `1`，含 `merchant_id=0`。空店脏数据不得默认成众享源品 - 在线商城（DEC-003 / REQ-070）。
3. **下单：** 创建订单时从用户拷贝池；mall 读写只认池 `1`。缺池或池不匹配当该人不存在。
4. **查找：** 店铺池按店 + 手机号。本批不加 UNIQUE（空手机号会撞唯一）。索引 `(user_pool, merchant_id, mobile)`。openid 仍全局唯一，不改分池语义。
5. **众享源品 - 在线商城登录：** 等 mall-online（DEV-010）。本批不实现手机号/账号密码登众享源品 - 在线商城，众享营销 - 本地生活也不开同一套（REQ-071 / REQ-072）。
