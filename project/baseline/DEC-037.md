- 主题：美发/商超核销码有没有有效期天数；到期要不要自动退
- 选择：方案 A
- 限制条件：不设核销天数，码不因到期作废；过期自动退不做；不改库等到 DEV-007
- 被拒方案：B（现在锁定 N 天、到期作废、不自动退）、C（锁定 N 天且过期自动退）
- 知情决策证据：INFORMED_REVIEW（会话正文）→ `LOOP-Q10=A` → 二次确认限制条件 → DECISION_APPLY
- 关联变更：CR-017

## 已确认规则

1. **适用范围：** 仅美发、商超核销码。餐饮扫桌不走本题。一次核销/部分核销不做仍以 DEC-034 为准。
2. **本期不设核销有效期天数。** 码不因「到期」作废。DEV-007 **不得**写死天数，**不验收**到期作废。
3. **过期自动退本期不做。** 不建过期扫描/自动退任务。DEV-007 **不验收**过期自动退。
4. **客人要退走现码退款。** 不新编退款状态机。钱仍在该店微信。
5. **以后若要天数或过期自动退：** 须另开知情决策 + CR，编码时不得私写。
6. **本窗不改业务代码、不改订单表。** 发码与核销等 DEV-007。
