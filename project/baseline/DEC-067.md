- 主题：ToB 营销 API/H5 本机端口是否写死；测试/正式用哪几个域名；H5 是否挂 `/wap`；发布如何 embed
- 选择：本机 API **8037**、H5 **8038**；测试一律 `.gyyx.store`，正式一律 `.zhengdeyunqi.cn`；H5 **挂 `/wap/`**（与源品根路径进首页不同）；先打前端再编静态二进制
- 限制条件：不编造商户号、jwt.secret、小程序 appid；容器内仍可 8000 + Nginx；外网只认下列域名
- 被拒方案：把 ToB 接到 mall / mall-online；与源品共用同一部署决策正文；H5 按源品根路径理解导致路径抄错
- 知情决策证据：会话正文用户确认 `部署=单独新决策；产品=轻量第四条线；规则=全纳分层；慎入=不进正文`
- 关联变更：CR-042（产品总册轻量第四条线）

## 已确认规则

1. **本机端口写死。** API `app/mall-tob` → **8037**；H5 静态 `app/h5-tob` → **8038**。不得占用 8031～8036。`go-uni-app-tob` 开发代理 / `.env.development` 只打 `127.0.0.1:8037`。
2. **C 端只调 mall-tob。** 禁止接到 `app/mall`（8032）、`app/mall-online`（8035）、租户后台（8033）。
   - 测试 API：`https://test-shop-tob-api-go.gyyx.store`
   - 正式 API：`https://shop-tob-api-go.zhengdeyunqi.cn`
3. **H5 挂载前缀 `/wap/`（与源品不同）。**
   - 测试：`https://test-shop-tob-h5-go.gyyx.store/wap/`
   - 正式：`https://shop-tob-h5-go.zhengdeyunqi.cn/wap/`
   - 本机静态进程 **8038**；`/` 跳转 `/wap/`。`go-uni-app-tob` 整包拷到 `app/h5-tob/web/dist` 后 `go:embed` 打进二进制。
4. **发布顺序。** 须先 `npm run build:h5:test`（正式用 `build:h5`）经 `publish.cjs` 写入 `web/dist`，再在同一工作区编 `h5-tob-server`。只编 Go、未嵌前端 → 首页缺失。
5. **对外静态契约（不进 dist，单独嵌在 `web/`）。**
   - 客服页：`/wap/chatlink.html`
   - 微信业务域名校验：域名根 `/iWxFdaLJBB.txt`（不得只挂在 `/wap/` 下）
6. **业务不按站点 ID 隔离。** ToB 专用小程序；后台写站点字段为 0；mall-tob 读路径不按站点过滤。环境变量可保留站点字段，不作为业务边界。
7. **真实 yml 不进 Git。** example 只写域名与端口；密钥 `CHANGE_ME`。

## 分层规则（产品侧摘要，细则见 PRD / CR-042）

下列与部署强相关、须在本决策可见，产品总册另有轻量表述：

- ToB 协议与源品协议隔离维护（业务类型分开）
- 平台可配：轮播、首页入口、功能分类、功能产品、ToB 协议；**不做**数据看板后台配置页
- 本期不做：客户留资进后台、省市区接口、微信取号；申请开通页可静态
- C 端首页/功能/看板有只读数据能力；看板库空可用演示数据

## 未扩大

- 不把端口/域名写进 PRD 业务规则正文（与源品部署决策同口径）
- 不在本决策罗列营销子页面文件名、PHP 壳接口清单、种子 SQL 行
- 不编造微信商户号、小程序 appid、jwt.secret
- Redis db 号本题不另定（独立键或独立 db，避开已占用号）
- 不把 ToB 并入本地生活用户池或源品用户池（另议）
