## 4. D01～D08 已交接的职责摘要

以下是上一会话对已确认包的**摘要**，不是逐条冻结条文：

1. D01：Design Governance Foundation（设计治理基础）。
2. D02：Rule / Context Governance（规则与上下文治理）。
3. D03：Design Source / Scene / Evidence / Design Truth（设计来源、场景、证据与设计真相）。
4. D04：Visual Property / Token / Foundation（视觉属性、设计变量与基础层）。
5. D05：Behavior / State / Interaction（行为、状态与交互）。
6. D06：UI Data Semantics / Fixture（界面数据语义与样例数据）。
7. D07：Design Package / UI_SPEC / Effective UI Contract（设计包、UI 施工规范与当前有效界面契约）。
8. D08：Implementation Guidance / IR / Pack（实现指导、中间表达与实现包）。

已交接的主链路：

```text
Design Source / Material / Evidence
→ Design Formation
→ Design Package
→ UI Governance
→ UI_SPEC
→ Effective UI Contract
→ Implementation Semantic Need
→ Implementation Guidance
→ Implementation IR
→ Implementation Pack
→ Framework Adapter
```

已明确分离的概念：`PRD ≠ UI_SPEC`；`Design Package ≠ UI_SPEC`；`UI_SPEC ≠ Implementation Pack`；`Geometry ≠ CSS`；`Design Token ≠ Shared Foundation`；`Visible State ≠ Behavior ≠ Business State`；`UI Data Semantic ≠ Business/API Contract`；`Evidence ≠ Truth ≠ Authority`；`Approved ≠ Current Effective`；`Readiness ≠ Authorization`。

D07 摘要：Design Package 是具体设计目标，UI_SPEC 是批准后的 UI Construction Contract，Effective UI Contract 是任务或批次快照；UI_SPEC ready 不等于允许施工。

D08 摘要：Guidance、IR、Pack、Adapter Output 分层；布局实现关系优先于抄截图坐标；Flex/Grid 属于实现决策。D08 复用既有 Design→Implementation Semantic Bridge，不另造第二座桥。
