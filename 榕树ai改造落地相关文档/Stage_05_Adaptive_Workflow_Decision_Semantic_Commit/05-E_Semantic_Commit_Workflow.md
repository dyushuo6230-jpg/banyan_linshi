# 05-E Semantic Commit Workflow

流程：

```text
Inspect Working Tree
→ Semantic Classification
→ Workflow/Task/Change/Batch Correlation
→ Group Candidate Changes
→ Hunk-aware Plan
→ Validate Each Group
→ Git Identity Precheck
→ Authorization Gate
→ Future Commit Executor
→ Capture Actual Commit
→ Evidence / Trace
→ Leftover Report
```

Stage 05 只冻结 Authorization Gate 之前及后续预期接口。
