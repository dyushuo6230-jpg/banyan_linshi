# 18.5-E Runtime Bridge

Stage 18.5 必须先识别 Runtime Implementation，再选择桥接：

```text
IN_PROCESS
LOCAL_PROCESS_RPC
LOCAL_HTTP
LOCAL_STDIO
OTHER_TYPED_LOCAL_BRIDGE
```

选择必须记录 rationale / failure semantics / lifecycle / timeout / evidence。

默认禁止：

```text
重写整个 Runtime 只为配合 Gin
```

Bridge failure 必须 typed，不能 fallback 到第二套逻辑。
