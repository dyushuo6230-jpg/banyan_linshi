# 18.5-B Ant Design Pro Simple Baseline

创建一个可审计的精简基线。

```text
no demo business pages
no sample mock backend
no sample account/auth assumptions unless Banyan explicitly owns them
no unused marketing/example assets
```

保留：

```text
ProLayout / application shell
routing
theme
required ProComponents
error boundary

```
