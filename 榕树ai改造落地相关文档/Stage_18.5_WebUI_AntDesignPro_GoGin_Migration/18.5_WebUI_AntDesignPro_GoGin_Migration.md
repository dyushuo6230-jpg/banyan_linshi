# Stage 18.5：WebUI → Ant Design Pro Simple / Control Plane → Go + Gin

## 1. 目标

替换实现，不替换 Banyan 已冻结语义。

最终链路：

```text
Ant Design Pro Simple
        ↓ HTTP / SSE
Go + Gin Control Plane
        ↓ Runtime Bridge
Existing Banyan Runtime API
        ↓
Permission / Git Safety / Trace / Index / Providers
```

## 2. 关键原则

```text
UI implementation may change
HTTP transport may change
Runtime contract must not change silently
Permission semantics must not move into UI/Gin
```

## 3. Frontend

从 Ant Design Pro Simple 基线构建。

只保留：

```text
layout
routing
theme
ProComponents used by Banyan
Banyan pages/features
API client
typed models
```

删除所有 Demo / Mock / 示例业务。

## 4. Go/Gin

Gin 只是：

```text
Transport Adapter
```

Gin Handler：

```text
parse
validate
call application/runtime bridge
map typed result
emit HTTP response
```

禁止：

```text
在 handler 内实现 Permission winner
在 handler 内决定 Git 是否允许
在 handler 内自动修复 UNKNOWN
```

## 5. Runtime Bridge

本阶段默认：

```text
Preserve existing Stage15 Runtime
```

定义：

```text
RuntimeBridge
```

接口至少：

```text
Status
PolicyStatus
ProjectSafety
Preflight
CommitPlan
CommitDryRun
TraceQuery
ProvenanceQuery
ProviderStatus
ActivationReadiness
```

具体桥接方式必须由现有 Runtime 实现事实决定并记录。

## 6. Release

构建：

```text
frontend build
→ static directory
→ asset manifest/hash
→ go:embed
→ Go binary
```

Go binary 能提供 WebUI，不需要 production Node server。

## 7. SPA

必须正确区分：

```text
/api/**
/events/**
static assets
SPA deep links
```

API 404 不能返回 index.html。

## 8. Existing Pilot

Stage17 `.banyan/`：

```text
READ / VERIFY ONLY
```

不得因 UI 迁移重新生成。

