# 11-G Query Contract

最低查询：

```text
find artifact by stable id
find artifact current locator
find incoming/outgoing references
find unresolved references
find source role / authority
find artifact versions/status history
find change → affected artifacts
find decision → evidence
find projection → sources
find source → projections
find stale/review-required projections
find handover → canonical refs
find progress current/historical
find trace by stage/run/subject
```

Query 结果必须携带 authority / freshness / provenance，不只返回正文。
