# Stage 02 Banyan Core Boundary Design

## 文档目的

定义 Banyan 通用能力边界设计方法。

------------------------------------------------------------------------

## Capability Boundary

每个能力必须记录：

-   capability_id
-   输入
-   输出
-   依赖
-   失败语义
-   是否跨项目通用
-   候选归属

------------------------------------------------------------------------

## Core Candidate 判断

条件：

-   多项目可复用
-   与具体业务无关
-   有稳定输入输出
-   可定义接口

------------------------------------------------------------------------

## Project Candidate 判断

条件：

-   依赖业务
-   依赖项目规则
-   包含业务语义

------------------------------------------------------------------------

## Provider Candidate 判断

条件：

-   外部工具
-   编辑器
-   模型
-   第三方服务

------------------------------------------------------------------------

## 禁止

Stage 02 不创建：

-   正式 .banyan
-   最终 banyan-framework
-   迁移目录
