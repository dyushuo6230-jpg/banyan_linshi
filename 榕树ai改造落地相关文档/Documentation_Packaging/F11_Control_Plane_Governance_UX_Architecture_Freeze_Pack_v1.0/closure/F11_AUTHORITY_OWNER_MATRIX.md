## Hard boundaries

```text
F11 owns UX semantics, not universal domain authority.
F11 must not own Runtime Permission, Runtime State Truth, Provider Binding,
Runtime Provider Resolution, Execution Lifecycle, Canonical Apply Authority,
DecisionProtocolDefinition, Evidence Authority, Product Authority, or Design Authority.
```
