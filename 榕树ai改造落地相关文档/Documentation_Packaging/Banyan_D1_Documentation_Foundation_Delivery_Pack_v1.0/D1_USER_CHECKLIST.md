# D1 完成后用户只需要检查什么

Codex 执行 D1 后，你不用逐篇校对。

只需要把以下内容发回给我做 D1 验收：

1. Codex 最终执行总结。
2. `banyan-framework/docs/D1_FOUNDATION_ACCEPTANCE_REPORT.md`
3. 最好同时打包并上传：
   - `banyan-framework/docs/README.md`
   - `banyan-framework/docs/DOCUMENTATION_MAP.md`
   - `banyan-framework/docs/WRITING_STYLE_GUIDE.md`
   - `banyan-framework/docs/reference/`
4. 如果 Codex 列出了 `Human Decisions Required`，一并发来。

D1 不要求你现在决定所有中文术语。
先让 Codex 按推荐名写第一版，再集中做一次命名决策。
